## Current State

`/town_loop/` is a new V1 game shell. It does not replace `equipment_grind_v3`; it wraps the same combat stack in a broader town loop. Battle is not reimplemented from scratch: visual fights use `battle-view`, and simulation uses `combat-sim`.

The equipment-generation code is local to the town loop but follows the V3 direction: level-based base stats, rarity-based affix count, and per-item focused affix concentration.

## Unresolved

- Background grind is active-page/session based, not true offline progress.
- Events auto-resolve on next-day settlement; there is not yet a dedicated event battle preview/choice screen.
- Recruitment skill levels currently add strength through attribute/build-layer bonus, not true per-skill multiplier curves.
- Only D1-D6 region data is included in V1 to keep the shell small.
- Browser visual QA was a smoke pass, not a full layout polish pass across many viewport sizes.
