# 自利式几何确认感 C

- 日期：2026-07-17
- 状态：已完成程序级实现与精准测试

## 用户目标

确认感不能只奖励“预测完全准确”。玩家主动换人、换装或调整策略后，如果实际效果高于预期，往往会把成功归因于自己，产生“我真牛逼”的自我确认；实际低于预期时，确认感才应随差距增大而衰减。

基础常数 `0.1` 本次不调整，先观察非对称几何关系本身的效果。

## 实现规则

先计算可见战斗进度的实际与预期比例：

```text
比例 = 实际战斗进度 / 预期战斗进度
```

确认倍率：

```text
比例 >= 1：比例的 0.5 次方，最高为 2
比例 < 1：比例的 1.5 次方
```

最终确认感：

```text
C = 0.1
  × 有效预测信心
  × 结果清晰度
  × 目标重要性
  × 几何确认倍率
```

这条 C 只接在玩家主动选择的换人预测结算上。战斗结果 R 和超预期、低预期的 A 仍然分开计算。

## 六点曲线测试

| 实际/预期 | 确认倍率 |
|---:|---:|
| 0.5 | 0.3536 |
| 0.8 | 0.7155 |
| 1.0 | 1.0000 |
| 1.2 | 1.0954 |
| 2.0 | 1.4142 |
| 4.0 | 2.0000，达到上限 |

## 实际结算测试

固定同一条换人预测：

| 情况 | C | A 与 C 合计 |
|---|---:|---:|
| 完全命中 | +0.0228 | +0.0228 |
| 实际略低、仍在同一感知档 | +0.0203 | +0.0203 |
| 实际略高、仍在同一感知档 | +0.0237 | +0.0237 |
| 实际明显更低、跨到低档 | +0.0166 | -0.0782 |
| 实际明显更高、跨到高档 | +0.0251 | +0.0794 |

结果符合目标：

- 实际越高，C 越强；
- 实际越低，C 越弱；
- 明显失败虽然仍保留少量自我确认，但负 A 更大，合计仍为负；
- 明显成功同时获得正 A 和更高的 C；
- 最高倍率限制为 2，不会无限爆炸。

## 当前判断

保留 `0.1` 是合理的。加入几何倍率后，确认感已经能随成功程度变化，目前没有必要立刻把基础常数提高到 `0.15`。

尚未进行真实多玩家参数校准；`0.5/1.5` 次幂和倍率上限 2 仍是暂定值。
