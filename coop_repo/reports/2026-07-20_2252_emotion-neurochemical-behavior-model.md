# 玩家情绪的神经化学—行为模型研究

- Date: 2026-07-20
- Agent/thread: Codex 主任务
- Scope: 情绪相关神经递质、激素、生理时间尺度与Agent行为偏置
- Status: complete（研究方案完成，未修改正式运行时）

## User Intent

用户明确纠正建模方向：目标不是统计多少种情绪信号，而是模拟愤怒、恐惧、愉悦等状态激活后真实涉及的神经递质、激素和身体变化，并让这些物理化学状态真正改变Agent注意、学习和行为。

## Completed

- 明确否定“每种情绪对应一种分泌物”的一对一模型。
- 区分快速神经递质、神经调质、神经肽/脂质信号、外周激素和免疫信号。
- 整理谷氨酸、GABA、NE、肾上腺素、HPA/皮质醇、DA、内源性阿片、5-HT、ACh、内源性大麻素、OXT、AVP、睾酮与炎症信号的主要作用和误用边界。
- 按恐惧、愤怒、焦虑、愉悦/期待、宽慰、悲伤、厌恶、依恋、惊讶/洞察、骄傲、羞耻/内疚/后悔、挫败/无助整理典型组合。
- 提出第一版九个生理轴和两个慢变量。
- 设计`释放—衰减—相互调节`动力学，并要求输入威胁、控制、责任、奖励预测误差、不确定性和社会安全等认知评价，而不是情绪标签。
- 明确生理轴直接改变注意、学习、动作、规划、社会选择、疼痛和疲劳。
- 给出现有R/A/C/EVerify/EDecision迁移到生理模型上游的方式，并标记双算风险。
- 给出12个确定性验证case和主要研究依据。

## Validation

- 使用人类药理、压力诱发、生理测量和学习实验检查以下方向：
  - NE/ACTH比皮质醇响应快；
  - 恐惧与愤怒并非同一自主神经/HPA模式；
  - DA更接近预测误差和行动动力而不是快乐；
  - 内源性阿片参与享乐；
  - 5-HT参与惩罚诱发抑制；
  - NE/ACh/DA对不确定性学习有不同作用；
  - OXT、内源性大麻素和睾酮作用高度依赖情境。
- 本轮未改运行时代码，没有代码回归。
