# Agent Handoff: 八大定位首套与骑兵／护佑者机制

- Date: 2026-08-15
- Agent/thread: Codex root equipment-design line
- Scope: 一级战斗定位、首套装备公式、骑兵冲锋与护佑回响
- Status: complete

## User Intent

按八大定位逐类设计第一套装备。每套由基础强化与战场职能强化构成；本轮纠正盾兵无需强行分子职业，确定骑兵共享冲锋规则与护佑者范围回响，并保留奇谋兵继续讨论。

## Completed

- 新建八大定位首套装备主文档，记录近战兵、盾兵、弓兵、骑兵、奇谋兵、护佑者、魔法师、战斗辅助。
- 保留近战兵`万夫之勇`与弓兵`鹰眼校准／天穹之箭`方向。
- 纠正叹息之墙：套装自身保持统一；不同盾兵通过已有光环范围、护盾量和控制强化自然改变其效果，不为每个子职业硬写分支。
- 将`冲锋`定义为共享战斗关键词：持续移动达到距离后进入状态，获得攻击与移速，首次接敌时无视普通敌人碰撞穿过路径并造成伤害；障碍、专门拦截与叹息之墙仍可阻断。
- 记录马骑兵靠加速和腾挪、象骑兵靠大范围、龙骑兵靠反复起降与持续移动运行同一冲锋规则。
- 记录护佑者基础强化为治疗与自身生命；原始治疗、护盾、净化对每个目标独立判定范围回响，多目标技能可触发多次，回响不可递归，锤牧只复制附带的护佑部分。
- 奇谋兵仅记录“敌方注意力／未被关注”候选资源，没有把具体兑现效果误写成定案。

## Current State

八大定位已有统一套装模板，其中五类拥有第一套方向。骑兵不再依赖每名角色自带冲锋技能；套装允许任何骑兵用足够移动距离进入共享冲锋。护佑者的战场价值从单体数值提高扩展为可在大战中多次扩散的保护效果。
