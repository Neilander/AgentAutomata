# Agent Handoff: 单例模糊类比与目标角色重绑定

- Date: 2026-08-16
- Agent/thread: root
- Scope: 验证模糊连续空间能否把一条源经历迁移到不同对象和领域
- Status: complete（隔离实验）；未接正式玩家

## User Intent

前一版只是“写下经历再查相似记录”，没有证明模糊表示的真正价值。需要验证：玩家只见过别人在A场景触发某结果，到了对象、措辞甚至领域不同的B场景，是否能因为变化结构模糊相似而预测相似结果；还必须防止表面相似造成错误类推。

## Completed

- 新建独立实验`analogical_transfer_v0`，没有覆盖前一版硬轨迹检索。
- 只保留15条源经历，每个因果家庭恰好一条；没有提前放入多种炸弹、车辆或武器换皮经验。
- 将场景参与者表示成临时槽位，如`actor/target/device/linked`；脆弱、坚硬、失效、接触、越阈值等决定性信息仍保持自然语言。
- 比较四种矩阵行：原始当前、原始变化、角色归一化当前、角色归一化变化。所有源经历一次编码成15×768矩阵，运行时单次矩阵乘法选取类比源。
- 取回源轨迹后，把后果中的临时角色重新绑定到目标对象，输出目标场景自己的后继状态，而不是复读源场景名词。
- 开发阶段发现陌生案例含“未知规则”文字泄漏后主动删除，重新定参；最终42例哈希冻结并只运行一次。

## Validation

- 最终总体：39/42（92.9%）。
- 已知规律跨场景迁移：31/32（96.9%）。
- 换领域10/11；换对象9/9；失效状态覆盖2/2；困难反例8/8；脆工具/脆障碍角色互换2/2。
- 完全陌生规律：正确拒绝8/10。
- 消融：原始当前27/42；原始变化19/42；角色归一化当前34/42；角色归一化变化39/42。
- 没有角色重绑定时，旧经历文本包含目标角色的比例为0%；重绑定后的目标专属后继状态正确率为96.9%。
- 成功例：只记得`玻璃剑撞钢墙→玻璃剑断`，面对`冰晶钻头撞钛合金舱壁`，输出`冰晶钻头在反作用力下断裂，钛合金舱壁保持完整`。
- 成功例：只记得`铁球撞脆木门→木门碎`，面对`装甲车撞薄冰墙`，输出`薄冰墙碎裂并失去阻挡作用，装甲车继续向前`。
- 唯一已知规律错误：`无人机吸入腐蚀气体`把“吸收有害物”错配为“只观察有害物”；两个候选相似度为0.9316与0.9274，几乎打平。
- 两个陌生规律误联想：`果实越过红线`被类比成未接触，`玻璃鱼贴住柔软石头`被类比成脆工具撞硬物；两例Top1与Top2差距也很小。

## Current State

这次证明的不是普通相似记录查询。目标对象从未出现在源记忆里，系统先用模糊空间取回结构相似的源变化，再把源后果中的角色关系投射到目标角色，才能生成目标自己的预测。角色归一化变化比原始当前高12/42，比原始变化高20/42，证明“临时角色连续性＋模糊变化结构”确实提供了额外能力。

最合理的当前结构是混合式的：连续空间负责模糊找类比，最小符号槽位负责保持“谁作用于谁”，硬轨迹保存看过的后果。纯文本相似不够，纯向量箭头平移也不够。

## Unresolved

- 实验预先提供了角色槽位和归一化描述。真正接入前，必须验证AI能否从规则/战报稳定生成这些槽位；否则92.9%只是理想解析器上限。
- 结果迁移使用源轨迹槽位模板，不是向量凭空生成新因果规律；这正适合“见过类似事情后的类推”，但不能预测完全新规律。
- 三个失败均表现为Top1/Top2几乎打平。可增加相似度差距门槛，把它们变成“我不确定”，但不能用当前最终集继续调；需另建留出集验证。
- 临时槽位只有少数角色，尚未测多主体、多阶段和角色在链条中交换身份。

## Recommended Next Step

下一步不要立刻接完整UFS。先做“AI自动构建临时角色轨迹”的隔离实验：给AI原始规则句和两帧公开场景，让它输出匿名槽位、前后关系和后继槽位模板；再与本实验的人工标准对比。若解析稳定，再把`归一化变化→矩阵类比→角色重绑定`接入UFS的一两条飞机落点链。
