# Agent Handoff: 一万条顺序类比学习实验

- Date: 2026-08-16
- Agent/thread: `/root`，数据设计、学习器、独立审计子 Agent 协作
- Scope: 验证“把经历作为模糊轨迹保存，见到相似变化后预测结果”能否随经历增加稳定提升
- Status: partial

## User Intent

生成一万条包含 1—3 个主体、1—2 次相互影响及结果的经历；学习侧与评测侧各 5000 条。Agent 每次新增读取 100 条并记录，再预测 100 条未回流的评测经历，直到连续稳定达到 80%，最多学习 5000 条。

## Completed

- 由 Agent 编写了 120 个跨领域因果家族：100 个训练/评测共享家族、10 个仅训练家族、10 个仅评测未知家族。程序只负责结构校验、表面展开、切分与哈希，没有把隐藏家族编号交给学习器。
- 生成并冻结了 5000 条学习经历与 5000 条评测经历；两侧各 5000 条公开文本均不重复，跨侧完全相同文本为 0。
- 每条经历包含 1—3 个主体、1—2 次相互影响、1—3 个可核验状态结果。评测结果永不写回记忆。
- 实现两种记忆检索：逐条轨迹近邻，以及把多条相似原因累积成连续“结果原型”的矩阵检索。后者明显优于被重复样本占满的 Top-K 投票。
- 完整跑完 50 轮理想解析上限实验：每轮增加 100 条记忆并预测新的 100 条，达到 5000 条后停止。
- 额外做了两轮真正的语言 Agent 盲测：Agent 只读公开经历，自行写短记忆并预测，没有读取答案、评分器、隐藏家族或上一轮分数。
- 完成泄漏审计、重复家族审计、失败案例归因和阈值风险分析。

## Main Results

### 冻结的一万条数据

- 学习侧：5000/5000 条公开文本唯一。
- 评测侧：5000/5000 条公开文本唯一。
- 学习/评测公开文本精确重叠：0。
- 共 50 个批次，每批新增学习 100 条、评测 100 条。

### 理想解析器 + 连续结果原型

这里的“理想解析器”表示程序已经正确知道谁作用于谁，仅测试模糊轨迹检索和结果重绑定能力；它不是完整 AI 玩家。

- 第 1 轮：31%。
- 第 50 轮：82%。
- 最高单轮：87%（第 14 轮）。
- 50 轮平均：75.02%。
- 最后 5 轮平均：76.2%。
- 共有 12/50 轮达到或超过 80%。
- 只固定使用最初 100 条记忆的对照，50 轮平均仅 35.78%。
- 预注册的稳定条件是连续 5 轮总准确率至少 80%，且已知规律与未知拒答各自过线；该条件没有达成，因此正式结论是**未通过稳定 80%**。

这证明增加经历确实显著改善了模糊类比，不是随机自娱自乐；但它仍会在复杂相近规律间波动，尚不足以当稳定唤醒器。

### 真实语言 Agent

- 读 100 条后的第一轮：16/100；回答覆盖率 71%，未知规律拒绝率 80%。
- 累计读 200 条后的第二轮：11/100；回答覆盖率 85%，未知规律拒绝率 40%。
- 第二轮 Agent 未读取第一轮评分或任何答案。

真实 Agent 并未表现出理想解析器的学习曲线，且第二轮更差。因此没有继续消耗 48 轮调用；不能把理想解析器的 82%表述成“Agent 已经学会”。当前最大瓶颈是：Agent 如何把自然语言经历稳定压缩成可比较的主体—互动—结果轨迹，以及如何严格把旧结果绑定到新主体。

## Current State

“变化轨迹可以作为模糊经验，并通过矩阵相似度跨场景迁移结果”已有正证据：随着记忆从 100 增至 5000，理想上限从 31%提升到最终 82%，远高于固定 100 条对照。

但现在只验证了给定正确结构后的检索上限。自然语言到结构的真实 Agent 接口不稳定，三主体、双互动尤其容易把相近但不同的因果规律混为一谈。

## Unresolved

- 结果原型目前按观察到的精确结果签名聚合；在本数据中，110 个学习家族几乎各有唯一结果签名，存在“结果签名近似代理标签”的风险，不能当成人类式泛化的最终证据。
- 多经验 Top-K 的初版被同义复制占满，并没有真正聚合不同证据；需按不同轨迹表面去重或限票。
- 三主体问题常被二主体经验错误解释，需要主体数量、角色连续性和有向互动结构的兼容度。
- 拒答阈值不能继续在已曝光评测池上调整；必须用独立开发集定参，再换全新冻结评测。
- 真实 Agent 只跑了 200 条。原因是连续两轮仅 16%/11%，继续跑到 5000 无法回答当前机制是否正确，只会浪费调用；修复上游记忆表达后应重新从新数据开始。

## Recommended Next Step

最高价值不是继续调相似度阈值，而是先做一个很小但严格的“自然语言经历 → 主体槽位 + 有向互动 + 状态变化”记录接口：同一事件让多个盲 Agent 独立解析，先把结构一致率与角色重绑定率做到可靠。随后把精确结果字符串改成连续的结果变化向量，加入主体/互动结构兼容度，再用全新种子与哈希重跑 5000 条顺序曲线。
