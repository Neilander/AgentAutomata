# 灰谷村魔物战争：静态网页

这是 `border_village_war` 程序核心的静态前端。它复用十五日版本的共享地图镜头、战斗视图和手动八部位配装思路，但把经营行动改成“点击地图节点，在节点旁处理”的结构。

## 打开

直接双击本目录的 `index.html`。页面通过相对路径加载共享脚本，不需要也不会自动启动服务器。

## 验证

```powershell
node verify-static-web.js
```

该验证只做程序与静态契约检查，不启动服务器或浏览器。它会确认地图镜头、节点局部行动、八部位手动装备/卸装、真实战斗时间线、战斗结算封口，以及脚本依赖完整性。

浏览器进度保存在 `localStorage` 的 `infinite_loot_border_village_war_v2`；右上角重开按钮可清除本章进度并更换种子。
