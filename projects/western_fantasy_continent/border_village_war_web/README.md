# 灰谷村魔物战争：静态网页

地图上的真实英雄与民兵会在建筑之间活动：单位先停在一座建筑旁，再沿内圈前往下一座建筑。主角、骑士、侦察者和不同民兵队使用不同的建筑组合；速度与出发时间错开，实际点击区域会跟随头像移动，悬停或键盘聚焦时暂停以便操作。

神话装备不再只使用红色边框。背包格、角色已装备槽和战后掉落格采用完整深红材质底，并叠加红金紫流光、斜向扫光、内侧高光和轻微呼吸；选中的神话装备另有金色内框。文本始终位于特效上层，系统启用减少动态时会停止扫光与呼吸。

为便于直接比较，新档初始背包会得到普通、稀有、史诗、传说、神话、永恒、黑金、炼狱各一件正式装备，刚好覆盖武器、头盔、胸甲、戒指、护符、手甲、腿甲和战靴八个部位。永恒采用蓝白冰光扫过整个格子，黑金使用低亮黑曜底与金脉流光，炼狱由暗红焦底和底部火焰构成；三者都覆盖背包格、已装备槽和战后掉落格，并遵守减少动态设置。第1天开场剧情中即可穿戴或卸下这些装备。已有浏览器存档不会自动补发，需要使用右上角“重开”创建新档。

这是 `border_village_war` v3 程序核心的静态前端。地图保持简洁节点图：房屋、农田、集市、铁匠铺、征召所和建设位继续使用统一节点语言。所有已拥有英雄与每支真实民兵都显示为战斗场景风格的圆形职业头像，并在建筑卡片旁的停靠点之间移动；两者都能点击进入人物页。繁荣等级还会带来额外的普通村民剪影（每级2人），它们不代表可战单位、不响应点击，并沿田边、河岸、集市和村口走不同的短路线。战士仍由左侧单位方框总览，避免地图重复拥挤。点击地图单位、左侧任一头像或地图底部“队伍与装备”，会打开同一个独立军备浮窗。编队页左侧管理2/4/8/20单位编队并显示40/100/200单位锁定规格；一名英雄、一支10人民兵队或一支10人战士队都占1单位。每支编队直接显示一战粮耗。出战与候选单位采用上下两块长方形人物牌：上方立绘区完全留给未来正式立绘；缩小的无框职业图标居中跨在立绘区与信息区的分界线上。右侧通过上下拖拽编辑成员，可按灰谷村筛选候选；“调整站位”会把右侧切成带前后方向的阵地槽位。超出单位上限或混城不会隐藏操作，而会让整队变红并显示原因。

进入战斗前先选择编队，再按“开战”让整个窗口左滑到军粮准备。军粮页中央是一口可点击的大锅：按一下投入1粮，长按连续投入，右下角持续显示 `已投入/满额` 与当前发挥百分比。0粮仍可出发但只有20%发挥，满额为100%；这个比例会真实改变参战队伍的生命、攻击和护甲，并由同一投入量完成权威结算。粮食不足不会隐藏战斗，只会显示粮仓可投入上限。小容量编队可以向下兼容更大规模战斗；全部编队依次分为“容量兼容且合法、容量兼容但不合法、超过人数上限”。人物页用上一页/下一页切换英雄、战士和民兵；民兵显示真实技能与基础数值，但八个装备槽和配装动作明确锁定。地图直接显示基础建筑和建设位；占领敌据点后原节点变成建设位。边林节点公开五档难度、掉落概率与共享加权积分：难度N胜利增加N分，5/20/90/200分依次解锁难度2—5。

经营阶段的地图东南侧会出现紫灰色“远古遗迹”高危节点。入口只公开无人返回的探险痕迹和4单位高难战，不会提前显示密室人物或后续机关。入口胜利后，节点原地推进到密室剧情：玩家在两个清楚标明战斗影响的救援方案中选择，再进入8单位极高难核心战。缺少12粮时补给方案继续以红色显示短缺原因，免费密道方案仍可选择。两种方案分别增加一名虚弱固定盟友或减少两组敌人；最终胜利后节点变为已完成状态，两名角色加入队伍并获得永恒遗珍。

地图右上角、顶部栏下方现在悬浮“当前城镇”状态框，常显灰谷村、当前人口/人口上限、今日行动/每日上限和繁荣等级；金币与粮食仍留在顶部栏。点击繁荣等级会打开一条可按住左右拖拽、滚轮横移或方向键浏览的人口轴。轴上方只显示人口刻度，轴下方显示奖励；40/70/100人口的“行动力+1”使用较大字号，前期每10人口的“+1民兵单位”使用次级小字。没有重复卡片和边框。当前人口上限之后设置一条金色纵向阻拦线并标注“人口上限”，线后的奖励继续可见但整体弱化。该界面读取核心公开的当前城镇里程碑，不在前端写死第二座城的规则。

征召完成后不再打开普通文字结果框，也不会搬出完整繁荣窗口。屏幕盖上一层80%透明度的纯黑遮罩后，中央只悬浮同一条人口轴，不显示标题栏、当前概况、拖拽提示、规则底框或窗口边框，也不使用灰度或模糊滤镜。人口从征召前的数字沿轴推进到新数字；未来奖励在演出中隐藏，只有标记实际跨过节点时，轴下对应的单位或行动力收益才弹出。若跨过繁荣等级，中央额外突出显示新等级和新的每日行动上限。整段演出完成后才单独浮出“返回城镇”，在此之前关闭键与Escape不会跳过关键反馈。

## 打开

直接双击本目录的 `index.html`。页面通过相对路径加载共享脚本，不需要也不会自动启动服务器。

## 验证

```powershell
node verify-static-web.js
```

该验证只做程序与静态契约检查，不启动服务器或浏览器。它会确认地图镜头、当前城镇框、人口/人口上限、繁荣里程碑与横向拖拽、收益标识、五档刷关选择与进度条、占领地建设、远古遗迹阶段节点、红色禁用原因、英雄与战士八部位配装、战前编队排序与真实部署、两段式左滑军粮准备、点击/长按投入、20%—100%真实战力缩放、真实战斗时间线、战斗结算封口以及脚本依赖完整性。

浏览器进度保存在 `localStorage` 的 `infinite_loot_border_village_war_v3`；右上角重开按钮可清除本章进度并更换种子。
