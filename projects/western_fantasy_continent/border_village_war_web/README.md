# 灰谷村魔物战争：静态网页

这是 `border_village_war` v3 程序核心的静态前端。地图直接显示基础房屋、农田、铁匠铺和两个初始建设位；资源建筑节点带有收益类型与大概范围。已知敌据点经真实战斗占领后，会在原节点变成新的建设位。边林节点会同时显示五档难度、共享总胜场、5/10/30/50次胜利解锁目标，以及每档精确的掉落件数和稀有度概率；任意难度胜利都推进解锁，锁定档位保持红色可见，解锁后由玩家手动切换。

## 打开

直接双击本目录的 `index.html`。页面通过相对路径加载共享脚本，不需要也不会自动启动服务器。

## 验证

```powershell
node verify-static-web.js
```

该验证只做程序与静态契约检查，不启动服务器或浏览器。它会确认地图镜头、收益标识、五档刷关选择与进度条、占领地建设、红色禁用原因、八部位与整队一键配装、基于已知事实的决战风险提示、真实战斗时间线、战斗结算封口以及脚本依赖完整性。

浏览器进度保存在 `localStorage` 的 `infinite_loot_border_village_war_v3`；右上角重开按钮可清除本章进度并更换种子。
