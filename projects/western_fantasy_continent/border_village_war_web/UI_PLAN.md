# 边陲村魔物战争 v3：玩家界面契约

## Intent

玩家在第7日总攻前，用金币扩大人数与补齐装备，用粮食训练和出征；攻占敌方据点后在原地建立新的持久产能。

## Core object

经营阶段的核心对象是可拖动地图：村庄基础设施、两个初始空建设位、已侦察敌据点和已占领前哨都直接存在于地图上。敌据点被占领后，原节点必须变成建设位，而不是从地图消失并在别处增加抽象数字。

战斗阶段的核心对象仍是共享真实战场；不能跳过过程或直接伪造结算。

## Player decision path

```text
看建筑收益标识
→ 在两个初始空位选择农田 / 铁匠铺 / 房屋
→ 免费刷装强化英雄并推动铁匠铺金币收入
→ 用金币购买确定装备或扩大征召
→ 用粮食训练民兵或突袭已知据点
→ 完整战斗并占领据点
→ 在原据点的新建设位继续扩大产能
→ 用实际有粮出战的军队参加第7日决战
```

## Information priority

- P0：日期、剩余行动力、金币、粮食、人口、当前打开的地图节点。
- P1：建筑收益类型与大概范围、敌据点的粮食成本和占领奖励、民兵/战士数量。
- P2：刷装后铁匠收入、战斗后解锁的新建设位、建筑立即完成后的收益变化。
- P3：装备词条、最近日志、市场三件商品。
- P4：敌方倍率、胜率、掉率表、未来事件、未取得情报的据点、正确路线。P4不得进入玩家界面。

## Map hierarchy

```text
map
  left unit rail: player, every recruited hero, every militia unit, every trained unit
  command node: current story or event
  village ring
    house: population cap badge
    farm: approximate daily food badge
    smithy: approximate daily gold badge
    market: daily gear stock badge
    conscription: population range badge
    two initial empty plots
  frontier
    visible enemy raids
    captured outposts replacing defeated raid nodes
  free equipment hunt
  war board
```

收益标识位于建筑节点上方，只显示“收益类型＋大概范围”；具体当前进度在点开节点后显示。地图不能变成文字表格。

## Controls and feedback

- 顶部右侧以“当前城镇”作为一个稳定对象：常显城镇名、当前人口/人口上限、今日行动/每日上限和繁荣等级。金币与粮食仍是资源，人口和行动力不再混进同一排全局数字。
- 点击当前城镇的繁荣等级打开人口收益轨迹。轨迹横向拖拽，当前人口最近到达的里程碑高亮；已获得、未来可达和超过当前人口上限分别使用完成、普通、虚线状态。每个节点只显示人口门槛与直接收益。
- 灰谷村沿用当前节奏：繁荣 Lv.1/2/3/4 对应人口0/40/70/100与每日行动3/4/5/6；前期10—100人口每10人新增1个民兵单位。前端消费核心里程碑数据，后续城镇可以采用不同的单位奖励间隔。
- 空建设位只显示农田、铁匠铺、房屋三项；建造消耗1行动并立即完成。
- 已解锁但暂时做不了的操作继续显示为红色，并明确列出缺少的行动力、金币、粮食、人口容量或可训练民兵。
- 未侦察据点和未来事件继续隐藏；“禁用可见”不能成为泄露未来内容的理由。
- 连续刷装画面同时显示今日装备进度和铁匠铺累计收入，让金币增长与掉落处在同一反馈区域。
- 集市每天刷新三件完整属性可见的装备；背包出售明确显示每日剩余5件额度。
- 突袭显示满额粮食、已知敌我成员和“占领后解锁1个建设位”，不显示胜率或推荐答案；粮食不足不隐藏战斗入口。
- 训练和突袭必须运行完整战斗；结果弹窗写清士兵晋升、敌军削弱和领地解锁。
- 战士每队一战满额需要3粮，民兵每队1粮；每支编队常显“一战粮耗”。战前由玩家逐份投入，0粮为20%发挥，满额为100%，中间线性变化；百分比明确对应全队生命、攻击和护甲，不是模糊预测。
- 决战入口只整理已经公开的事实：敌我实体数、穿装英雄数和已占用部位，并给出粗粒度风险词；不显示胜率、隐藏强度公式或推荐解法。
- 地图底部军备按钮和可配装单位头像打开同一个模态军备界面；旧的底部多页抽屉不再作为主要换装路径。
- 军备浮窗顶部保留“编队 / 人物”分页切换。人物页不常驻全角色头像轴，而是在左侧人物栏用上一页/下一页切换，排序仍为队内在前、候补在后。
- 人物翻页包含英雄、已训练战士和每支民兵。民兵使用正式战斗模板显示4个技能与基础数值，但八个装备槽保持可见锁定；“一键当前”改为红色“装备锁定”，背包只允许查看。民兵不进入装备所有权、一键全队分配或装备/卸下动作。
- 编队页左侧约25%为全部编队长列表：2/4/8/20单位规格可编辑，40/100/200单位规格保持可见锁定。每行直接显示当前单位数/上限、编队名、所在城池和合法性。一名英雄、一支10人民兵队或一支10人战士队均占1单位。
- 编队页右侧约75%为同一拖拽簇：上方出战成员，下方可选成员。成员向上拖入、向下拖出，点击卡片作为无拖拽设备的恢复路径；可选区右上可筛选当前城池并显示筛选后的候选数量。
- 编队单位使用上下两块长方形人物牌。上方是占据剩余高度、完全留空的立绘区；缩小的无边框、无底板职业图标水平居中，跨在立绘区与下方信息区的分界线上，承担上下衔接而不冒充立绘。下方信息区第一行左对齐姓名、右侧城镇，第二行用更小字号显示“战斗力＋完整数字”，避免窄底栏挤压数值。战斗力来自当前真实战斗属性而非装备评分；换装后同步更新。站位槽沿用身份与战斗力层级的紧凑版，职业图标同样不加装饰框。
- 出战成员区提供“调整站位”。进入后左侧编队列表保留，右侧候选与成员列表让位给阵地这一核心对象：2单位为一前一后，4单位为2×2，8单位为4×2，20单位为5×4方阵。成员按出战顺序从前到后初始入槽；拖到空槽移动，拖到占用槽交换。点击头像再点击目标槽是无拖拽设备的替代路径，“完成站位”返回成员选择。
- 超员和混城不会阻止编辑；左侧编队行、右侧整个编辑区和明确原因同步变红。玩家必须能看到自己制造了什么问题，也能立即把成员拖回下方修复。
- 每场战斗公开一个战斗类型和参战人数上限：讨伐/训练最多4单位、突袭最多8单位、最终决战最多20单位。编队向下兼容，只要自身容量不超过本场上限就视为容量兼容。战前左侧列出玩家全部已建立编队，严格按“容量兼容且合法 → 容量兼容但不合法 → 超过人数上限”排序；同组内最接近上限的编队优先。点击任何一队都可查看，不能出战的队伍保留红色原因。
- 战前第一页右侧专门显示当前所选编队：容量、驻地、一战粮耗、总战斗力、按站位排序的成员、固定附加单位以及已知敌方阵容。容量兼容、合法且非空时可以按“开战”，窗口整体左滑进入第二页军粮准备；粮食不足不阻断。
- 军粮准备页以大锅为唯一核心操作。点击投入1粮，长按连续投入；右下角同时常显`x/X`与发挥百分比，并提供清空和返回选队。所选成员、站位、投入粮食和由此得到的战力倍率必须共同进入实际战斗与权威结算，不能只改变预览。
- 军备浮窗的核心对象是“当前人物＋八个装备槽”。分页释放出的全部高度由左右两区使用：左侧以安静的立绘占位为中心，不使用放大的姓名汉字；左右各4个小方形装备槽、下方显示4个技能；右侧是背包与当前物品操作。
- 人物两侧的装备方格只常显部位图标、部位名和稀有度边框；完整装备名、评分、基础属性与词条在鼠标悬停或键盘聚焦时显示，避免八个大文本框挤压立绘。
- 立绘区让出约5%的垂直空间给技能；技能区不再套独立外框，四张技能卡直接形成一组。技能卡的常态阅读顺序固定为“左上技能名 → 下一行技能类型 → 一句效果概述”，冷却置于右上；鼠标悬停或键盘聚焦时显示目标数量、基础值、攻击倍率、伤害类型、持续时间及被动的真实结算比例。数值来自正式技能与战斗规则，不用模糊文案代替。
- 背包排序固定为“当前角色已穿 → 未穿戴 → 其他角色已穿”，让物品所有权在换装前可见。不能直接转交的他人装备保留显示并说明恢复步骤。
- 数值按钮与“一键当前 / 一键全队”处于同一技能操作行，紧跟在“一键全队”右侧；悬停后用覆盖层替换立绘和技能信息。数值是当前装备结算后的公开结果，不显示胜率或隐藏敌方公式。
- 军备浮窗保留单人和整队一键配装，逐件手动配装与卸下仍保留。装备总和称为“显示评分”，不冒充角色的实际伤害预测。
- 地图左侧常驻无外框的单位头像方块：主角、所有已招募英雄（含候补）、每支民兵和每支战士各占一个40px方格；从上到下排列，高度不足时换到第二列，不使用滚动容器。只承担在场表现与数量/状态识别，不把地图变成角色操作列表。

## Attention budget

- 经营：地图与节点60%，当前节点浮层20%，顶部资源与战况12%，军备入口与单位表现8%。
- 军备浮窗：顶部模式切换8%，左侧当前人物、立绘、八槽与技能46%，右侧背包与物品操作46%；数值覆盖层仅在玩家悬停请求时取得左侧注意力。
- 连续刷装：战场65%，掉落陈列18%，铁匠收入与停止控制17%。
- 战前选队：编队选择25%，所选编队与敌方详情48%，战斗类型/规模/满额粮食15%，开战/取消12%。战前军粮：大锅与投入反馈62%，`x/X`和发挥百分比20%，返回/清空/出发18%。
- 战斗：真实战场82%，标题与粮食8%，结算10%。

## User review contract

User: 第一次进入第3日的新手。
Intent: 看懂两种核心资源，建立产能，并尝试夺取一个新建设位。
Prior knowledge: 只知道第7日有魔物总攻。
Success state: 能从建筑标识解释钱和粮从哪里来；能从红色禁用项说出缺什么；能亲历“发现据点→战斗→占领→原地建设”。

恢复路径：地图浮窗和战前窗口可取消；连续讨伐可在本轮后停止；战斗失败只消耗公开显示的行动与粮食，已知据点不会消失；错误建筑不会隐藏其他系统，但本Demo暂不提供改建。
