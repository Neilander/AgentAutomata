# 边陲村魔物战争：玩家界面契约

## Intent

玩家进入页面，是为了在第7日兽人大军抵达前，用有限行动经营灰谷村、用无限讨伐武装英雄、通过突袭削弱敌军，并亲自看完最终大规模战斗。

### Screen states

- 剧情引入：地图只突出当前现场与一项必须处理的剧情，不提前铺开经营菜单。
- 经营：整张村庄地图是核心对象；点击建筑、空地、事件或敌方据点，才在节点旁展开本地点行动。
- 队伍：底栏展示全部英雄；所选英雄的定位、偏好词条与八个装备部位相邻显示。
- 背包：固定网格扫描装备；详情区紧邻所选角色与“装备/出售”动作，不提供一键配装。
- 战前：显示双方成员、投入粮食与预计发挥，不显示胜率、内部数值或推荐答案。
- 战斗：地图与经营按钮退出注意中心，共享真实战场占据主区域；无跳过按钮。
- 结果：先显示胜负、倒下者、存活、伤害/治疗/护盾，再由玩家确认应用战后变化。

## Core object

- 经营阶段：六块建筑地、当前事件、边林讨伐与已经侦察到的敌方据点组成的灰谷村地图。
- 战斗阶段：共享战斗运行时中的双方单位与完整战斗过程。
- 配装阶段：所选角色及其八个固定装备部位。

所有“选择来源→影响目标”保持邻近：建筑行动贴着建筑节点；背包装备与角色八部位同处底栏；粮食投入与敌我预览同处战前窗口。

## Information inventory

- P0：当前日/决战日、剩余行动力、剩余敌军与主将、当前打开的节点、正在运行的战斗。
- P1：金币/粮食/铁料/精钢、实际人口/上限/民兵、行动成本、农田预测、集市购买力、战前投入后的发挥。
- P2：行动后的资源差、次日完工、解锁的新据点、新角色定位、倒下者与战斗贡献。
- P3：最近记录、全部装备词条、市场库存、建筑说明。
- P4：随机数、真实掉率、敌方倍率、未来事件、未出现的事件选项、设计目标。P4 永不进入玩家界面。

## Attention budget

- 剧情：当前现场65%，日期与威胁20%，队伍15%。
- 经营：地图/建筑55%，当前节点浮层22%，战争与资源13%，底栏摘要10%。
- 队伍：英雄列表22%，所选角色与八部位48%，角色定位/偏好20%，其余10%。
- 背包：装备网格48%，物品详情27%，所选角色和动作25%。
- 战斗：真实战场82%，战斗标题与补给8%，结算10%。

## Control choices

- 地图只同时显示约8—12个有空间关系的节点，不把全部行动做成侧栏卡片。
- 点击节点打开就地 popover；点击空白或关闭按钮退出，错误选择可安全取消。
- 两块空地各自显示三种建筑选择；铁匠打造的八个部位压缩为下拉框加确认按钮。
- 市场购买在市场节点；出售只针对背包当前选中装备，避免几十个出售按钮淹没地图。
- 队伍与背包用底栏标签切换；角色列表、八部位和装备动作保持同一操作簇。
- 招募使用灰色遮罩的覆盖提示；新据点以一次脉冲标记，并在行动结果中写明来源。
- 战前窗口提供取消；战斗开始后没有跳过，连续讨伐只能“本轮结束后停止”。
- 结果弹窗只用于会改变局势/资源/建筑的行动；查看角色、换装等即时操作用近场反馈，不打断流程。

## Hidden/debug information

不显示成功率、敌方生命/攻击倍率、掉率表、未来事件、未满足的事件方案、预设正确路线、模拟玩家知识或内部 action id。公开的20%—100%粮食发挥、农田产量范围、固定交易价格、人口与民兵关系属于可决策规则，应直接显示。

## Expected player path

```text
处理第1—2日剧情
→ 第3日先看战争牌与六块地
→ 点击一个建筑/事件/边林节点
→ 在节点旁完成一项行动
→ 通过结果弹窗看资源或局势变化
→ 在底栏给具体角色手动配装
→ 侦察据点并选择粮食投入
→ 完整观看突袭
→ 第7日晨收、全员集结、完整观看决战
```

## User review

User: 第一次进入第3日的新手。  
Intent: 判断今天先经营、刷装还是突袭。  
Prior knowledge: 只知道第7日有20支军团和3名主将。  
Success state: 能在两秒内找到行动力、战争压力和一个可点击节点；一次只需理解当前节点的2—4个动作。

关键任务路径：

1. 看威胁：顶部与战争牌同时给出日期、敌军、民兵；点击任一节点不会遮住这些数字。
2. 建建筑：点空地→看成本→选择→近场显示“第几日完工”；误点可关闭浮层。
3. 配装：点底栏角色→点背包装备→看替换项→确认装备；可继续用其他装备替换，没有不可逆死锁。
4. 突袭：点据点→选择粮食档→战前预览→取消或开战→完整战斗→结果说明削减了多少敌军。
5. 决战：第6日结束前明确显示仍有最后晨收、会全员集结；第7日只有补给档和开战，不出现已经失效的经营动作。

最小恢复路径：所有 popover/dialog 均可取消；战前可返回；连续讨伐可在当前轮结束后停止；本地存档可通过重开对话框清除。战斗失败属于有意压力，不提供中途跳过或伪结算。
