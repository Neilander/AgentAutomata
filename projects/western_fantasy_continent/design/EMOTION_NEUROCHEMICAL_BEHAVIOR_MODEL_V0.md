# 玩家情绪的神经化学—行为模型 V0

- 日期：2026-07-20
- 状态：研究方案，尚未接入正式运行时
- 目标：不再把“愤怒、恐惧、快乐”等情绪当成直接控制行为的命名数值，而是模拟它们共享的神经递质、激素、身体状态和学习偏置。

## 一、最重要的科学边界

现实中不存在以下一对一关系：

```text
愤怒 = 分泌某一种物质
恐惧 = 分泌另一种物质
快乐 = 分泌多巴胺
```

真实情况更接近：

```text
事件与身体信号
→ 玩家对威胁、控制、责任、奖励、损失和不确定性的判断
→ 多套神经化学与自主神经系统以不同速度共同变化
→ 注意、学习、疼痛、行动速度、趋近、逃避、耐心等发生偏置
→ 结合“对象是谁、我能否控制、是谁造成的”等认知内容
→ 形成愤怒、恐惧、兴奋、悲伤、宽慰等主观体验和行为
```

同样的心跳加快、去甲肾上腺素和肾上腺素上升：

- 面对强敌且认为自己无力逃生，可以成为恐惧；
- 面对阻碍且认为自己能够反击，可以成为愤怒；
- 面对主动选择的高难挑战，可以成为兴奋。

所以化学状态提供“身体与行为底盘”，认知评价决定它被组织成什么情绪。

## 二、“分泌物”实际包含四种不同东西

不能把它们全部当作血液里的激素。

1. **快速神经递质**
   - 谷氨酸、GABA；
   - 在神经元之间局部释放；
   - 毫秒到秒级；
   - 决定局部回路是兴奋还是抑制，但并不对应某一种情绪。

2. **神经调质**
   - 多巴胺、去甲肾上腺素、血清素、乙酰胆碱；
   - 调整大量神经网络的学习率、注意、行动活力和抑制；
   - 秒到分钟级；
   - 同一种物质在不同脑区和受体上可以产生不同甚至相反作用。

3. **神经肽与脂质信号**
   - 内源性阿片、催产素、加压素、内源性大麻素；
   - 影响疼痛、愉悦、安全、依恋、压力恢复和社会注意；
   - 秒、分钟到更长时间。

4. **外周激素与免疫信号**
   - 肾上腺素、皮质醇、睾酮、ACTH、细胞因子；
   - 通过心血管、代谢、免疫和较慢的脑反馈改变行为条件；
   - 秒到小时，慢性变化可延续数天。

## 三、主要物质与真实行为作用

下表不是“情绪配方”，而是第一版需要考虑的生理作用库。

| 物质/系统 | 主要来源与时间 | 比较可靠的作用 | 常参与的体验 | 不能误写成 |
|---|---|---|---|---|
| 谷氨酸 | 脑内局部，毫秒 | 快速兴奋、感觉和记忆回路传递 | 几乎所有认知和情绪 | 兴奋或愤怒专用物质 |
| GABA | 脑内局部，毫秒 | 回路抑制、限制过度兴奋 | 平静、恐惧抑制、动作控制都可能用到 | “放松激素” |
| 中枢去甲肾上腺素 NE | 蓝斑等，秒级 | 警觉、注意重置、意外变化后的学习率、威胁记忆 | 恐惧、惊讶、愤怒、焦虑、洞察前的注意集中 | 恐惧专用物质 |
| 外周肾上腺素 EPI | 肾上腺髓质，秒级 | 心率与心输出、供能、肌肉动员、颤抖 | 急性恐惧、愤怒、高激活兴奋 | 决定攻击或逃跑的单一开关 |
| CRH→ACTH→皮质醇 | 下丘脑—垂体—肾上腺轴，分钟级 | 维持压力供能、改变注意和记忆、延长应激状态 | 持续威胁、焦虑、无助、社会评价压力 | 一出现恐惧就瞬间增加的数值 |

| 乙酰胆碱 ACh | 基底前脑等，秒级 | 选择性注意、线索可靠性、预期不确定性下的更新 | 搜索、集中、学习、复杂规划 | 思考快乐本身 |
| 内源性大麻素 AEA/2-AG | 脑与外周，秒至分钟 | 压力调节、恢复、镇痛、食欲和恐惧消退相关过程 | 压力后的缓解、放松、部分愉悦 | 天然镇静剂的单一刻度 |
| 催产素 OXT | 下丘脑及外周，分钟级 | 社会线索显著性、依恋安全、亲密接近；强烈依赖对象和情境 | 依恋、照料、信任、群体内接近 | 对所有人无条件友善的“爱激素” |
| 加压素 AVP | 下丘脑等，分钟级 | 社会记忆、配偶联结、警戒、领地和地位行为；人类证据弱于动物 | 依恋、保护、社会警戒 | 攻击激素 |
| 睾酮 T | 性腺/肾上腺，分钟至小时 | 地位、竞争、趋近和对挑衅的条件性反应 | 愤怒、支配、胜利后的地位感可能相关 | 自动制造愤怒和暴力 |
| 炎症细胞因子 | 免疫系统，小时至天 | 疲劳、活动下降、快感减退、睡眠和“生病行为” | 长期压力后的低能量、倦怠 | 单次游戏失败的即时情绪 |
| 食欲素/组胺等唤醒系统 | 下丘脑/脑干，秒至分钟 | 清醒、能量动员、觅食与动机背景 | 兴奋、警觉、疲劳恢复 | 某一种具体情绪 |

## 四、按情绪观察“常见组合”

下列只描述典型方向，不代表每个人或每次事件都相同。

### 1. 急性恐惧

典型组合：

```text
中枢NE快速上升
+ 外周肾上腺素上升
+ 交感神经激活
+ 威胁持续时HPA/ACTH/皮质醇随后上升
+ ACh将注意集中到威胁线索
+ 内源性阿片在部分情况下提供应激镇痛
```

主要物理影响：

- 心率、呼吸和供能增加；
- 注意优先捕捉威胁；
- 非关键目标被压低；
- 反应更快，但复杂规划可能缩窄；
- 疼痛感可能暂时下降；
- 威胁记忆学习加强。

行为不是固定“逃跑”。结合可控性和距离，可以形成逃跑、冻结、躲藏、防御性攻击或求援。

### 2. 愤怒

典型组合：

```text
NE与肾上腺素上升
+ 行动动员和趋近倾向上升
+ 地位/挑衅情境下睾酮可能变化
+ 多巴胺支持追击和付出
± 皮质醇高度依赖控制感和情境
```

主要影响：

- 更愿意直接改变阻碍；
- 动作强度和坚持上升；
- 注意集中于责任对象；
- 风险容忍可能提高；
- 对惩罚的抑制减弱时，更容易报复。

实验中，愤怒诱发可与睾酮上升相关，但外源睾酮并不必然让普通人变得愤怒或暴力。应模拟“地位挑战与可反击性对睾酮/趋近系统的调节”，而不是写`testosterone -> aggression`。

### 3. 焦虑

典型组合：

```text
中等但持续的NE
+ HPA/皮质醇
+ ACh持续扫描不确定线索
+ 5-HT参与惩罚预测和行为抑制
```

主要影响：

- 扫描更多危险；
- 更重视低概率损失；
- 决策变慢或反复检查；
- 在没有可执行路径时回避；
- 高度持续后损害工作记忆和探索。

恐惧常针对较明确、较近的威胁；焦虑更容易由未来不确定性持续维持，但二者共享大量生理系统。

### 4. 愉悦、期待与满足

必须拆开：

```text
期待/追求：
  多巴胺预测与行动动力

实际“喜欢”：
  内源性阿片 + 内源性大麻素等享乐系统

安稳满足：
  较低交感/HPA + 安全与阿片/社会安慰信号
```

获得比预期更好的奖励会产生多巴胺式教学信号；真正享受奖励更依赖阿片等享乐机制。两者可以分离：玩家可能非常想刷奖励，却已经不怎么享受它。

### 5. 宽慰

宽慰是一个时间轨迹，不是某个固定浓度：

```text
原先威胁预期很高
→ 发现威胁解除
→ NE/交感激活开始下降
→ HPA较慢恢复
→ 安全、阿片和内源性大麻素调节增强
```

所以同样的最终安全状态，没有先前威胁就只是平静；先前高度恐惧后突然安全才是强烈宽慰。

### 6. 悲伤、失落与哀伤

目前没有可靠的“悲伤分泌物”。

可能参与：

- 急性失落中的HPA/皮质醇与自主神经变化；
- 奖赏趋近和行动动力下降；
- 社会分离与内源性阿片/依恋系统；
- 长期压力下的炎症、睡眠和疲劳变化；
- 催产素相关的寻求安慰和社会连接。

行为取决于“是否还能恢复”：

- 可恢复：求助、修复、反复回想；
- 不可恢复：降低追求、保存能量、重新组织目标；
- 高社会安全：接近他人寻求安慰；
- 高羞耻：反而回避他人。

### 7. 厌恶

没有唯一分泌物。常涉及：

- 岛叶和内感受；
- 5-HT相关的厌恶、恶心和惩罚性抑制；
- 副交感/胃肠反应；
- 污染情境下的免疫准备。

其行为核心是拒绝摄入、接触和靠近，不等同于恐惧的“预计会被攻击”。

### 8. 依恋、爱与社会安全

典型组合：

```text
催产素/加压素的社会与联结调节
+ 多巴胺赋予特定对象激励价值
+ 内源性阿片提供亲密、安全和安慰
```

催产素的作用高度依赖关系、群体和情境，可能增加对“自己人”的接近，也可能增强对社会线索的敏感，而不是让玩家普遍相信所有NPC。

### 9. 惊讶、发现与洞察

典型过程：

```text
预测被打破
→ NE提高意外变化后的警觉和学习率
→ ACh重新分配注意并更新线索可靠性
→ 如果结果优于预期或找到有价值路径，DA产生正向教学与行动动力
```

这直接连接EDecision中的“找到突破口”：

- NE/ACh负责“停下来，重新看这个问题”；
- 主观选项压缩和理解更新知识；
- DA只在这条新理解被认为有价值、提高成功前景时明显加入；
- 后续EVerify再决定该洞察的信心是否保留。

### 10. 骄傲、自我确认

没有骄傲专用分泌物。合理组合是：

- 成功结果带来的多巴胺和享乐反馈；
- 自我归因提高自我效能与Agency；
- 地位显著时可能涉及睾酮和社会奖赏系统；
- 社会认可时还会加入依恋/社会安全系统。

现有确认感C可以作为“自我归因成功”的认知输出，但以后不应直接再加一遍快乐；它应触发自我效能、趋近、地位和享乐系统的相应变化。

### 11. 羞耻、内疚与后悔

三者没有各自唯一物质，主要差别存在于认知对象：

- 后悔：我本可以选择另一条路；
- 内疚：我的行为伤害了别人，我还可能修复；
- 羞耻：我整体是坏的，并且暴露在他人评价中。

共享系统可能包括社会威胁下的NE/HPA、5-HT相关抑制和社会依恋系统。  
行为差别来自归因：

- 后悔促使重选；
- 内疚促使赔偿；
- 羞耻更容易促使隐藏或退出。

### 12. 挫败与无助

它们适合用同一生理系统的时间变化解释：

```text
初次受阻但仍有路：
  NE + DA行动动力 + 愤怒式趋近

连续失败，可信路径减少：
  Agency下降，HPA持续，搜索扩大或变乱

所有已知路径都被反驳：
  DA行动价值下降，持续压力与疲劳上升
  → 卡住、回避、放弃或寻求低风险恢复
```

所以掌控感不是一种分泌物，却决定同一套应激化学最终变成“我要再打一次”还是“我没办法了”。

## 五、第一版程序不应模拟“情绪值”，而应模拟生理轴

建议先建立九个可衰减状态，而不是几十种情绪：

```text
centralAlerting       中枢NE：警觉、意外、学习重置
bodyMobilization      肾上腺素/交感：身体动员
sustainedStress       HPA/皮质醇：持续压力
rewardDrive           DA：追求、行动动力、预测误差
hedonicSafety         阿片/安全：享乐、镇痛、安慰
punishmentInhibition  5-HT功能投影：惩罚下的克制
attentionalPrecision  ACh：注意与线索可靠性
socialBonding         OXT/AVP/阿片：依恋与社会安全
recoveryBuffer        内源性大麻素/副交感恢复
```

慢变量以后再加：

```text
statusDrive           睾酮/地位趋近
inflammatoryFatigue   慢性炎症和倦怠
```

谷氨酸/GABA第一版不单独做全局值，因为它们遍布所有回路。只有将来模拟惊厥、镇静、药物或睡眠时才值得提升到玩家状态层。

## 六、统一动力学

每个生理轴都需要基线、释放、衰减和个体敏感度：

```text
下一时刻浓度 =
  当前浓度
  + 当前事件释放量 × 玩家敏感度
  - 回归基线的清除量
  + 其他系统的调节
```

程序形式：

```text
dx_i / dt =
  release_i(appraisal, perceivedSignal)
  - (x_i - baseline_i) / tau_i
  + interaction_i(otherStates)
```

输入不能是`emotion = fear`，而应是玩家已经拥有的认知量：

```text
threatMagnitude       预计会受多大伤害
threatImmediacy       威胁有多近
controllability       我能否影响它
escapeAvailability    有没有逃跑路径
obstruction           目标被阻碍多少
blame                 我把责任归给谁
rewardPredictionError 实际比预期好/差多少
rewardConsumption     当前实际享受多少
expectedUncertainty   已知环境有多随机
unexpectedChange      世界是否突然换了规则
socialSafety          对象是否可信和亲密
statusChallenge       是否涉及支配、尊严和地位
pain                   身体/角色损伤
```

## 七、生理状态如何真正改变Agent行为

不要先解码成情绪名字再写固定行为树。生理轴直接修改：

1. **注意**
   - NE高：优先意外和威胁；
   - ACh高：维持任务线索、更新可靠性；
   - 高压力：缩窄到最显著风险。

2. **学习**
   - DA预测误差：更新奖励与行为价值；
   - NE：环境突然变化时提高整体更新率；
   - ACh：在已知噪声中调整线索权重；
   - EVerify：决定具体因果知识更新什么。

3. **动作**
   - 肾上腺素/交感高：反应快、动作强、休息意愿下降；
   - 高DA：更愿意付出和追击；
   - 高5-HT功能：更容易被惩罚预期抑制；
   - 高阿片/内源性大麻素：疼痛影响减弱、恢复增强。

4. **规划**
   - 中等NE/ACh：更容易找到突破口；
   - 过高NE/HPA：候选空间缩窄、复杂规划下降；
   - DA低：即使知道方案也不愿意付出；
   - Agency低：把高成本方案视为不可行。

5. **社会选择**
   - OXT/联结系统高：更重视亲密对象和关系修复；
   - 地位系统高：更重视挑战、认可和尊严；
   - 羞耻认知+高社会威胁：可能回避，而不是求助。

6. **疼痛与疲劳**
   - 阿片/内源性大麻素提高短期耐受；
   - 持续HPA和炎症提高长期疲劳、降低探索；
   - 生理恢复需要时间，不能在事件结束的一帧全部清零。

## 八、与现有R/A/C/EVerify的连接方式

现有模块可以保留，但以后应从“直接情绪加分”逐渐改成“认知评价与释放触发器”。

```text
R：
  实际得到什么
  → rewardConsumption / pain / progress
  → DA、阿片、应激和恢复系统

A：
  实际与预期差
  → rewardPredictionError / unexpectedChange
  → DA和NE学习信号

C：
  主动调整后的自我确认
  → 自我效能、Agency、地位趋近
  → DA/享乐/地位系统的条件性变化

EVerify：
  因果链支持或反驳
  → 具体知识和方案自信
  → ACh/NE学习、DA路径价值、Agency重算

EDecision：
  搜索、洞察和自我选择
  → 注意负荷、学习和行动准备
  → 不直接等于分泌快乐物质
```

正式迁移时必须避免双算：如果R已经通过化学系统产生了享乐和行动动力，就不能再把旧R数值直接加进最终情绪一次。

## 九、两个最能说明模型的例子

### 例1：同一个Boss突然冲过来

玩家A认为自己有盾反：

```text
威胁高、时间近、可控性高
→ NE和肾上腺素上升
→ DA支持执行已知反制
→ 行为：集中注意、迎击
→ 主观可能是紧张和兴奋
```

玩家B不知道任何反制：

```text
威胁高、时间近、可控性低、无逃路
→ 同样NE和肾上腺素上升
→ HPA持续增强
→ 复杂规划缩窄
→ 行为：冻结、乱按、逃跑
→ 主观更接近恐惧
```

不是Boss分别分泌了“兴奋素”和“恐惧素”，而是相同身体动员被不同控制认知组织成不同状态。

### 例2：玩家发现Boss可能弱电

```text
意外线索
→ NE/ACh提高注意和更新率
→ 候选打法从8种压缩到2种
→ 方案自信和Agency上升
→ 若这条路看起来能提高成功率，DA行动动力上升
→ 玩家主动试电系打法
```

如果随后EVerify连续反驳：

```text
弱电假设信心下降
→ DA路径价值下降
→ Agency取决于是否还有其他路径
→ 有替代方案：转向新实验
→ 没有替代方案：持续HPA与卡住感增加
```

这正是“化学真正影响行为”，而不是把“洞察爽感+2”直接写进情绪。

## 十、验证方案

第一轮至少做以下确定性case：

1. 同一威胁，高控制与低控制分别产生迎击和逃避。
2. 同样高激活，奖励挑战产生兴奋，伤害威胁产生恐惧。
3. 突然规则变化提高NE学习率，稳定随机噪声主要提高ACh线索更新。
4. 意外奖励先产生DA预测误差，实际享受再产生阿片反馈。
5. 高“想要”但长期重复刷取：DA驱动仍高，阿片享乐逐渐低。
6. 威胁解除后NE先降、皮质醇后降，形成宽慰轨迹。
7. 强反证后原样重试：路径DA价值与Agency下降，持续压力上升。
8. 输掉战斗但确认局部机制：R负，知识和相关Agency上升。
9. 随机胜利但不知道原因：R/享乐正，因果自信不增加。
10. 被NPC伤害：亲密对象、敌人和陌生人触发不同社会归因。
11. 同样失败：高地位敏感玩家趋向愤怒，低控制玩家趋向恐惧/回避。
12. 长期连续压力逐渐产生疲劳，而不是每场结束瞬间恢复。

先验证行为方向和时间顺序，不拟合真实人体浓度。

## 十一、研究依据与证据边界

较可靠的项目约束：

- 人类急性压力中，去甲肾上腺素和ACTH反应快于皮质醇，IL-6等更慢；
- 恐惧表现与较高心血管/HPA反应相关，而愤怒/厌恶在同一压力任务中可呈不同模式；
- 多巴胺神经元可编码奖励预测误差，不等于主观快乐；
- 人类药理研究支持内源性阿片参与奖励享乐；
- 降低血清素合成可削弱惩罚诱发的行为抑制；
- 去甲肾上腺素、乙酰胆碱和多巴胺对不确定性更新有可区分作用；
- 催产素与依恋安全和社会接近有关，但受个体和情境调节；
- 急性压力可提高循环内源性大麻素相关信号；
- 睾酮对挑衅和地位行为的影响是条件性的，并不自动导致愤怒或攻击。

仍不能声称：

- 已经知道每种情绪的唯一化学配方；
- 外周血液浓度等于脑内特定回路释放；
- 一个全局多巴胺值能表达不同脑区和受体；
- 当前九个生理轴就是人脑真实最小维度；
- 暂定动力学参数可以直接解释真人。
