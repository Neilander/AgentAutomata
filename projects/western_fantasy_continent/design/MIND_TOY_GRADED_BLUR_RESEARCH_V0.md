# MindToy 地图信息渐进模糊研究 V0

## 结论

人脑对复杂地图的模糊不是均匀随机删除，也不是简单把所有字段乘一个精度系数。至少需要区分四种现象：

1. 未进入注意：低优先级或意外信息可能完全没有形成可用表征。
2. 群体概括：相似对象被编码成数量范围、平均特征、密度、主要类别和空间中心，而不是独立个体列表。
3. 精度下降：同时维持的对象越多，单个对象的颜色、位置、数量等连续属性越不精确。
4. 绑定错误：对象类型、属性和位置仍被记住，但可能错误组合，例如把东路弓兵记到北路盾兵的位置。

空间记忆还会使用区域和地标类别进行重建。精细位置变弱后，回忆会向“城门附近”“高地中心”等区域原型偏移。因此地图外围更适合保存区域级关系和威胁概况，而不是给每个单位加独立高斯噪声。

## 研究依据

- Ariely 的集合视觉研究发现，观察者能较准确记住一组相似对象的平均与范围，却不擅长识别其中的单个成员。这支持把远处士兵压成群体摘要。<https://journals.sagepub.com/doi/pdf/10.1111/1467-9280.00327?download=true>
- Alvarez 与 Oliva 发现，注意焦点之外仍能保留对象集合的中心位置等摘要特征。<https://pmc.ncbi.nlm.nih.gov/articles/PMC2587223/>
- Brady 与 Alvarez 发现，个体记忆会被所在群体和整个集合的平均值系统性拉动，说明记忆是个体层与群体层共同构造，而非独立保存每个对象。<https://journals.sagepub.com/doi/10.1177/0956797610397956>
- Bays 等的实验支持共享资源模型：对象数量增加时，单个对象的回忆精度连续下降；对象特征与位置还会出现错误绑定。<https://pmc.ncbi.nlm.nih.gov/articles/PMC3118422/>、<https://pmc.ncbi.nlm.nih.gov/articles/PMC3119435/>
- Huttenlocher、Hedges 与 Duncan 的空间类别调整模型认为，位置同时以细粒度值和类别保存；细节不精确时，会结合区域原型重建。<https://eric.ed.gov/?id=EJ435132>
- Simons 与 Chabris 的非注意盲视实验说明，未获得注意的显眼事件可能根本没有进入可报告意识，而不仅是变模糊。<https://doi.org/10.1068/p281059>
- Oliva 与 Torralba 的场景 gist 工作说明，人能快速获得场景的整体意义、布局、拥挤度和少量关键对象，而无需先识别所有独立对象。<https://www.sciencedirect.com/science/article/pii/S0079612306550022>

## 地图士兵的合理模糊方式

假设地图上有多个位置、不同类型敌军，玩家当前关注东门。

### 当前焦点：个体级

```text
东门：
- 2名盾兵
- 1名弓兵
- 弓兵站在高地后方
- 盾兵挡住入口
```

当前计划需要这些信息，因此保留个体、类型、局部位置和关键关系。

### 焦点近邻：小组级

```text
东门北侧：
- 大约3~4名敌人
- 主要是远程单位
- 似乎有一个保护单位
- 位置在北侧高地附近
```

个体身份消失，保留数量范围、类型分布、主要威胁和地标位置。

### 外围区域：gist级

```text
北路：敌人比较密集，远程压力偏高。
西侧：兵力较少，似乎可以绕行。
```

只保留区域占领、密度、威胁方向和可通行性。

### 未进入注意：不可用

地图角落新增一名不显眼的侦察兵，若与当前目标无关且没有强信号，玩家可能完全没注意到。它不应以“低清晰度侦察兵”进入 MindToy，而应暂时不存在于玩家主观模型。

### 可能的记忆错误

```text
- 数量误差：记成“约4人”，实际为3人。
- 均值偏移：一个精英混在普通兵中，记成“这队整体稍强”，但忘记精英个体。
- 位置类别化：记得敌人在“高地附近”，精确格子向高地中心偏移。
- 绑定交换：记得有弓兵和盾兵，也记得东门与北路两个位置，但把弓兵放错区域。
- 完全漏掉：没有注意到侧翼侦察兵。
```

## 推荐的数据结构

不要对完整单位列表统一加噪声。先按当前目标与空间结构形成多层表示：

```text
MapMindRepresentation {
  focusInstances: [
    // 当前思路直接使用的少量单位，个体级
  ],
  nearbyGroups: [
    // 数量范围、类型分布、中心位置、主要关系
  ],
  peripheralGist: [
    // 区域密度、威胁等级、主要方向、是否可通行
  ],
  unattended: [
    // 不传给MindToy；只保留在游戏真相侧
  ]
}
```

每个主观对象附带：

```text
source          观察、旧记忆或推断
resolution      instance | group | gist
confidence      对当前表征的信心
recency         最近何时关注
focusRelevance  与当前idea的关系
bindingRisk     类型与位置记串的风险
```

## 生成过程

```text
1. 目标与当前idea决定注意中心。
2. 显眼、相关、最近使用的信息获得更高资源；加入少量有偏随机性，避免完全机械。
3. 焦点内保留个体。
4. 空间相近、类型相似的非焦点单位聚合成群体摘要。
5. 更远区域只保留场景gist和地标关系。
6. 超出资源的信息不进入ActiveMindToy。
7. 随时间降低个体精度，并增加向群体均值、区域原型偏移和绑定错误的概率。
8. 玩家重新观察某区域时，从画面重新编码，而不是凭空恢复旧精确记忆。
```

随机性只用于资源竞争、噪声和偶发漏看；它必须受到目标相关度、显眼度、空间聚类、相似性和最近使用的强烈偏置。不能随机遮掉30%的单位。

## 第一版最小实现

第一版只实现三层输出和一种错误即可：

1. `instance`：焦点内精确单位。
2. `group`：近邻单位的数量范围、主要类型、平均威胁和中心区域。
3. `gist`：外围区域的兵力密度、主要威胁和方向。
4. 绑定错误：只在多个相似群体、工作记忆负荷较高时，小概率交换单位类型与区域。

暂时不建神经机制，不拟合精确人类参数。先用同一地图改变焦点，验证输出是否出现合理的个体→群体→gist变化，以及重新观察能否恢复局部精度。
