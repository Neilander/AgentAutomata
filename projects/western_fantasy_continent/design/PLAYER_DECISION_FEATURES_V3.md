# 玩家决策四核心特征与Aha二层模型 V3

- 日期：2026-07-22
- 状态：当前已对齐定义；完成隔离程序验证，尚未接入正式玩家
- 取代：`PLAYER_DECISION_FEATURES_V2.md` 中把Insight作为核心特征，以及把突破步骤人为排除出QDecision的设计

## 当前结构

一次决策先产生四个核心特征：

```text
EDecision
QDecision
Ordering
ChoiceAuthorship
```

它们仍然只是特征，不是快乐、疲劳或奖励。`AhaMoment`不属于核心特征，而是读取认知状态变化后产生的二层体验。

```text
决策过程
  → 四个核心特征
  → 结合玩家偏好、能力与状态的二层反馈

困惑状态突然大幅消解
  → 二层AhaMoment
```

## 1. EDecision：主动思考累计剂量

它回答：

> 玩家为了作出这次决定，实际投入了多少主动、受控的思考？

隔离版使用：

```text
EDecision = Σ（主动思考持续量 × 主动控制强度）
```

它不判断思考有没有用，也不因为问题客观复杂、结果正确或Agent文字很多而自动提高。累计剂量不在特征层封顶，玩家喜欢多少、何时疲劳属于二层模型。

## 2. QDecision：复杂问题解决程度

它回答：

> 玩家通过这些思考，让原本复杂、未知或互相冲突的问题得到了解决吗？

典型内容包括发现真正的问题、理解原因、排除错误解释、解决约束冲突、找到可行办法。隔离版把它表示为每单位主动思考带来的主观复杂度消解：

```text
QDecision = 加权平均（每段思考解决的复杂度）
```

它允许为负：玩家越想越矛盾、越无法行动时，复杂度不是被解决，而是在增加。

QDecision不读取战后输赢。一个有依据、确实缩小问题、还能被验证的假设，即使后来被EVerify证伪，战前Q仍可以为正；证伪之后形成的新认知会影响下一次决策。

## 3. Ordering：增序程度

它回答：

> 玩家通过思考，把多少原本混乱、无序的内容整理成了清晰结构？

Ordering不是“是否解决复杂问题”，而是“是否建立秩序”。秩序可以表现为：

- 时间顺序：先控制、再破防、最后输出；
- 空间关系：站位、路线、保护关系；
- 依赖关系：必须先拿钥匙，才能开门；
- 优先级：先处理谁、资源先给谁；
- 职责组织：谁控制、谁击杀、谁保护。

这些是估算Ordering的证据，不升级为更多正式特征。隔离版使用每单位思考带来的结构增益；越安排越乱时允许为负。

Q与Ordering可以独立变化：

- 发现Boss弱点但没有制定行动顺序：高Q、低Ordering；
- 弱点早已知道，只重新排出技能顺序：低Q、高Ordering；
- 既解决机制冲突又排出完整行动链：二者都高。

## 4. ChoiceAuthorship：自我选择程度

它回答：

> 在确实有意义的不同选项之间，这个选择有多大程度表达了玩家自己的意愿？

隔离版要求：

- 至少存在两个有意义选项；
- 选项确实不同；
- 玩家理解自己放弃了什么；
- 选择是自愿的；
- 选择能够表达玩家偏好。

系统强迫、只有一个按钮或多个实际相同的伪选项都不能产生高值。ChoiceAuthorship不要求存在客观最优解，也不等于选择正确。

## AhaMoment：二层的豁然开朗

AhaMoment回答：

> 此前积累的很多困惑，是否在很短的瞬间被真正理解并大量解决？

发现Boss关键弱点和尤里卡时刻是同一种现象，只要这个发现把此前多个困惑突然串成了一个清晰解释。

当前隔离版只使用三个核心条件：

```text
AhaMoment
= 困惑消解量
× 瞬间性
× 真正理解程度
```

其中瞬间性由消解所用时间推导。它能区分：

- 长期困惑后突然理解Boss弱点：高Aha；
- 得到同样结论但经过多次实验逐渐学会：低Aha；
- 教程开局直接告知、此前没有多少困惑：低Aha；
- 看到显眼线索但困惑没有减少：低Aha；
- 答案出现但玩家没有理解：低Aha。

Aha不是第五个核心特征，也不是另一份Q。Q记录解决复杂问题的程度；Aha只把其中“此前困惑突然大面积消失”的变化翻译为特殊二层体验。以后不能把同一份问题解决量同时当作普通Q奖励和Aha奖励简单相加。

Ordering同样可以触发Aha：如果玩家突然看懂多个混乱步骤的正确先后关系，困惑会瞬间下降，也会产生豁然开朗。

## 隔离程序接口

核心接口严格只输出：

```js
{
  EDecision,
  QDecision,
  Ordering,
  ChoiceAuthorship
}
```

二层接口另外输出：

```js
{
  AhaMoment
}
```

胜负、奖励、情绪和玩家偏好不能反向改变四个核心特征。Aha接口也不写回Q或Ordering。

## 隔离验证结果

隔离程序：

- `experiments/player_decision_features_v2/decision-feature-model-v2.js`
- `experiments/player_decision_features_v2/test-decision-feature-model-v2.js`

已通过16个核心案例和6个Aha案例：

- 复杂Boss因果问题：`E=6.6、Q=0.7258、Ordering=0.05`。
- 已知任务只排时间顺序：`E=4.2、Q=0.05、Ordering=0.825`。
- 同时解题并规划团队行动链：`Q=0.7、Ordering=0.725`。
- 已知角色能力只排空间站位：`Q=0.075、Ordering=0.775`。
- 强化方向已知只排资源优先级：`Q=0.1、Ordering=0.825`。
- 高投入死循环：`E=9、Q=-0.45、Ordering=-0.25`。
- 发现Boss弱点但未规划：`Q=0.95、Ordering=0`。
- 已知弱点只排技能顺序：`Q=0.08、Ordering=0.86`。
- 背包自我选择：`ChoiceAuthorship=0.9`；强迫与伪选项均为`0.05`。
- Boss尤里卡：`Aha=0.6957`；同幅度逐渐学会仅`0.1143`。
- Ordering豁然开朗：`Aha=0.5938`。

这些结果证明定义可以在隔离夹具中被一致区分，不证明真实Agent痕迹已经能够自动、客观地产生`resolvedComplexity`和`orderingGain`。真实提取仍是下一阶段。
