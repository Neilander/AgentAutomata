# 职业、魔法学派与技能来源框架 v1

- 状态：方向已确认，职业与学派名单仍可继续调整
- 范围：角色战斗身份、技能来源、套装适配范围
- 不包含：最终职业数量、完整技能表、掉率与平衡数值

## 1. 核心结论

角色的物理战斗方式由职业决定，魔法技能由学派决定。角色必须拥有职业，但不一定掌握魔法学派。

```text
角色战斗内容
= 职业提供的身体、武器、站位与物理技能
+ 可选魔法学派提供的法术
+ 少量角色专属技能
```

不把所有角色强制归入学派。一个普通盾兵可以完全依靠盾兵技能完成战斗，不需要为了装备系统额外拥有魔法身份。

## 2. 三种技能来源

### 2.1 职业技能

职业描述角色直观的战斗方式：使用什么武器、站在哪里、怎样移动和怎样进行物理攻击。

- 职业技能与职业绑定。
- 盾兵不能因为换了一套装备就自动学会骑兵冲锋。
- 职业套装可以直接强化该职业的核心动作，例如格挡、拦截、冲锋和招架。
- 职业名称应尽量让玩家不读技能说明也能猜到大致表现。

### 2.2 魔法学派技能

学派描述法术遵循的规则，不等同于角色职业。

- 学派是可选层，纯物理角色可以没有学派。
- 同一学派的法术可以出现在不同职业身上。
- 学派套装读取技能的学派标签，而不读取具体英雄名字。
- 同一套学派装备应允许不同职业形成不同用法，但不保证每个只会一个相关法术的角色都适合穿满六件。

### 2.3 角色专属技能

少量英雄可以拥有无法被公共职业池或学派池完全替代的能力，用于保留人物辨识度。

- 专属技能不应成为所有角色的标准配置。
- 专属技能默认不作为大批套装的唯一触发条件。
- 可以由特殊散件或专属遗物改变，但避免把普通套装退化成英雄专武。

## 3. 角色的常见技能构成

以下是内容制作模板，不是所有角色必须遵守的硬槽位限制：

- **纯武职**：主要或全部使用职业技能，不掌握学派。
- **魔武混合**：职业技能与一个学派的法术混用。
- **施法者**：职业提供施法方式和少量职业动作，大部分主动能力来自学派。
- **特殊英雄**：在以上结构中加入一个角色专属技能。

## 4. 职业候选池

### 4.1 常规物理职业

| 职业 | 武器与位置 | 主要职业动作 |
| --- | --- | --- |
| 盾兵 | 盾牌、前排 | 格挡、拦截、嘲讽、盾击、受击反击 |
| 长枪兵 | 长枪、中前排 | 攻击远一格、阻止冲锋、穿刺、维持阵线 |
| 骑兵 | 骑枪、机动前排 | 冲锋、穿过阵线、脱离后再次突入 |
| 重武器战士 | 大剑、重斧或战锤、前排 | 顺劈、破甲、击退、压制多个前排 |
| 剑士 | 单手剑、中前排 | 招架、连续斩击、点名决斗、寻找空隙 |
| 狂战士 | 双斧或巨斧、前排 | 自伤、低血强化、吸血、濒死反扑 |
| 弓箭手 | 长弓、后排 | 快速射击、齐射、穿透箭、远程压制 |
| 猎人 | 弓弩与陷阱、后排 | 标记、陷阱、追踪、针对大型敌人 |
| 刺客 | 匕首、机动位置 | 切入后排、隐匿、低血处决、脱离 |

`重武器战士`替代抽象的`破阵兵`名称。它直接说明角色拿重武器进行范围攻击和破甲，不要求玩家先理解“破阵”术语。

### 4.2 特殊战斗职业

| 职业 | 职业核心 |
| --- | --- |
| 炼金师 | 投掷瓶剂、混合异常、准备消耗品 |
| 吟游诗人 | 调整节奏、维持增益、触发队友连携 |
| 法师 | 蓄力、法术连发、扩大范围、调整施法节奏 |
| 祭司 | 祈祷、引导、代伤、把效果分享给队友 |
| 术士 | 契约、自我献祭、延长负面效果、窃取生命 |

法师、祭司和术士仍然可以是职业，但它们决定的是“如何施法”。火焰、寒霜、治疗、毒素等具体法术内容仍由学派提供。

### 4.3 稀有职业

龙骑兵不作为普通骑兵的通用名称，而作为具有飞行、俯冲、龙息或特殊坐骑规则的稀有职业。以后还可以存在狮鹫骑兵、飞马骑士等同级特殊职业。

## 5. 魔法学派候选池

| 学派 | 核心法术语法 |
| --- | --- |
| 炼狱 | 火焰、自我献祭、灵魂燃烧、危险爆发 |
| 自然 | 植物、毒素、野兽、恢复、生长与传播 |
| 寒霜 | 减速、冻结、冰甲、碎裂 |
| 圣光 | 治疗、净化、祝福、审判 |
| 暗影 | 诅咒、生命窃取、幻象、灵魂伤害 |
| 风暴 | 雷电连锁、加速、击退、连续施法 |
| 奥术 | 法术复制、空间移动、能量护盾、改变冷却 |

角色通常掌握零至一个学派。双学派应该是少数高级角色的辨识点，不能成为默认配置。

## 6. 当前 Matrix 内容的迁移方向

当前共享战斗资产拥有 10 个职业底盘、17 个标准阵容以及 43 种实际技能组合。它们是可复用的机制资产，但现有职业边界过宽。

- 铁壁、嘲讽和反击骑士迁移为盾兵职业内容。
- 冲锋骑士迁移为骑兵职业内容。
- 顺劈、破甲和压线战士迁移为重武器战士职业内容。
- 点名与单挑战士迁移为剑士职业内容。
- 标记连射偏向弓箭手职业内容。
- 陷阱、追踪和大型敌人针对偏向猎人职业内容。
- 火焰技能归入炼狱学派。
- 冰冻与减速法术归入寒霜学派。
- 毒素、生长与自然恢复归入自然学派。
- 治疗、净化和祝福归入圣光学派。
- 诅咒、窃取和灵魂攻击归入暗影学派。
- 吟游诗人的节奏和连携优先视为职业技能，不强制包装成魔法学派。

迁移时应复用已经验证的实际战斗效果，不因重命名重新写一套简化战斗。

## 7. 装备与套装分类

装备构筑至少允许四种来源并存：

1. **职业套装**：强化盾兵、骑兵、猎人等职业动作，适配范围窄但可以更强地改变具体战斗方式。
2. **学派套装**：强化某一学派法术，能够跨职业使用，是主要的横向复用层。
3. **通用套装**：读取普攻、护盾、持续伤害、暴击等行为，不检查职业或学派。
4. **特殊散件**：改变单条战斗规则，负责补足六件套与三件套剩余的装备位置。

长期装备组合仍按八个装备部位考虑，目标形状包括：

- 六件套 + 两件散件；
- 三件套 + 三件套 + 两件散件；
- 三件套 + 五件散件；
- 八件散件。

普通装备仍应保持易读。复杂的规则改变集中在有明确名称和目标的套装、特殊散件与遗物上，不能让每件普通掉落都变成一段规则说明。

## 8. 首个六件套候选：繁生之环

### 8.1 定位

- 类型：自然学派六件套。
- 适用对象：拥有多次自然法术施放能力的角色。
- 核心体验：播种、继续灌注、成熟绽放、有限传播。
- 当前状态：用于验证套装表达和跨职业适配，名称与数值均未冻结。

### 8.2 三件效果：播种

自然法术影响一个当前没有种子的单位时，为其种下一枚持续 6 秒的种子。同一目标最多存在一枚来自该角色的种子。

种子存在期间，该角色再次用自然法术影响该目标，会增加 1 点生长，最多 3 点。

种子在持续时间结束时绽放：

- 友方目标：每点生长恢复其 4% 最大生命值。
- 敌方目标：每点生长受到相当于施法者 55% 法术强度的自然伤害。

### 8.3 六件效果：繁生

种子达到 3 点生长时会立即绽放，不再等待持续时间结束，并向距离最近的同阵营单位传播一枚只有 1 点生长的新种子。

传播产生的种子可以继续被自然法术培养，但不能再次传播，防止无限连锁。

同一套装持有者的立即绽放传播每 6 秒最多触发一次。界面必须显示种子剩余时间和当前生长点数。

### 8.4 不同职业的用法

- **自然祭司**：在受伤队友身上培养种子，形成延迟群体恢复。
- **自然术士**：围绕一个高威胁敌人反复施毒，成熟后向其他敌人传播进攻种子。
- **自然炼金师**：利用多次瓶剂快速催熟，但需要决定集中培养一个目标还是铺开多个种子。
- **只会一个自然法术的盾兵**：可以使用三件效果获得偶发收益，但很难稳定催熟，因此通常不值得穿满六件。

### 8.5 设计价值

这套装备不是给某个英雄加专属倍率，而是强化自然学派“效果会生长并传播”的共同语法。不同职业共享同一套规则，但因技能频率、目标类型和队伍职责不同，实际构筑与战斗表现不同。

### 8.6 风险与验证点

- 友方恢复与敌方伤害不能同时强到让它成为所有自然角色的唯一答案。
- 高频群体法术可能过快催熟，需要限制同一技能是否能对同一目标重复计数。
- 传播必须有清晰动画和禁止递归的规则提示。
- 需要用自然祭司、自然术士、自然炼金师和只有一个自然法术的混合角色分别测试，确认适配范围宽但仍存在效率差异。

## 9. 尚未冻结

- 最终职业数量，以及长枪兵、弓箭手和猎人是否都需要在首个版本独立存在。
- 每个职业和学派的正式技能池大小。
- 角色能够掌握几个学派，以及双学派的获得方式。
- 六件套是否由八个可能部位中的任意六件组成。
- 三件套是否拥有独立品类，还是部分六件套也提供三件阶段效果。
- 职业套装、学派套装、通用套装和散件的实际掉落比例。
- `繁生之环`的名称、数值、传播距离、冷却及最终视觉表现。
