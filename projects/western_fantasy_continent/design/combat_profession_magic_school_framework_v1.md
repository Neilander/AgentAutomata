# 职业、魔法学派与技能来源框架 v1

- 状态：方向已确认，职业与学派名单仍可调整
- 范围：角色战斗身份、技能来源、套装适配范围

## 核心框架

```text
角色战斗内容
= 职业提供的身体、武器、站位与物理技能
+ 可选魔法学派提供的法术
+ 少量角色专属技能
```

角色必须拥有职业，但不一定掌握魔法学派。职业回答“怎样进行物理战斗”，学派回答“法术遵循什么规则”。学派套装读取技能的学派标签，不读取具体英雄名字；普通盾兵不需要为了套装系统被强行包装成法师。

## 职业候选

| 职业 | 主要动作 |
| --- | --- |
| 盾兵 | 格挡、拦截、嘲讽、盾击、反击 |
| 长枪兵 | 远一格穿刺、阻止冲锋、维持阵线 |
| 骑兵 | 冲锋、穿阵、脱离后再次突入 |
| 重武器战士 | 顺劈、破甲、击退、压制前排 |
| 剑士 | 招架、连续斩击、点名决斗 |
| 狂战士 | 自伤、低血强化、吸血、濒死反扑 |
| 弓箭手 | 快速射击、齐射、穿透、压制 |
| 猎人 | 标记、陷阱、追踪、针对大型敌人 |
| 刺客 | 切后排、隐匿、处决、脱离 |

特殊战斗职业包括炼金师、吟游诗人、法师、祭司和术士。法师、祭司、术士仍然决定“如何施法”，火焰、寒霜、治疗、毒素等具体内容由学派提供。龙骑兵属于稀有职业，不是普通骑兵的改名。

| 炼狱 | 火焰、自我献祭、灵魂燃烧、危险爆发 |

| 圣光 | 治疗、净化、祝福、审判 |

角色通常掌握零至一个学派。双学派是少数高级角色的辨识点。

## 装备与套装分类

1. 职业套装：强化格挡、冲锋、陷阱等职业动作。
2. 学派套装：强化一个学派的共同语法，跨职业复用。
3. 通用套装：读取普攻、护盾、持续伤害、暴击等行为。
4. 特殊散件：改变单条战斗规则，补足三件套和六件套之外的部位。

八部位的长期组合目标包括：六件套加两件散件、三件套加三件套加两件散件、三件套加五件散件，以及八件散件。普通装备保持易读，复杂规则集中在套装和特殊散件。

## 首个套装：繁生之环

- 类型：自然学派套装。
- 核心体验：播种、继续灌注、成熟绽放、有限传播。

### 三件效果：播种

自然法术第一次影响某单位时，种下一枚持续 6 秒、初始 1 点生长的种子。同一施法者在同一目标上最多一枚种子；同一次技能即使有多个效果，也只对该目标计数一次。

该施法者之后用另一次自然法术影响目标时，种子增加 1 点生长，最多 3 点，并刷新持续时间。持续时间结束时绽放：

- 友方目标：每点生长恢复目标 4% 最大生命值。
- 敌方目标：每点生长造成施法者 55% 法术强度的自然伤害。

### 六件效果：繁生

种子达到 3 点生长时立即绽放，并向距离最近的同阵营单位传播一枚 1 点生长的新种子。传播种子可以继续培养和绽放，但不能再次传播；同一套装持有者的传播有 6 秒冷却。战斗界面必须显示种子剩余时间与生长点数。

### 跨职业用法

- 自然祭司：在受伤友军身上培养，形成延迟恢复。
- 自然术士：围绕高威胁敌人施毒，成熟后向其他敌人传播。
- 自然炼金师：用多次瓶剂快速催熟，在集中培养与广泛播种之间取舍。
- 只有一个自然法术的物理职业：能获得三件套偶发收益，但通常难以稳定催熟六件套。
