# 职业、魔法学派与技能来源框架 v1

- 状态：方向已确认，职业与学派名单仍可调整
- 范围：角色战斗身份、技能来源、套装适配范围

## 核心框架

```text
角色战斗内容
= 职业提供的身体、武器、站位与物理技能
+ 可选魔法学派提供的法术
+ 少量角色专属技能
```

角色必须拥有职业，但不一定掌握魔法学派。职业回答“怎样进行物理战斗”，学派回答“法术遵循什么规则”。学派套装读取技能的学派标签，不读取具体英雄名字；普通盾兵不需要为了套装系统被强行包装成法师。

## 一级战斗定位

当前收束为八个玩家容易理解的大定位：近战兵、盾兵、弓兵、骑兵、奇谋兵、护佑者、魔法师、战斗辅助。大定位回答“这个单位在战场上负责什么”，具体职业回答“它用什么方式完成”。

- 近战兵是基础战斗主体，包括普通战士、剑士、重武器战士、狂战士等；不是只有剑士。
- 盾兵阻挡推进并保护队友。
- 弓兵利用前线之外的空间增加输出并狙杀关键单位。
- 骑兵依靠机动抓住机会并突击敌阵。
- 奇谋兵通过隐蔽、伏击、破坏和欺骗绕过正常正面对抗。
- 护佑者依靠治疗、护盾、净化和救命保护队友。
- 魔法师是行动迟缓、害怕干扰但拥有远程范围毁灭能力的炮台。
- 战斗辅助通过削弱、强化、建筑和战场条件帮助队伍取胜。

当前按八大定位设计的首套装备与共享关键词，记录在`combat_role_set_framework_v0.md`。

## 职业候选

| 职业 | 主要动作 |
| --- | --- |
| 盾兵 | 格挡、拦截、嘲讽、盾击、反击 |
| 长枪兵 | 远一格穿刺、阻止冲锋、维持阵线 |
| 骑兵 | 冲锋、穿阵、脱离后再次突入 |
| 重武器战士 | 顺劈、破甲、击退、压制前排 |
| 剑士 | 招架、连续斩击、点名决斗 |
| 狂战士 | 自伤、低血强化、吸血、濒死反扑 |
| 弓箭手 | 稳定直射、齐射、穿透、压制与阵地输出 |
| 游侠 | 隐蔽、规避、高机动射击与在复杂环境中转移阵位 |
| 猎人 | 陷阱、追踪、守备阵地与针对大型敌人 |
| 刺客 | 切后排、隐匿、处决、脱离 |

特殊战斗职业包括炼金师、吟游诗人、法师、祭司和术士。法师、祭司、术士仍然决定“如何施法”，火焰、寒霜、治疗、毒素等具体内容由学派提供。龙骑兵属于稀有职业，不是普通骑兵的改名。

### 弓系职业族

弓箭手、游侠和猎人属于同一个“弓系职业族”。职业族共享远距离、狙杀、瞄准与蓄力等弓术语法；具体职业回答“怎样在战场上维持这些优势”。同一件弓系套装应读取瞄准、锁定、直射或抛射等共享动作，而不是硬编码某个职业名。

| 职业 | 共同目标的实现方式 | 当前定位 |
| --- | --- | --- |
| 弓箭手 | 依靠稳定射击持续完成瞄准和锁定 | 最经典、最稳定的弓系基准职业，适合正规军阵与持续远程输出 |
| 游侠 | 依靠隐蔽、规避控制和高机动保持射击不中断 | 灵活的精锐远程职业；未来存在地形、掩体和非对冲战场后，能主动转移射击位置 |
| 猎人 | 依靠陷阱限制敌人，并让陷阱帮助建立锁定 | 偏防守和预设阵地，敌人进入准备好的区域时锁定效率更高 |

三者不是强弱递进，也不要求各自拥有完全隔绝的装备池。它们可以追求同一种结果，但为维持这个结果承担不同风险：弓箭手依靠稳定输出，游侠避免自身被中断，猎人限制敌方行动。

| 学派 | 核心法术语法 |
| --- | --- |
| 炼狱 | 火焰、自我献祭、灵魂燃烧、危险爆发 |
| 自然 | 植物、毒素、野兽、恢复、生长与传播 |
| 寒霜 | 减速、冻结、冰甲、碎裂 |
| 圣光 | 治疗、净化、祝福、审判 |
| 暗影 | 诅咒、生命窃取、幻象、灵魂伤害 |
| 风暴 | 雷电连锁、加速、击退、连续施法 |
| 奥术 | 复制、空间移动、能量护盾、改变冷却 |

角色通常掌握零至一个学派。双学派是少数高级角色的辨识点。

## 装备与套装分类

1. 职业套装：强化格挡、冲锋、陷阱等职业动作。
2. 学派套装：强化一个学派的共同语法，跨职业复用。
3. 通用套装：读取普攻、护盾、持续伤害、暴击等行为。
4. 特殊散件：改变单条战斗规则，补足三件套和六件套之外的部位。

八部位的长期组合目标包括：六件套加两件散件、三件套加三件套加两件散件、三件套加五件散件，以及八件散件。普通装备保持易读，复杂规则集中在套装和特殊散件。

## 套装设计公式：基础强化与战场职能强化

一套核心套装通常由两个层次构成：

1. **基础强化。** 生命、攻击、射程、治疗、移动等简单属性直接强化定位，玩家不研究完整公式也能理解收益。
2. **战场职能强化。** 套装必须制造一次可观察的关系变化，例如近战兵越战越强、盾兵阻断冲锋、弓兵锁定区域落矢、骑兵穿阵或护佑效果扩大回响。

细节机制可以筛选最适配的角色，但不是每套都必须给所有子职业写专属分支。叹息之墙可以让不同盾兵用已有的光环范围、护盾量与控制强化自然改变同一个机制；鹰眼校准则允许弓箭手、游侠和猎人用不同方法维持共同的锁定资源。只有真实产生构筑差异时才增加分支。

因此，同一套装在不同战斗规模下提供不同层次的理解：

- 小队战中，玩家关注谁能触发机制、技能顺序、目标选择和队友配合。
- 大规模战斗中，玩家首先关注军职：超远程点杀、阻止冲阵、方阵控制、阵地恢复、攻城或反大型单位。

部分六件套可以让高度适配角色接近翻倍，但并非所有套装都必须如此。高强度必须来自角色技能与套装机制真正咬合，不能让任何角色穿上都无条件翻倍。

### 机制不得退化为通用计数器

不能反复使用“攻击三次”“施法三次”“暴击三次”后触发额外伤害的模板。这类计数器几乎不读取角色原有玩法，只会泛化成攻速、技能急速或暴击率越高越好，难以形成有辨识度的 BD。

只有当“次数”本身就是该职业或学派的既有语法时，计数才成立。例如繁生之环读取自然法术对种子的播种与培养，不是脱离技能内容另记三次施法。

优先让套装读取以下细节：

- 学派状态：燃烧的层数、剩余持续伤害、冻结进度、种子生长、毒层、诅咒种类、护盾来源、溢出治疗。
- 职业动作：格挡了什么攻击、拦截了哪次冲锋、骑兵穿过多少敌人、猎人标记的目标、陷阱覆盖区域、攻击发生时的实际距离。
- 战场关系：目标是否正在冲阵、是否位于密集方阵、是否为军官或大型单位、施法是否跨过友军阵线、效果是否同时覆盖多名单位。

优先使用“改变既有状态的产生、转换、结算、传播和消耗方式”，而不是在既有玩法之外附加一套相同的命中计数器。

### 学派联动示例（仅说明方法，不代表定案套装）

假设一套装备适合持续施放炼狱法术的角色：

- **明显强化**可以赋予其清理密集阵线或持续压制的军职。
- **细节机制**可以让炼狱法术命中燃烧目标时，有概率提前结算其部分“剩余燃烧总伤害”；触发强度取决于目标已经积累的燃烧，而不是简单按本次攻击力追加固定伤害。

这会自然筛选能够快速叠燃烧、延长燃烧或同时维持多名燃烧目标的角色。只有一招火球但没有燃烧循环的角色可以使用，却无法获得同等收益。玩家构筑时考虑的是燃烧产生速度、剩余伤害规模、结算频率以及是否消耗燃烧，而不是泛用的“怎样最快攻击三次”。

类似地：

- 寒霜套装应读取减速、冻结进度、冰甲或碎裂，而不是读取任意三次法术。
- 圣光套装应读取净化对象、过量治疗、祝福或审判，而不是读取任意三次治疗。
- 盾兵套装应读取成功格挡、被保护目标和冲锋拦截，而不是读取任意三次受击。
- 猎人套装应读取标记、陷阱、目标类型或射击距离，而不是读取任意三次远程攻击。

### 设计检查

每个套装定案前必须能够回答：

1. 不看细节公式，能否用一句话说清它在大规模战斗中的军职？
2. 它具体读取了哪个职业动作、学派状态或战场关系？
3. 哪些技能组合会使它特别强，哪些角色只能获得有限收益？
4. 如果把触发技能全部换成无关技能，套装是否仍能发挥大部分强度？如果能，机制通常过于泛用。
5. 玩家是否会为了套装调整技能组合、队友、目标选择或站位？如果完全不用，通常还没有形成 BD。

## 首个套装：繁生之环

- 类型：自然学派套装。
- 核心体验：播种、继续灌注、成熟绽放、有限传播。

### 三件效果：播种

自然法术第一次影响某单位时，种下一枚持续 6 秒、初始 1 点生长的种子。同一施法者在同一目标上最多一枚种子；同一次技能即使有多个效果，也只对该目标计数一次。

该施法者之后用另一次自然法术影响目标时，种子增加 1 点生长，最多 3 点，并刷新持续时间。持续时间结束时绽放：

- 友方目标：每点生长恢复目标 4% 最大生命值。
- 敌方目标：每点生长造成施法者 55% 法术强度的自然伤害。

### 六件效果：繁生

繁生之环属于少数“六件套直接定义角色构筑”的套装。适配角色穿齐后，目标不是获得少量附伤，而是在能够持续施放自然法术的战斗里接近翻倍的有效输出或保护能力；并非所有六件套都采用这一强度模型。

种子达到 3 点生长时立即绽放。六件套持有者的满层绽放获得以下强化：

- 持有者的自然与毒系有效伤害提高 35%；该增幅不重复作用于套装自身的绽放与花潮。
- 敌方目标：每点生长改为造成施法者 100% 法术强度的自然伤害；满层绽放还会对距离最近的两个敌人分别造成主目标 50% 的“花潮”伤害。
- 友方目标：每点生长改为恢复目标 5% 最大生命值；溢出治疗等量转化为“余蕴”护盾。
- 绽放后向距离最近的同阵营单位传播一枚 2 点生长的新种子。传播种子可以继续培养和绽放，但不能再次传播。
- 同一套装持有者的传播仍有 6 秒冷却。战斗界面必须显示种子剩余时间与生长点数。

### 跨职业用法

- 自然祭司：在受伤友军身上培养，形成延迟恢复。
- 自然术士：围绕高威胁敌人施毒，成熟后向其他敌人传播。
- 自然炼金师：用多次瓶剂快速催熟，在集中培养与广泛播种之间取舍。
- 只有一个自然法术的物理职业：能获得三件套偶发收益，但通常难以稳定催熟六件套。
