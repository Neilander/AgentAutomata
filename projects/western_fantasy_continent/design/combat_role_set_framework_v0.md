# 八大战斗定位与首套装备框架 v0

- 状态：持续讨论中；近战兵、盾兵、弓兵、骑兵、护佑者、魔法师首套方向已确认，奇谋兵仅有候选方向
- 范围：一级战斗定位、每类首套装备、共享战斗关键词
- 与旧稿关系：`equipment_set_catalog_v1_grounded.md`仍保留此前八套探索；本文记录当前按八大定位重新建立的首套装备线

## 1. 一级战斗定位

| 大定位 | 战场职责 | 当前细分示例 |
| --- | --- | --- |
| 近战兵 | 正面接敌、活下来并持续攻击，是所有战斗单位的基准 | 普通战士、剑士、斧兵、重武器战士、长柄兵、双持战士、狂战士 |
| 盾兵 | 阻挡敌人推进，维持阵线并保护队友 | 盾卫、重甲守卫、强化光环／护盾／控制的盾兵变体 |
| 弓兵 | 利用前线之外的空间增加输出，并狙杀关键单位 | 弓箭手、游侠、猎人，未来可有弩手、长弓手 |
| 骑兵 | 依靠移动抓住机会，突击暴露目标并穿越阵线 | 马骑兵、象骑兵、龙骑兵 |
| 奇谋兵 | 绕过正常正面对抗，以隐蔽、伏击、破坏或欺骗制造战局转折 | 刺客、潜行者、破坏者、伏击者、幻术／间谍型单位 |
| 护佑者 | 救死扶伤，通过治疗、护盾、净化和保护阻止队友死亡 | 牧师、军医、守护祭司、锤牧 |
| 魔法师 | 远程范围毁灭；行动迟缓、极怕干扰，但无人限制时能融化敌阵 | 不同魔法学派的正规法师与炮台型施法者 |
| 战斗辅助 | 改变战场条件而非亲自完成击杀 | 炼金师、吟游诗人、工程师、削弱型术士 |

基础近战不是只有剑士。普通战士是最简单的基准单位；狂战士仍属于近战兵，其高攻速和低血能力只是运行近战循环的方式。盾兵、弓兵等专业定位都应当用一部分基础能力换取明确的战场权限。

## 2. 首套装备的统一标准

每套装备包含两层：

1. **基础强化。** 用生命、攻击、射程、治疗量、移动能力等简单属性强化该定位最直观的能力。
2. **战场职能强化。** 赋予一个能在战场上看见、会改变单位关系的强效果，例如越战越强、不可突破、区域落矢、冲锋穿阵或护佑回响。

八部位结构可继续采用三件套承接基础强化、六件套承接战场职能强化；具体件数和数值在程序演武前仍不锁死。

同一定位下的子职业不必都写一段专属套装规则。有两种合法设计方法：

- **共同机制自然读取不同技能。** 例如叹息之墙始终是同一个圈；不同盾兵用自身光环范围、护盾量和控制强化改变它。
- **不同职业用不同方式维持共同资源。** 例如鹰眼锁定中，游侠避免被控、猎人用陷阱加速、弓箭手稳定射击。

只有确实产生构筑差异时才写子职业分支，不能为了表面丰富强行给每个职业补一条规则。

## 3. 近战兵首套：万夫之勇

### 基础强化

- 提高生命。
- 提高攻击力。

### 战场职能强化：万夫之勇

- 穿戴者每实际命中一个敌方单位，获得少量攻击力，持续到本场战斗结束。
- 范围攻击命中多个单位时，每个实际命中的单位分别提供增长。
- 连击、反击和反伤造成的有效命中也能积累；同一敌方攻击引发的反伤最多记一次，避免一次结算被程序重复计数。
- 第一版暂不设置上限，观察其在长时间、大规模战斗中的自然增长曲线。

不同近战兵自然拥有不同效率：重武器战士靠范围攻击一次命中多人，反击／反伤战士靠被围攻获得更多有效命中，狂战士靠高攻击速度快速积累。套装不把狂战士移出近战定位。

战场职能是让一名能持续接敌的近战兵在大规模混战中逐渐成长为核心。小规模短战、无法接敌、频繁受控和过早死亡都是自然克制。

## 4. 盾兵首套：叹息之墙

### 基础强化

- 提高生命。
- 提高自身提供的护盾量。

### 战场职能强化：叹息之墙

- 穿戴者周围存在一个跟随自身移动的守护圈，不需要玩家放置。
- 开战时以及之后每隔一段较长时间，为自身和圈内友军提供一次数值较高的护盾；当前体验参考为约20秒一次，最终间隔与护盾量待演武。
- 圈的边界具有“不可突破”效果：带有`冲锋`、`突破`等标签的位移试图从外部穿入时，会在边界处被打断并眩晕。
- 普通步行不受阻挡，避免守护圈变成完全封路的空气墙。

套装不需要为每一种盾兵分别改写规则。部分盾兵自身擅长扩大光环范围，部分擅长提高护盾量，部分擅长强化眩晕与控制；这些职业能力直接改变同一个叹息之墙的实际表现。

多个守护圈重叠时如何合并视觉、同一次冲锋是否只能被拦截一次，仍需在大规模战斗演武中确定；不能让十个圆圈制造无法阅读的界面或连续眩晕漏洞。

## 5. 弓兵首套：鹰眼校准

### 基础强化

- 提高攻击力。
- 提高射程。

### 战场职能强化：天穹之箭

- 持续攻击同一目标会增加锁定值。
- 穿戴者被控制或射击被打断时，当前锁定归零。
- 锁定达到门槛后，以目标当时的位置锁定一片固定区域；短暂平静后，天穹之箭持续覆盖该区域。
- 落矢区域不追踪原目标。敌人可以利用前兆移动离开，队友可以用定身、减速、阻挡和聚集提高命中收益。
- 正常战斗主要表现瞄准线、落点前兆和密集落矢，不需要常驻显示锁定数字。

弓箭手依靠稳定射击提高锁定；游侠依靠隐蔽、规避控制和高机动避免锁定归零；猎人的陷阱可以增加锁定。三者共享一个结果，但维持锁定的方法不同。

锁定门槛、换目标规则、天穹之箭范围与持续时间仍待确定。

## 6. 骑兵首套：名称待定

### 基础强化

- 提高移动速度。
- 提高“移动速度转化为攻击速度”的效率，使加速同时改善持续攻击能力。
- 移动期间获得减伤，降低骑兵在接敌和重新寻找路线时被远程单位持续消耗的问题。

### 共享关键词：冲锋

`冲锋`应成为战斗包中的可复用状态／动作关键词，而不是某一名骑兵大招里的特例。

- 穿戴者持续移动达到一定实际距离后，进入冲锋状态。因此即使角色本身没有主动冲锋技能，只要拥有足够跑动空间，也能自然发动冲锋。
- 冲锋状态提高攻击力与移动速度。
- 冲锋者遇到第一个敌人时，继续向前突破一段距离。
- 突破期间无视普通敌方单位的碰撞体积，对路径上所有敌人造成伤害；突破完成后结束冲锋状态。
- 普通敌人不能靠身体碰撞截停突破，但地图障碍、专门拦截冲锋的能力以及叹息之墙的“不可突破”边界仍然有效。

### 不同骑兵如何运行冲锋

- **马骑兵：快速起势与腾挪。** 拥有大量加速和其他位移技能，能迅速积累移动距离，并左右调整路线、规避会阻挡冲锋的障碍。
- **象骑兵：缓慢但宽广。** 基础速度较慢，进入冲锋更困难，但突破覆盖范围和路径伤害范围更大。
- **龙骑兵：反复离地与落地。** 可以通过起飞、降落和持续空中移动反复寻找新的冲锋路线，并利用持续移动维持减伤。

实际距离怎样累计、普通位移和传送是否计入、受控后距离是否清零、冲锋提高多少攻击与移速，均未定案。

## 7. 护佑者首套：名称待定

### 基础强化

- 提高治疗量。
- 提高自身生命，使护佑者不容易被切入者一次击杀。

### 战场职能强化：护佑回响（工作名）

- 穿戴者对一个合法目标施加治疗、护盾、净化等护佑效果时，有一定概率以该目标为中心，在更大范围内再触发一次同类效果。
- 单体净化触发回响时可以变成群体净化；单体治疗触发时可以产生一圈范围治疗。
- 原始技能同时影响多个目标时，每个原始目标都分别获得一次触发机会。因此多目标治疗确实可能连续产生多次范围回响，而不是整次技能只判定一次。
- 回响本身不能再次触发回响，避免无限递归。
- 同一单位被多个合法回响覆盖时可以多次获得效果；最终概率与倍率需要按大规模战斗中的重叠收益校准。
- 锤牧的范围攻击若本身附带周围治疗，套装读取其中的护佑效果：先发生原始治疗，成功触发后再出现一次更大范围的治疗回响；伤害部分不会因为护佑套自动复制。

该套装不要求给祭司、军医、锤牧各写一条分支。它读取“对目标施加护佑效果”这一共同动作；不同职业通过单体强治疗、多目标治疗、净化、护盾或攻击附带治疗产生不同触发密度。

## 8. 魔法师首套：流星火雨

### 基础强化

- 提高法强。当前共享战斗包已经存在独立的`magicPower`属性，法术伤害会读取它，装备构筑层也支持`magicPowerAdd`。

### 战场职能强化：流星火雨

- 穿戴者累计造成10次有效火焰伤害后，立即清空本轮计数并触发一次流星火雨。
- 每个实际承受火焰伤害的目标／伤害实例分别计数：一个范围火焰命中多名敌人可以一次推进多次，燃烧的有效伤害跳也可以持续推进计数。
- 触发时选定7个战场位置。位置确定后固定，不继续追踪敌人。
- 每个位置分别获得0.5—1.5秒的独立随机延迟；延迟结束后在该位置爆发一次火焰范围伤害。
- 七个落点应有短暂、清晰的地面前兆和落火表现，不增加常驻计数条。精确的当前计数只在选中角色详情或调试信息中显示。
- 流星火雨自身造成的伤害不增加本套装的火焰计数，避免七次爆炸命中多人后立刻自我触发形成无限循环。

这一套强化魔法师“无人干扰便持续融化敌阵”的定位：范围火法可以靠一次命中多人快速触发，持续燃烧法师可以稳定推进，单体且低频的火焰角色触发较慢。火雨落点存在延迟，因此定身、减速、阻挡与聚集能提高命中，敌人移动和分散则能减少损失。

七个位置具体怎样选取、不同落点能否重叠、爆发倍率与再次触发的实际节奏，留待程序演武后确定。

## 9. 奇谋兵首套：尚未定案

奇谋兵目前最大的困难不是数值，而是找到刺客、伏击者、破坏者和幻术单位真正共享的战斗资源。不能因为刺客拥有爆发，就把整个类别重新写回“爆发兵”。

当前最值得继续讨论的候选轴是“敌方注意力”：

- 奇谋兵在一段时间内没有被敌人锁定、攻击或看见时，进入“奇袭准备”。
- 下一次从未被关注状态发动的技能获得规则级强化，而不只是伤害提高。
- 刺客用隐身创造未被关注；伏击者用地形；破坏者趁守卫被牵制接近战场对象；幻术单位把注意力引到假目标。

但“规则级强化”究竟是绕过保护、打断命令、破坏阵型，还是制造短暂混乱，尚未确定。本段只记录候选共同资源，不作为已确认套装。
