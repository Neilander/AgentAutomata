# Field Effect Brainstorm 2026-07-07 14:44

Scope: design-only heartbeat round. No source code changes. Three subagents each proposed three field effects using only formal base roles and existing official mechanisms.

Existing field-effect families to avoid repeating:

- `Iron Oath`: frontline survival / multi-frontline.
- `Arcane Tide`: caster skill windows.
- `Blood Moon`: low-health brawl.
- `Hunter Fog`: backline hunting.
- `Ember Air`: burn / poison DOT pressure.
- `Shield Echo`: shield / sustain tempo.
- `Tempo Drum`: basic-attack frequency.
- `Frost Clock`: control / delayed payoff.

## Consolidated Pass Candidates

### 1. Crown Relay / Crown Lantern

Status: pass as strongest new direction.

Merged from:

- `Crown Lantern`
- `Crown Relay`

Core idea:

The field rewards teams that route resources into one visible carry. Bard, priest, knight, and warlock help one highest-output unit become the win condition. The player should see one unit receiving more healing/shield/buffs and dealing a larger share of damage; if that carry dies early, the team collapses.

Suggested scope:

- Both teams.
- Require or strongly reward at least two routing/support roles: bard, priest, warlock, knight.

Suggested levels:

- L1: routing roles skill haste +6%; highest-output ally physical/magic power +8-10%; received healing +6-8%.
- L2: routing roles skill haste +12%; carry power +15-22%; received healing +8-18%.
- L3: routing roles skill haste +20%; carry power +24-38%; received healing +15-32%.

Favorable teams:

- Knight / priest / bard / ranger.
- Warrior / priest / bard / berserker.
- Knight / priest / warlock / mage.
- Bard / priest / warlock / assassin.

Risk:

- Could become too universal if every team simply brings two supports.
- Needs damage-share validation so the carry actually becomes the visible win condition.
- Must not collapse into generic shield sustain, which is already covered by `Shield Echo`.

Difference from existing effects:

- Not a physical, caster, shield, or low-health field.
- Tests resource routing and carry protection.

Next validation:

- Compare carry damage share before/after.
- Check teams with no clear carry do not gain the same value.
- Check assassin/ranger burst can still punish the carry.

### 2. Many-Target Hall

Status: pass as a clean teaching direction.

Core idea:

The field rewards teams that spread meaningful damage across several enemies. It teaches multi-target coverage and pressure distribution rather than single-target deletion or DOT stacking.

Suggested scope:

- Both teams.
- Favor warrior, mage, alchemist, ranger.

Suggested levels:

- L1: listed roles power x1.08; if team has at least two listed roles, skill haste x1.04.
- L2: power x1.18; team bonus skill haste x1.09.
- L3: power x1.32; team bonus skill haste x1.16.

Favorable teams:

- Warrior / mage / alchemist / priest.
- Knight / mage / ranger / bard.
- Warrior / ranger / mage / alchemist.

Risk:

- Can blur into `Ember Air` if DOT becomes the main damage source.
- Needs signal check that several HP bars fall together.

Difference from existing effects:

- `Ember Air` rewards DOT over time.
- `Arcane Tide` rewards caster skill bursts.
- `Hunter Fog` rewards hunting a specific target.
- This tests damage distribution width.

Next validation:

- Track number of enemy units below 50% HP at the same time.
- Track whether first kill is delayed but teamwide HP pressure is higher.

### 3. Purging Rain / Clear Spring / Silver Rain

Status: record/pass as a useful opposite-pole field, but merge all three variants into one direction.

Merged from:

- `Clear Spring`
- `Purging Rain`
- `Silver Rain`

Core idea:

The field rewards teams that can survive status pressure through effect resistance, cleanse, healing, shielding, and steady recovery. It should be used as a soft answer to poison/burn/control pressure, not as a permanent generic sustain field.

Suggested scope:

- Both teams.
- Favor priest, alchemist, warlock, and optionally knight.

Suggested levels:

- L1: effect resist +8%; received healing/shield x1.05-1.06.
- L2: effect resist +15-16%; received healing/shield x1.12-1.15; optional skill haste x1.07.
- L3: effect resist +24-26%; received healing/shield x1.20-1.28; optional skill haste x1.08-1.14.

Favorable teams:

- Knight / priest / alchemist / warlock.
- Warrior / priest / alchemist / mage.
- Knight / priest / priest / warlock.

Risk:

- If too strong, it invalidates DOT fields and DOT teams.
- If no enemy status pressure exists, it feels invisible.
- Should be gate-kept as a status-pressure dungeon effect.

Difference from existing effects:

- `Ember Air` makes DOT offense stronger.
- `Shield Echo` is shield/sustain tempo.
- This rewards processing enemy status pressure.

Next validation:

- Run specifically against poison/burn-heavy opponents and ordinary physical opponents.
- Ensure it helps against status pressure but does not make physical burst matchups free.

### 4. Quarry Sigils

Status: pass with caution.

Merged from:

- `Quarry Sigil`
- `Quarry Sigils`

Core idea:

The field rewards mark as a resource economy: setup, maintain, and cash out mark stacks. It should not provide backline access; otherwise it duplicates `Hunter Fog`.

Suggested scope:

- Both teams.
- Favor ranger, assassin, alchemist.

Suggested levels:

- L1: ranger/assassin/alchemist effect power +8%; marked-target damage +6%; or physical power x1.10 and skill haste x1.06 if runtime only supports pre-battle stat transforms.
- L2: effect power +16%; marked-target damage +12%; small mark retention.
- L3: effect power +26%; marked-target damage +20%; mark cash-out retains about 25% value.

Favorable teams:

- Warrior / ranger / assassin / priest.
- Knight / ranger / ranger / bard.
- Warrior / ranger / alchemist / assassin.

Risk:

- Can become a generic ranger/assassin damage field.
- Some suggested effects need runtime mark hooks, not only pre-battle stats.
- Must not overlap with `Hunter Fog`.

Difference from existing effects:

- `Hunter Fog` is target access.
- This is resource stacking and payoff.

Next validation:

- Track mark stacks, mark-consuming damage, and whether marked targets die faster.
- Reject if the benefit appears without mark usage.

### 5. Banner Crucible

Status: record as a promising but overlap-prone direction.

Core idea:

The field rewards team tactical windows: war banner, taunt, bard rhythm, and early front-line coordination. It should feel like "survive first contact, then the whole team turns on together."

Suggested scope:

- Both teams.
- Favor warrior, knight, bard.

Suggested levels:

- L1: warrior/knight/bard skill haste x1.07; HP x1.04.
- L2: skill haste x1.15; HP x1.09; armor x1.10.
- L3: skill haste x1.26; HP x1.16; armor x1.20; if at least two of the three roles are present, received healing/shield x1.08.

Favorable teams:

- Warrior / knight / bard / ranger.
- Warrior / knight / bard / priest.
- Knight / bard / berserker / warrior.

Risk:

- Can overlap with `Iron Oath` if it becomes pure frontline survival.
- Can overlap with `Tempo Drum` if bard haste dominates.
- Needs signal validation around ultimate/team-window timing.

Difference from existing effects:

- `Iron Oath` is body durability.
- This is synchronized team timing and tactical window acceleration.

Next validation:

- Track first ultimate/team-window timestamp.
- Track whether the second rotation flips the fight.

## Duplicate / Rejected Items

- `Clear Spring`, `Purging Rain`, and `Silver Rain` are one merged direction: status-pressure handling.
- `Crown Lantern` and `Crown Relay` are one merged direction: carry resource routing.
- `Quarry Sigil` and `Quarry Sigils` are one merged direction: mark economy.
- No candidate was fully rejected, but `Banner Crucible` is closest to existing fields and should not be implemented until the team-window signal is clearly distinct from frontline durability.

## Next-Round Forbidden Directions

Do not ask for more variants of:

- Generic frontline durability.
- Generic caster haste / magic power.
- Generic low-health brawl.
- Generic backline hunting.
- Generic burn/poison DOT amplification.
- Generic shield/healing sustain.
- Generic attack-speed field.
- Generic control-duration field.
- Carry-resource-routing unless the prompt asks for refinements of Crown Relay.
- Status-pressure-cleanse fields unless the prompt asks for refinements of Purging Rain.
- Mark-economy fields unless the prompt asks for refinements of Quarry Sigils.

## Empty / Underexplored Directions

Worth asking for next:

- Formation shape fields: front-row/back-row split, diagonal pressure, isolated corner.
- Death-order fields: first death, last survivor, revenge after ally falls.
- Resource denial fields: delayed ultimates, cooldown tax, shield-breaking objective.
- Enemy-threat readability fields: one dangerous elite plus weak guards.
- Movement / distance fields, if runtime hooks are later supported.

## Recommended Priority

1. Implement/test `Crown Relay` first if the goal is teaching build intent.
2. Test `Many-Target Hall` if the goal is making encounter identity immediately visible.
3. Keep `Purging Rain` as the defensive counterpart to DOT/status dungeons.
4. Save `Quarry Sigils` for a runtime-hook pass because the best version needs mark-specific logic.
