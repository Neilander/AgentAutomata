# Field Effect Brainstorm 2026-07-07 14:59

Scope: design-only heartbeat round. No source code changes. Three subagents each proposed three field effects using only formal base roles and existing official mechanisms.

This round intentionally avoided both:

- Existing implemented field families: frontline durability, caster window, low-health brawl, backline hunt, DOT pressure, shield sustain, basic-attack frequency, control payoff.
- Previous brainstorm directions: carry resource routing, multi-target pressure, status-pressure handling, mark economy, tactical team-window acceleration.

## Consolidated Pass Candidates

### 1. Twin-Lane Bastion

Status: pass as the strongest formation/space candidate.

Core idea:

Reward paired front/back side lanes. The player should see that a backline unit performs better when its same-side frontliner stays alive, and that one collapsed lane exposes that backline.

Suggested scope:

- Both teams.
- Requires formation metadata or side-lane pairing check.

Suggested levels:

- L1: paired frontliner hp x1.04, armor x1.08, received healing x1.04; paired backliner physical/magic power x1.06, skill haste x1.04.
- L2: paired frontliner hp x1.09, armor x1.18, received healing x1.08; paired backliner power x1.13, skill haste x1.09.
- L3: paired frontliner hp x1.16, armor x1.32, received healing x1.14; paired backliner power x1.24, skill haste x1.16.

Favorable teams:

- Warrior / knight / ranger / mage.
- Knight / warrior / priest / ranger.
- Warrior / knight / bard / mage.

Risk:

- May become a default 2-front/2-back best practice field if too broad.
- Needs UI or battle signal that visually connects each front/back pair.
- Backline-hunt teams should punish lane collapse.

Difference from existing effects:

- Not `Iron Oath`: it rewards pair integrity, not just more or tougher frontliners.
- Not `Crown Relay`: it creates two small protected lanes, not one carry funnel.

Implementation note:

- Can be prototyped as a pre-battle transformation if slot positions are stable.
- Better long-term version needs formation-aware display and lane-break signals.

### 2. Lone Gate

Status: pass as a high-risk formation candidate.

Core idea:

Reward single-frontline / triple-backline teams. One frontliner is the gate; if it holds, the backline gains time. If it falls, the team collapses fast.

Suggested scope:

- Both teams.
- Trigger only when the team has exactly one frontline role or one front-row slot occupied.

Suggested levels:

- L1: only frontliner hp x1.08, armor x1.12, received healing x1.06; backline skill haste x1.04.
- L2: only frontliner hp x1.18, armor x1.28, received healing x1.12; backline skill haste x1.09, power x1.06.
- L3: only frontliner hp x1.34, armor x1.52, received healing x1.22; backline skill haste x1.16, power x1.12.

Favorable teams:

- Knight / mage / warlock / priest.
- Warrior / ranger / mage / bard.
- Berserker / priest / bard / warlock.

Risk:

- Can become a generic backline-cannon field if backline bonuses are too high.
- Backline access and front-burst should remain good counters.

Difference from existing effects:

- It is the inverse of `Iron Oath`: less frontline, more risk.
- It is not `Arcane Tide`: backline skill value is gated by one frontliner surviving.

Implementation note:

- Can be prototyped by counting front-row/frontline units before battle.

### 3. Vengeance Bell

Status: pass as the strongest death-order candidate.

Core idea:

When a unit kills someone, it becomes the revenge target. This creates a visible "killer is exposed" loop: kill, get marked, get hunted.

Suggested scope:

- Both teams.
- Trigger on every kill or every first kill per side; start conservative with every kill but short duration.

Suggested levels:

- L1: killer receives 2 mark stacks; dead unit's allies deal +8% damage to killer for 5 seconds.
- L2: killer receives 3 mark stacks; revenge damage +14%; dead unit's allies skill haste +8% for 6 seconds.
- L3: killer receives 4 mark stacks; revenge damage +22%; dead unit's allies skill haste +12% for 6 seconds; if revenge succeeds, team heals 6% max HP.

Favorable teams:

- Ranger / assassin revenge mark teams.
- Warrior / berserker trade-back teams.
- Priest / bard teams that can survive the revenge window.

Risk:

- Too much revenge value can invalidate burst teams.
- Too little value becomes decorative.
- Needs death/killer runtime hook and target-highlight signal.

Difference from existing effects:

- Not `Quarry Sigils`: mark appears because of kill responsibility, not resource setup.
- Not `Hunter Fog`: target is chosen by kill event, not by backline access.

Implementation note:

- Requires combat runtime event hook for killer identity and temporary revenge modifier.
- Should be implemented after the first pre-battle field batch.

### 4. First Blood Writ

Status: record as a simpler death-order variant.

Core idea:

The first kill creates a short tempo swing, but the killer is marked as an exposed target. It teaches first-kill timing and anti-snowball counterplay.

Suggested levels:

- L1: first-kill team gains skill haste +8% and attack speed +6% for 5 seconds; killer receives 2 mark.
- L2: skill haste +14%, attack speed +10% for 6 seconds; killer receives 3 mark.
- L3: skill haste +22%, attack speed +16% for 7 seconds; killer receives 4 mark.

Risk:

- Can become too snowbally.
- Less reusable than `Vengeance Bell` because it only fires once.

Difference from existing effects:

- Death-order trigger, not constant attack speed or backline hunting.

Implementation note:

- Requires first-death runtime hook.

### 5. Last Candle

Status: record, but watch overlap with low-health berserker.

Core idea:

The last survivor receives a last-stand state. It asks: who should be the final unit alive?

Suggested levels:

- L1: last survivor power +12%, received healing +10%, effect resist +8%.
- L2: power +22%, attack speed +10%, received healing +18%, effect resist +14%.
- L3: power +36%, attack speed +18%, skill haste +10%, received healing +26%, effect resist +22%.

Risk:

- Can overlap with `Blood Moon`, especially berserker.
- Can drag fights if sustain is too high.

Difference from existing effects:

- Trigger is team death order, not low HP alone.

Implementation note:

- Requires runtime alive-count hook.

### 6. Blackout Bell

Status: pass as the strongest resource-denial candidate.

Core idea:

Delay ultimates and reward teams that can survive or build advantage before the first major ultimate window. This asks whether the team has a functional early game without relying on a quick ultimate.

Suggested scope:

- Both teams.
- Universal ultimate delay plus small-skill compensation for setup/early-game roles.

Suggested levels:

- L1: all units ultimate opening cooldown +2 seconds; warrior/knight/ranger/alchemist small-skill cooldown efficiency +4%.
- L2: ultimate opening cooldown +4 seconds; same roles +8%.
- L3: ultimate opening cooldown +6 seconds; same roles +13%.

Favorable teams:

- Warrior / knight / ranger / alchemist early setup.
- Frontline plus ranger mark pressure.
- Alchemist / warrior / priest teams that can build before ultimates.

Risk:

- If too strong, ultimate-centric fantasy feels bad.
- Needs UI/log feedback that the field is delaying ultimates, otherwise it can feel like the game is broken.

Difference from existing effects:

- Not `Arcane Tide`: it delays ultimate timing instead of empowering skill windows.
- Not `Frost Clock`: it is resource/timing denial, not control payoff.

Implementation note:

- Needs battle-engine support for opening ultimate cooldown adjustment. Could be prototyped by transformed unit specs if slots expose opening cooldown overrides later.

### 7. Toll Forge

Status: record as a broader but riskier resource-tax field.

Core idea:

Skill haste is taxed globally. Teams that rely on stable physical pressure, front pressure, and low-cooldown independence gain relative value.

Suggested levels:

- L1: all units skill haste x0.94; warrior/berserker/ranger/assassin physical power x1.06.
- L2: all units skill haste x0.87; listed roles physical power x1.13; knight armor x1.08.
- L3: all units skill haste x0.78; listed roles physical power x1.23; knight armor x1.16.

Risk:

- Can feel like "the game is slower" rather than a clear encounter identity.
- Overlaps with `Tempo Drum` if physical compensation becomes too high.

Difference from existing effects:

- Taxes skill resources instead of rewarding basic attack speed.

Implementation note:

- Can be prototyped with pre-battle skillHasteMult transforms.

### 8. Glass Aegis

Status: pass as an enemy-threat readability candidate.

Core idea:

One enemy shield/armor target becomes the obvious objective. It has a big shield, but once the shield breaks, it becomes vulnerable. The player learns to break the highlighted target before bursting.

Suggested scope:

- Prefer enemy-only for encounter identity.
- Can be both-side in sandbox validation, but player-facing use is better as enemy buff.

Suggested levels:

- L1: target starts with max HP 12% shield; while shielded armor x1.08; after shield break, receives +8% damage for 5 seconds.
- L2: shield 22%; armor x1.15; after break receives +14% damage for 6 seconds.
- L3: shield 36%; armor x1.25; after break receives +22% damage for 7 seconds.

Favorable teams:

- Warrior / berserker front pressure.
- Mage / alchemist multi-hit pressure.
- Ranger-assisted focus fire.

Risk:

- Can hard-counter shield teams if applied globally.
- Needs clear visual highlight and shield-break signal.

Difference from existing effects:

- `Shield Echo` rewards the player's own shield sustain.
- `Glass Aegis` turns shield into an enemy objective and failure-diagnosis target.

Implementation note:

- Requires opening shield and on-shield-break vulnerability hook for the best version.
- Not ideal as pure pre-battle stat transform.

## Duplicate / Rejected Items

- `Clash Line` is record-only because it risks becoming `Iron Oath` plus physical power. It is useful only if future runtime supports front-line pressure or displacement signals.
- `Toll Forge` is record-only because it may feel like a slower game rather than a positive puzzle unless UI explains cooldown tax clearly.
- `Last Candle` is record-only because it overlaps with `Blood Moon` and berserker last-stand fantasy.

## Next-Round Forbidden Directions

Do not ask for more variants of:

- Frontline durability / more frontliners.
- Caster skill haste / magic power.
- Low-health brawl or last-stand unless specifically refining `Last Candle`.
- Backline hunting.
- DOT amplification.
- Shield sustain.
- Basic-attack frequency.
- Generic control payoff.
- Carry resource routing.
- Multi-target pressure.
- Status-pressure cleanse.
- Mark economy.
- Tactical banner/window acceleration.
- Two-lane formation or single-frontline formation unless refining `Twin-Lane Bastion` / `Lone Gate`.
- Death-order revenge unless refining `Vengeance Bell`.
- Ultimate delay / cooldown tax unless refining `Blackout Bell`.
- Shield-break objective unless refining `Glass Aegis`.

## Empty / Underexplored Directions

Worth asking for next:

- Enemy ecology fields: one elite plus guards, healer plus fragile ward, summoner plus minions if runtime supports it.
- Objective fields: survive 20 seconds, kill marked target first, protect a ward.
- Reward-shaping fields: extra loot if no unit dies, extra loot if battle ends fast.
- Map-hazard fields: rotating danger zones, safe lanes, delayed bombs, if movement/runtime hooks are later supported.

## Recommended Priority

1. `Twin-Lane Bastion`: best pure formation lesson and probably testable with pre-battle transformation.
2. `Blackout Bell`: best resource-denial lesson, but needs ultimate-opening-cooldown support.
3. `Vengeance Bell`: most interesting death-order lesson, but requires runtime death/killer hook.
4. `Glass Aegis`: best enemy-threat readability field, but needs shield-break hook and visual highlight.
