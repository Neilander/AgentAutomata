# Field Effect Brainstorm 2026-07-07 16:04

Scope: design-only heartbeat round. No source code changes. Three subagents each proposed three field effects using only formal base roles and existing official mechanisms.

This round intentionally avoided all implemented fields and all prior brainstorm families, including stat-buff fields, target objectives, boss phases, resistance reversal, loot diagnosis, route pressure, enemy targeting, and waste diagnosis.

The prompt focused on remaining gaps:

- morale / retreat / regroup behavior;
- one-use field devices;
- long-term blessings / curses / multi-fight commitments.

## Consolidated Pass Candidates

### 1. Rout Line

Status: pass as the strongest morale / endgame behavior candidate.

Core idea:

When the enemy side falls below a total-health threshold, low-health non-boss enemies panic and rout. Routed enemies stop casting skills and try to drag out the end of the fight. This makes cleanup ability visible: chase, execute, DOT finish, or ranged pressure.

Suggested scope:

- Enemy behavior rule.

Suggested levels:

- L1: when enemy total HP first falls below 35%, non-boss enemies below 25% HP rout for 3 seconds. Routed units do not cast small skills or ultimates and only basic attack.
- L2: total HP threshold 40%, individual HP threshold 30%, rout lasts 4 seconds. If routed target has mark, slow, poison, or burn, rout lasts +1 second.
- L3: total HP threshold 45%, individual HP threshold 35%, rout lasts 5 seconds. At most 2 new routed targets every 8 seconds.

Favorable teams:

- Ranger / assassin cleanup teams.
- Warlock / alchemist DOT finish teams.
- Mage late-burst teams.
- Teams with reliable end-of-fight reach rather than only opening burst.

Counter / risk:

- Pure tank-heal teams may create routed enemies but fail to finish them.
- If movement / retreat is not supported, it must be represented with casting discipline, target behavior, and clear panic visuals rather than physical kiting.
- Values should avoid making enemies harmless too early.

Player understanding signal:

- Low-health enemies show a panic / retreat state.
- They stop using skills and become cleanup targets.
- DOT or ranged finishers visibly clean them up faster.
- If the player lacks finish, multiple low-health enemies stay alive and extend the fight.

Difference from existing effects:

- Not `Blood Moon`: it does not buff low-health units.
- Not death revenge, first kill, or last survivor.
- Not `Hunter Fog`: it tests cleanup after enemies rout, not backline access.

Validation:

- Track time from first enemy below 30% HP to enemy death.
- Check whether cleanup teams shorten the endgame without making the whole fight trivial.

### 2. Salvage Winch

Status: pass as the strongest one-use field device candidate.

Core idea:

A one-use field device lets the player cash out active positive short-duration states into immediate healing / shielding, while shortening those states. It asks whether the player should keep a power window running or spend it to survive now.

Suggested scope:

- Player-activated one-use battlefield device.

Suggested levels:

- L1: each cashed-out positive state grants 18 healing to its unit; that state's remaining duration is reduced by 35%. Max 2 states per unit.
- L2: each state grants 24 healing + 20 shield; remaining duration reduced by 30%. Max 3 states per unit.
- L3: each state grants 32 healing + 28 shield; remaining duration reduced by 25%. Max 3 states per unit.

Eligible state examples:

- ordinary positive short timers such as guard, haste, bonusPower, lifeSteal, retaliation-style windows;
- avoid rare miracle states such as undying unless explicitly supported later.

Favorable teams:

- Bard / knight / priest support-window teams.
- Berserker teams deciding whether to keep lifesteal / speed windows or convert them to survival.
- Warrior / ranger timing teams with active buffs.

Counter / risk:

- Triggering too early wastes offensive windows.
- Triggering too late yields little because states already expired.
- Must not become generic shield sustain; the cost is shortening existing states.

Player understanding signal:

- Active positive glows collapse into the device.
- HP/shields rise immediately.
- The original buff icons shrink or expire faster.
- The player sees "future advantage converted into current survival."

Difference from existing effects:

- Not `Shield Echo`: shields do not passively grow.
- Not a generic tactical window: the player chooses a one-use conversion with a real cost.
- Not `Idle-Cast Calibration`: it is a player timing decision, not a waste detector.

Validation:

- Track whether winch use saves units that would otherwise die.
- Track lost buff duration and whether the tradeoff is meaningful.

### 3. Rotating Expedition Writ

Status: pass as the strongest long-term commitment candidate.

Core idea:

Across several fights, recently used roles become fatigued while unused roles become prepared. It teaches roster width and role substitution: repeated use of the same team gets duller, but swapping to fresh roles creates a visible lift.

Suggested scope:

- Multi-fight dungeon modifier.
- Track formal roles: warrior, knight, berserker, assassin, ranger, mage, priest, warlock, bard, alchemist.

Suggested levels:

- L1: roles used last fight have power -4% and skill haste -4% next fight. Roles not used last fight have power +5% and received healing +4%.
- L2: fatigue lasts 2 fights: first fight power -6%, skill haste -6%; second fight half value. Unused roles have power +8% and received healing +6%.
- L3: fatigue lasts 2 fights: first fight power -9%, skill haste -8%; second fight half value. Unused roles have power +12%, received healing +8%, effect power +6%.

Favorable teams:

- Players with two or more viable team shells.
- Teams that can swap priest to bard/alchemist, warrior to knight, ranger to mage, etc.
- Roster-building gameplay rather than one perfect team forever.

Counter / risk:

- Too harsh for early game or players with shallow rosters.
- If values are high, it becomes forced rotation.
- Needs clear pre-fight role status: fatigued / prepared.

Player understanding signal:

- Reusing the same role makes that role feel slower and weaker.
- Fresh roles show prepared highlights and perform better.
- The pre-fight UI shows which roles are fatigued or prepared.

Difference from existing effects:

- Not `Forked Danger Road`: it does not branch route risk.
- Not `Expedition Pressure`: it is not wound attrition.
- Not a single-fight role buff; it is roster memory.

Validation:

- Check whether prepared role swaps feel optional but attractive.
- Reject if it punishes small roster players too early.

### 4. Borrowed Dawn

Status: pass/record as a multi-fight debt candidate.

Core idea:

The player borrows power for two fights, then repays in the third fight. It creates a clear "use this now, prepare for the debt" pattern.

Suggested levels:

- L1: fights 1-2 opening 10 seconds: skill haste +6%, power +5%, received healing +5%. Fight 3 opening 10 seconds: player received healing -8%, enemy power +5%.
- L2: fights 1-2 opening 12 seconds: skill haste +10%, power +8%, received healing +8%. Fight 3: received healing -12%, enemy power +8%, enemy skill haste +5%.
- L3: fights 1-2 opening 14 seconds: skill haste +15%, power +12%, received healing +12%. Fight 3: received healing -18%, enemy power +12%, enemy skill haste +8%.

Reason to record:

- Very clear, but partially overlaps generic opening power and route planning.
- Best used as a rare dungeon pact, not a common field family.

### 5. Rift Reticle

Status: record as a one-use focus device.

Core idea:

The player marks one enemy for a short time. The next few directed small skills prefer that enemy and add small flat damage.

Suggested levels:

- L1: lasts 4 seconds; next 3 skill hits add 18 damage.
- L2: lasts 5 seconds; next 4 hits add 24 damage.
- L3: lasts 6 seconds; next 5 hits add 32 damage.

Reason to record:

- Useful, but overlaps focus-fire / target objective / mark-adjacent space.
- Keep only if implemented explicitly as a one-use targeting device, not as mark economy.

### 6. Battle Bell Echo

Status: record as a one-use timing device.

Core idea:

The player rings a battle bell once to compress imminent small-skill casts.

Suggested levels:

- L1: 2 closest-to-ready units reduce small-skill wait by 2.0 seconds; if already nearly ready, gain 1.2 seconds haste.
- L2: 3 units reduce wait by 2.4 seconds; near-ready units gain 1.5 seconds haste.
- L3: 4 units reduce wait by 2.8 seconds; near-ready units gain 1.8 seconds haste.

Reason to record:

- Good one-use pacing button, but overlaps generic tactical windows and skill timing.
- `Salvage Winch` has a clearer cost and less overlap.

## Duplicate / Rejected Items

- `Collapse Banner` / `Regrouping Banner` style effects merge into `Rout Line` or are rejected if they become ordinary shield protection.
- `Oath Pilgrimage` is close to ordinary role-family buffs. It is less distinct than `Rotating Expedition Writ`.
- `Rift Reticle` risks reintroducing mark/focus-objective space and should be kept as a tool-only variant.
- `Battle Bell Echo` risks becoming a one-use `Arcane Tide` / tactical window variant; record, but do not prioritize.

## Next-Round Forbidden Directions

Do not ask for more variants of:

- Enemy rout / morale collapse / regroup unless refining `Rout Line`.
- One-use positive-state cashout unless refining `Salvage Winch`.
- Role fatigue / prepared roster rotation unless refining `Rotating Expedition Writ`.
- Borrowed power then debt unless refining `Borrowed Dawn`.
- One-use reticle / temporary focus target unless refining `Rift Reticle`.
- One-use skill timing bell unless refining `Battle Bell Echo`.

Carry over all earlier forbidden directions:

- Frontline durability, caster haste, low-health brawl, backline hunting, DOT amplification, shield sustain, attack-speed fields, generic control payoff.
- Carry routing, multi-target pressure, status cleanse, mark economy, tactical banner/window acceleration.
- Lane formation, lone-front formation, death revenge, first blood, last survivor, ultimate delay, cooldown tax, shield-break objective.
- Guarded captain, fragile ritual core, timed kill target, survive timer, no-death contract, emergency low-health fuse, tile explosions, neutral-object protection.
- Boss interrupt channel, timed boss second phase, resistance reversal, damage-type contribution ledger, loot diagnosis, reward branch between sharpen/repair.
- Enemy targeting high output or healing recipient, route-risk branching, expedition wound pressure, low-value skill-cast detection, overheal/overkill ledgers.

## Empty / Underexplored Directions

Worth asking for next:

- Enemy morale rewards that end a fight early without reducing loot, if surrender support exists.
- Dungeon-wide pact choices that change enemy composition rather than stats.
- Player-side one-use devices that consume enemy states rather than allied states.
- Meta-progression fields that teach roster bench management without forcing rotation too early.

## Recommended Priority

1. `Salvage Winch`: best one-use field device; real timing choice with a clear cost.
2. `Rout Line`: best battle-ending behavior rule; makes cleanup ability visible.
3. `Rotating Expedition Writ`: strongest roster-width rule, but likely midgame-only.
4. `Borrowed Dawn`: strong rare pact; useful after multi-fight dungeons exist.
5. `Rift Reticle`: lower priority because it overlaps focus/mark space.
