# Map Cognition Iteration V1.2: Prison-First Soft Order

- Time: 2026-07-09 18:48 UTC heartbeat
- Basis: V1.1 plus dual review
- Status: recommended active baseline before V2

## Why V1.2 Exists

V1.1 fixed V1's largest flaw by making Prison A visible before Camp A is consumed. The second review found a remaining problem:

```text
If Prison A and Camp A are both visible and equally actionable, the player may choose Camp A first because equipment is already known to increase power.
```

That skips the intended `Prison A` failure memory. Without that failure memory, Camp A is only a high-value side reward, not a cognitively meaningful key.

V1.2 keeps both nodes visible but changes their psychological order:

```text
Visible at the same time.
Prison A is the main desire and first low-cost attempt.
Camp A is the preparation clue.
After Prison A failure, Camp A becomes the highlighted key.
```

## Target Concepts

No new concept beyond V1.1:

```text
关卡战斗 -> 装备 -> 换装备 -> 战力 -> 监狱/角色 -> 营地装备钥匙 -> 角色上阵 -> 主线过程墙验证
```

Rarity remains deferred except for possible reward color preview later.

## Revised M4: 旧塔求援

M4 completion reveals both Prison A and Camp A, but with different salience.

### Prison A Presentation

```text
role: main desire point
visual salience: strong
camera / focus: points to Prison A first
label: 旧塔监狱
message: 里面关着一名可救出的角色
action cost: low
failure cost: none
```

Design intent:

```text
The player should think: "I should try saving this character."
```

### Camp A Presentation Before Prison Failure

```text
role: preparation clue
visual salience: weak to medium
label: 附近军械营地
message: 也许有攻坚装备
action: visible but not more attractive than Prison A
```

Design intent:

```text
The player can see there is a preparation route, but it does not steal the first attempt.
```

## Prison A First Attempt

```text
difficulty: high chance to fail before Camp A, but not hopeless
fight length: short
failure cost: none
failure message: 战力不足 / 装备还不够
baseline_power: record first failed attempt
```

Important:

Do not teach:

```text
you need a different role
team composition is wrong
rarity matters
```

The player only knows equipment/power as reliable explanations.

## After Prison A Failure

Now Camp A changes state.

```text
Camp A visual salience: strong
Camp A message: 也许旧塔军械能帮助攻坚
Camp A role: explicit equipment key
```

Failure memory:

```text
failed_object: Prison A
baseline_power: power at first failed attempt
primary attribution: 战力不足
secondary attribution: 装备还不够
wake:
  current_power >= baseline * 1.3 starts retry chance
  current_power >= baseline * 2.0 guarantees retry
on_retry_fail:
  refresh baseline_power
```

## Camp A: 旧塔军械营地

Reward target:

```text
useful total power gain: +30%-50%
```

The reward should be strong enough to wake Prison A retry, but not so strong that the player learns:

```text
side branches trivialize all locks
```

## Prison A Success

Reward:

```text
first rescued character
```

Knowledge update:

```text
concepts +角色
behaviors +上阵新角色
knowledge +监狱能给角色
```

Do not yet claim:

```text
角色能决定胜负
```

That needs process evidence.

## M5: Low-Pressure Role Process Proof

M5 should be winnable without the new character, but using the character must change a readable process metric.

Examples:

```text
牧师:
  frontliner avoids dropping into danger range
  end-of-fight HP loss is visibly lower

游侠:
  backline or fleeing low-HP enemy dies earlier
  cleanup time is visibly shorter

盾民兵:
  one extra enemy wave is absorbed without the knight collapsing
```

Knowledge update if character is used:

```text
knowledge +角色能改变战斗过程
```

If character is not used:

```text
do not mark role-value knowledge as learned
keep unexecuted no-cost behavior "上阵新角色" available for wake-up
```

## M6: First Process Wall

M6 is the first place where character function may change the result.

Keys:

```text
Key A: use rescued character after M5 process proof
Key B: farm/equip enough to brute force
```

Failure attribution:

```text
if no character rescued:
  primary = 战力不足

if character rescued but not used:
  primary = 战力不足
  wake = unexecuted no-cost behavior 上阵新角色

if character used and still failed:
  primary = 战力不足
  secondary = 队伍功能还不够
```

Avoid over-teaching composition. The player is learning that character choice matters, not yet team-building theory.

## V2 Gate

Rarity can be introduced only after V1.2 conditions hold:

```text
Prison A is psychologically first.
Camp A is understood as response to Prison A failure.
M5 gives visible process proof for the rescued character.
```

Allowed V2 form:

```text

```

Forbidden V2 forms:

```text

rarity as affix optimization
rarity as build-specific gear choice
rarity competing with M5 role proof
```
