## V1.2 Check

### Intended Player Path

```text
M1-M3:
  learn equipment/power

M4:
  see Prison A as main desire point
  see Camp A as nearby preparation clue

Prison A first attempt:
  likely fail, no punishment
  failure attribution = 战力不足 / 装备还不够
  record baseline_power

After Prison A fail:
  Camp A salience increases
  Camp A is now interpreted as key, not generic side reward

Camp A:
  gives +30%-50% useful power
  wakes Prison A retry

Prison A retry:
  success gives first character

M5:
  low-pressure role process proof

M6:
  first process wall with character-function or equipment brute-force solution
```

### Key Risk To Validate

```text
Does a known-solution node (Camp A: equipment) still overpower a new-treasure node (Prison A: character)?
```

If yes, V1.2 still fails and Camp A should become actionable only after Prison A failure.

## Playtest / Review Feedback

### Agent A: V1.2 Cognition Naturalness

Severity: `minor`, near `serious` edge.

Findings:

- V1.2 mostly solves the Camp-first problem, but only if presentation and action salience are implemented correctly.
- Before M4, the player knows equipment and power; Camp A is a known-solution extension while Prison A is a new treasure concept.
- V1.2 works because Prison A is framed as a low-cost/no-punishment first attempt, matching the action rule that new no-cost actions are likely to be tried.
- After Prison A failure, Camp A's `+30%-50%` power gain hits the wake threshold and naturally points back to Prison A.
- M5 can establish first-layer role knowledge only if the role changes a visible process metric, not just win/loss.

Modification constraints:

```text
M4 camera and first selection must land on Prison A.
Camp A can be visible, but should not flash, default-select, or foreground reward preview before Prison failure.
Prison A first failure message must be power/equipment attribution only.
Camp A before Prison failure is weak/medium salience; after failure it becomes strongly highlighted.
```

Fallback trigger for V1.3:

```text
If playtesters often choose Camp A first,
or say "prepare gear first is smarter",
or treat Prison A as high-risk instead of low-cost,
or clear Camp A without returning to Prison A,
then make Camp A preview-only until Prison A failure.
```

### Agent B: V2 Rarity Gating

Severity: `minor`.

Findings:

- If V1.2 holds, narrow V2 can enter.
- Rarity must mean reward-quality expectation only.
- Safe nodes:
  - M4 Camp A preview: `高等级白装 + 1 蓝装`, weak/medium salience.
  - after Prison A failure: Camp A highlighted as equipment key.
  - Camp A reward: first blue item as part of `+30%-50%` power jump.
  - M6 first clear: blue item to reinforce hard node / branch reward quality.
- Unsafe:
  - M1-M3 rarity teaching.
  - M5 rarity teaching.
  - Boss A purple strong preview.
  - any expression that blue item is required to clear Prison A.
  - affix/optimization/build discussion.

V2 concept additions:

```text
concepts +蓝装
concepts +稀有度, only as reward signal
knowledge +营地/支线/难点首通更容易给高质量奖励
knowledge +蓝装通常更值得看, but not guaranteed best
```
