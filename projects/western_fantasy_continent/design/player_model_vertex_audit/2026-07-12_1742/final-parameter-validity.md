# 玩家模型参数有效性结论

## 验收口径

一个参数只有同时满足以下条件，才记为“有效”：

1. 设计变量变化后，参数方向按预期变化。
2. 变化幅度稳定，24 个配对随机种子下不翻向。
3. 参数变化能够进入情绪、反馈库存或行为，而不只是仪表盘数字。
4. 原版与调试版的可见时间线、输入和结算口径一致。

“公式敏感”只表示改系数会改输出，不等于心理假设已被验证。

## 总结

- 设计顶点：`21/30` 通过。
- 诊断值会变但没有体验/行为作用：`9/30`。
- 27 个数值系数均可执行，但多数尚未获得心理标定证据。
- 相比只计算 `R - 时间衰减` 的简化模型，复杂模型额外识别了 4 类变化：完整决策链、感知清晰度、无效重复、不可理解度。
- 两种模型都看不见的 9 类变化：显著性、目标相关性、Agency 的 7 个子参数。

## P：过程投入

| 参数 | 结论 | 顶点证据 | 主要问题 |
|---|---|---|---|
| `W` 无决策过程时长 | 有效但过耦合 | 降低敌人生命、缩短接敌路程均令 W/P 下降、库存上升 | W 同时增加 P、提高预期结果、触发负 A，并参与库存时间衰减，长流程被重复惩罚 |
| `E.Decision` | 有效 | 加入 problem→cause→behavior→hypothesis 后 E/P/Q 与总体验上升 | 目前由数组声明，不受“玩家是否看见/理解证据”约束 |
| `E.Verify` | 有效 | 可比较且命中目标时 EVerify、verificationR、R 上升 | 未形成知识置信度更新，只改变本局分数和通用继续理由 |
| `P = 0.35E + 0.4W` | 有效但需重构 | 三类 P 顶点方向稳定 | 决策 E 与无效 W 被塞进同一个总量，随后共同推高预期，语义混杂 |

## Q：过程质量

| 参数 | 结论 | 顶点证据 | 主要问题 |
|---|---|---|---|
| `baseWithDecision` | 公式有效，心理未标定 | 系数敏感测试通过 | 仅有决策链就固定获得正底值，未检查链条证据质量 |
| `noDecisionBase` | 公式有效，心理未标定 | 从 0 调高会改变 Q | 当前为 0，普通战斗的正向打击过程几乎无法进入 Q |
| 感知清晰度 `perceptual` | 有效 | 0.2→1 时 Q 与总体验上升；简化模型看不见 | 对 EDecision、知识置信度和行为没有门控作用 |
| 因果清晰度 `causal` | 有效但重复计权 | 0.2→1 时 Q、progressionR、A、总体验均上升 | 同时进入 Q、R 和 H，存在多次计权 |
| 进度可读性 `progressReadability` | 有效但重复计权 | 0.15→1 时 Q、progressionR、总体验上升 | 同时奖励过程与结果；应明确这是有意双通道还是重复 |
| 无效重复 `deadRepetition` | 有效 | 0.9→0 时 Q 与总体验显著上升；简化模型看不见 | 不影响疲劳、换行为或放弃，只影响单局分数 |
| 不可理解度 `incomprehension` | 有效 | 0.9→0 时 Q 与总体验显著上升；简化模型看不见 | 不会降低 EDecision、归因置信或下一步行动，认知语义未接通 |

## H：信号接收

| 参数 | 结论 | 顶点证据 | 主要问题 |
|---|---|---|---|
| `perceptual` | 输入有效，但不是通过 H 生效 | Q 感知清晰度顶点 | 直接进入 Q；H 的乘积结果没有负责传递它 |
| `causal` | 输入有效，但不是通过 H 生效 | Q 因果顶点 | 直接进入 Q/R；H 本身冗余 |
| `salience` | 无效 | 0.15→1 只改变 H，总体验与行为为 0 变化 | 没有任何下游路由 |
| `goal relevance` | 无效 | 0.15→1 只改变 H，总体验与行为为 0 变化 | 没有影响注意、结果价值或行动选择 |
| `H = salience×perceptual×causal×goal` | 当前冗余 | 两个 H 顶点均为 diagnostic-only | 保留为诊断值可以，但不能宣称已参与玩家模拟 |

## R：结果反馈

| 参数 | 结论 | 顶点证据 | 主要问题 |
|---|---|---|---|
| 进度量 `progression` | 有效 | 0.4→2 时 progressionR/R/A 上升 | 依赖 causal 与 progressReadability，需防止和 Q 重复解释 |
| 进度新鲜度 | 有效 | 0.2→1 时 progressionR 上升 | 与事件新鲜度、验证新鲜度名称混杂 |
| 典型伤害 `gTypical` | 有效 | 20→30 伤害时稳定上升 | 微小随机波动也会形成正负成长，缺感知死区 |
| 攻击频率 `gFrequency` | 有效 | 固定 12 秒训练波次内 1/s→2/s，W 不变，频率成长与 R 上升 | 固定高血目标令绝对 `impact` 偏低；需要按测试目标建立匹配基线 |
| 峰值伤害 `gPeak` | 有效但不纯 | 固定时长加入规律爆发后峰值成长与 R 上升 | 爆发也会自然提高平均占血比，和 impact 有合理联动 |
| 单击主观冲击 `gImpact` | 方向有效、定义不完整 | 固定时长内目标 200HP→100HP，单击占血比提高，R 上升 | 目前只有“掉血比例 b”，缺少用户提出的“敌人认知强度 a”，跨敌人比较会失真 |
| 基线置信度 | 有效 | 0.2→1 时同一成长的 growth.value 上升 | 没有驱动继续验证或更新知识 |
| 成长事件新鲜度 | 有效 | 8 次重复→1 次时 growth.value 上升 | 只按 signal repetitions 近似，事件族归类尚未进入主流程 |
| 验证奖励 | 有效 | 假设确认后 verificationR 上升 | 与 EVerify 同时奖励，需确认双重奖励是设计意图 |
| 验证新鲜度 | 有效 | 0.2→1 时 verificationR 上升 | 与其他新鲜度相互独立但报告命名不清 |
| `otherResult` | 可执行但过宽 | 0→2 时 R/A/体验上升 | 无类型、无来源、无新鲜度，是容易掩盖建模缺口的万能口袋 |

## A：预期差

| 参数 | 结论 | 顶点证据 | 主要问题 |
|---|---|---|---|
| 正向 mismatch | 有效 | 同时长增加额外结果后 mismatch/A/体验上升 | 当前固定 `k`，不是玩家从历史学到的交换率 |
| 负向 mismatch | 有效 | 同时长移除进度并倒扣结果后 mismatch/A/体验大幅下降 | 负反馈明显强于正反馈，方向合理但强度未标定 |
| `k` 预期交换率 | 公式有效，心理无效 | 系数敏感测试通过 | 固定 k 令普通长战斗普遍产生强失望；缺少来源、更新和冻结逻辑 |
| 正/负 scale | 公式有效，待标定 | 系数顶点通过 | 目前主要证明能调，不证明数值符合人类体感 |
| 正/负 power | 条件有效 | 在大 mismatch 场景方向正确 | 当 `|mismatch|<1` 时幂次增大反而缩小绝对值，不能用“更大就更强”理解 |

## Agency：目标感与行动性

| 参数 | 结论 | 顶点证据 | 主要问题 |
|---|---|---|---|
| desire | 仅诊断 | Agency value 会变，总体验/行为不变 | 未进入行动排序 |
| gap | 仅诊断 | 同上 | 未进入继续投入或目标强度 |
| problem clarity | 仅诊断 | 同上 | 未影响归因、假设形成或 Q |
| path visibility | 仅诊断 | 同上 | 未约束可选行为 |
| causal control | 仅诊断 | 同上 | 未影响行为 ROI 或验证策略 |
| expected improvement | 仅诊断 | 同上 | 未进入下一行动得分 |
| perceived cost | 仅诊断 | 同上 | 未进入 P 或候选行为比较 |
| Agency 总值 | 当前无效 | 7 个顶点全部保持相同 nextAction | 计算存在，但没有接到行为系统；这是整组参数未完成，不是数值平衡问题 |

## 反馈库存与行为

| 参数 | 结论 | 证据 | 主要问题 |
|---|---|---|---|
| `initialFeedbackStock` | 可执行 | 系数敏感测试通过 | 只是起点，尚无玩家类型/历史依据 |
| `stockDecayPerSecond` | 可执行但和 W 重复 | 系数敏感测试通过 | 时间既通过 W/A 惩罚，又直接扣库存 |
| `abandonThreshold` | 可执行 | 人工跨阈值时 continue→abandon | 30 个自然顶点中 nextAction 几乎恒定，阈值没有形成真实行为区分 |
| `nextAction` | 当前不足 | 两位盲玩 Agent 均指出几乎所有版本都继续 | 缺候选行为、知识、归因、Agency 路由和概率行为 |

## 新鲜度与对数幅度模块

| 参数 | 结论 | 证据 | 主要问题 |
|---|---|---|---|
| `freshnessLambda` | 公式有效 | 重复次数顶点通过 | 主场景只影响成长新鲜度，未统一进度/验证/概率事件 |
| `familyFreshnessWeight` | 仅独立函数有效 | magnitude sequence 系数测试通过 | 尚未接入 `simulateScenario` 的事件循环 |
| `magnitudeSurpriseWeight` | 仅独立函数有效 | 同上 | 尚未接入主场景 |
| `breakthroughWeight` | 仅独立函数有效 | 同上 | 尚未接入主场景 |
| `baselineAlpha` | 仅独立函数有效 | 连续幅度序列会更新期望基线 | 尚未接入主场景和知识状态 |

## 两位盲玩 Agent 的共同判断

1. P/Q/R/A 的局部方向大多可信。
2. 固定 k 令 A 在普通战斗中异常主导，尤其长战斗。
3. W 被同时用于投入、预期与库存衰减，存在重复惩罚。
4. H 与 Agency 是最明确的“有数值、无后果”。
5. EDecision 不受可见证据约束，玩家可以在不可理解时仍获得完整推理链。
6. 成长变化没有形成知识、假设或下一步行为。
7. 当前模型能评分一局，但还不能模拟一个会学习和改变行为的玩家。

## 最终裁决

- **应保留并继续标定**：W、EDecision、EVerify、Q 的五个子项、R 的进度/成长/验证子项、A 的正负差异。
- **应重构而不是删除**：P 总量、W 到预期的映射、k、反馈库存、nextAction、新鲜度命名与事件族。
- **必须接通后重测**：H.salience、H.goal、Agency 全组。
- **暂时降级为实验模块**：对数幅度的四个系数；在进入主事件循环前，不计入正式玩家模型能力。

因此，复杂模型不是“全是无用参数”：它确实比简化模型多识别了决策、清晰度、重复和不可理解四类体验。但复杂度中约三分之一仍停留在诊断层，尚未转化为玩家情绪或行为能力。
