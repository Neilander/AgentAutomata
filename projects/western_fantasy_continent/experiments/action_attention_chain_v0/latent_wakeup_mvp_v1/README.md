# 语义唤醒动作粘合 MVP V1

目标：验证AI只根据玩家可见UFS规则设置一次注意力预设和记忆预设后，运行时能否统一完成：

`动作 → 注意区域 → 局部对象变化 → 语义Top-K召回 → 通用事实校验 → 粘上下一动作`

本实验禁止在冻结模型中出现测试场景ID、坐标、随机上游名称和测试用角色改写词。运行器也没有“如果是箭头就右移”等对象分支；各规则的目标概念、触发经验、必要事实和后续动作都作为玩家读规则后形成的记忆预设存在。

召回不是只取Top-1：对象概念明显不相似时拒绝；剩余Top-K按对象语义和变化趋势排序，再逐条检查动作事实。这样“母舰下降格”和“骷髅行”可以同时被联想到，但当前行动者是飞船时，骷髅规则不会粘上，下一条母舰下降规则仍有机会通过。

运行时召回已经矩阵化。所有记忆的对象例句和变化原型预编译成一个扩展矩阵；当前对象与趋势拼成1536维查询，一次矩阵乘法同时得到全部对象例句的激活和对象门槛分，再按记忆归并、应用Top-K和事实遮罩。逐条算法只保留在测试中验证数值等价，不参与实际动作选择。

注意力暂时使用AI第一次编译值：移动时看主体、起点、整条路径、终点和其中图案；终点图案显眼度1.0、路径图案0.45，只有终点图案可以形成后果候选。数值以后再反复调试。
