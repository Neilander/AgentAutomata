# 可增量修订的规则实例化程序 v0

目标：验证一条由AI从规则生成的小程序，能否覆盖同结构下的大量参数变化；当新例外规则出现时，能否只追加小补丁并保持旧案例不回归。

基础程序只表达：放置骰子后，选择同列飞船并按骰子点数下降。随后按冻结顺序加入五条规则：防空房减一、冻结飞船不动、重型飞船距离减半、加速飞船在所有修正后加一，以及聚焦房只保留最靠近城市的并列目标。最后一条故意超出原本只能逐对象判断的能力，要求给语言增加通用的目标组归约步骤。

程序不是任意Python代码，而是受限的声明式结构：触发条件、变量绑定、目标选择、局部变量和状态效果。补丁只允许替换绑定、追加筛选条件或包装现有表达式。每个补丁必须引用冻结规则原文。

`preview`在公开状态副本上封闭试运行，不修改输入，并记录实际读取过的状态路径。这些读取路径可以在下一步转换成连续设想控制器消耗的注意点。

当前验证由同一个AI编写基础程序和四个补丁，因此证明的是“这种结构可以参数泛化且可以增量组合”，不是“陌生Agent已经能盲目自动修程序”。后者需要下一轮隔离盲测。

运行：

```powershell
.\run-local.ps1
```

完整逐版本程序、失败样例和950个生成案例结果写入`artifacts/validation.json`。
