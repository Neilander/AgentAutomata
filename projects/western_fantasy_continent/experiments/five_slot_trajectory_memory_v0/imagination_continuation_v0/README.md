# 连续设想与停止条件 v0

这是五槽轨迹记忆之后的隔离控制器，不负责召回记忆，也不执行游戏规则。它接收已经被召回并完成事实举证的后果，决定当前设想是否继续粘连。

## 两道门

1. 结构门由轨迹来源声明后果种类：`automatic`、`choice`、`random`、`unknown`、`complete`。同一事件可以有多个并行后果；一个随机分支不会阻止其他确定分支继续。
2. 认知门逐个检查该后果内部的注意点。每个注意点都消耗注意力；熟悉轨迹成本下降但不归零。预算不足时输出`attention_stop`，且不会错误地产生尚未想到的下一事件。

目标暂存为：对象概念、状态概念、期望方向、紧急度和时间范围。直接目标匹配只负责调整并行后果的检查顺序；它不会修改客观规则，也不会凭空增加预算。当前精确概念匹配是可替换接口，之后可接向量或规划模型。

## 重要边界

- 这里的数值是结构测试脚手架，尚未声称为真实人类参数。
- `random`保留已知范围，但不编造一次具体结果。
- `unknown`说明需要查询什么；实际查到规则后，可以从新事件重新进入控制器。
- `choice`把控制权交还决策模块。
- 正常结束必须召回一条明确的`complete`轨迹，例如“普通格没有即时效果”。什么都没召回到不能假装安全，会输出`unknown`，以区分真实无后果和记忆缺失。
