# UFS 可调注意力空间 v0

这是一个隔离模块，只负责：

`完整公开状态 → 动作初始注意 → AI复盘调整 → 有限预算 → 实际注意到的公开事实`

它不选动作、不预测结果，也不读取引擎隐藏状态。

## 四个组成部分

1. `UfsAttentionSpace`：把真实 UFS 公开观察拆成可寻址的状态部分，包括骰子、飞船、天空格、基地格、房间和公开轨道。未被重点关注的内容仍以低激活留在空间里。
2. `UfsAttentionProfile`：保存 AI 复盘产生的增加、降低、沿公开关系扩展和撤销调整。每个调整都有阶段/动作/目标作用域和原因。
3. `AttentionFieldBuilder`：把背景、动作初始预设和当前作用域内的调整相加，得到每个公开状态部分的 `0..1` 激活度，并保留每一项贡献的审计记录。
4. `AttentionBudgetAllocator`：根据 `0..1` 玩家注意力等级，确定本次真正进入后续设想的项目数量；输出 `gist / clear / precise` 三档清晰度。

## 当前 `place_die` 初始预设

初始重点是：本颗骰子、目标基地格、所属房间、目标列飞船，以及这些飞船在本次数值下预计经过的天空格。伤害、能源、研究等公开轨道仍存在，但默认只保持弱背景激活。

AI 复盘之后可以调用：

- `increase_attention(...)`
- `decrease_attention(...)`
- `expand_attention(...)`
- `remove_adjustment(...)`
- `inspect_attention(...)`

规则阅读阶段还可以调用 `define_initial_attention(...)`，为新的阶段或动作建立初始预设。因此模块并不只认识写死的 `place_die`；当前内置放骰预设只是第一个经过测试的 UFS 样例。

例如，玩家因白骰导致剩余骰子重掷而吃亏后，可以只在 `dice + place_die` 作用域中提高“所有未放置骰子”的注意；不会永久把所有阶段的骰子都调高。

## 验证

```powershell
.\run-local.ps1
```

验证使用真实 Roswell 公开快照，覆盖：完整公开空间、隐藏信息隔离、输入不可变、初始窄注意、增加/降低/扩展/撤销、作用域隔离、审计来源、有限预算单调性和答案字段拒绝。

## 尚未声称的部分

- 初始激活常数和注意容量只是明确可调的测试参数，还没有人体实验标定。
- 当前预算采用确定性的按激活排序截取，不模拟眼动、疲劳或随机漏看。
- AI 复盘如何从一次失败自动写出调整，属于下一层；本模块只提供安全接口。
- 本模块尚未接入 UFS 玩家选择器，先隔离验收。
