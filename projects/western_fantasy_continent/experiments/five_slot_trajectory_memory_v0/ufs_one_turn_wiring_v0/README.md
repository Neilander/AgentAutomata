# UFS 一回合五槽记忆接线 V0

这个隔离实验连接三件事：

1. 用UFS安全公开观察和合法动作，把通用规则轨迹中的“该骰子、该列、该飞船”绑定成当前真实对象；
2. 当前候选动作先查询五槽记忆，向量只取Top-3，公开事实只能在这三个候选内二次校验；只有选中的记忆后继才会被物化到假想世界，新落点继续查询直到停止；
3. 用显式目标权重比较所有候选的预想结果，选出更接近目标的一项。

玩家端只接收`publicObservation`、`publicLegalActions`和公开地图。验证器在玩家完成全部预想和选择之后，才另行调用正式引擎取得真实后果进行对照。

当前`PlanningGoal`同时读取即时风险和延迟收益：城市伤害、母舰前进、飞船接近城市、随机性、能源变化、研究推进、击毁飞船、挖掘推进和多格房准备分别有公开权重。它只用于验证结果比较接口，不代表最终玩家价值观。

灰骰和白骰的全部合法位置都会参与排名。白骰附带的重掷被记成“已知会发生、具体新点数未知”的随机后果；比较时承担不确定性成本，但绝不会读取或猜定引擎未来随机数。

运行：

```powershell
.\run-local.ps1
```

当前验证使用3个真实开局，共208个合法放置，产生704次记忆唤醒。除了即时天空后果，还唤醒多格房准备30次、挖掘43次、战斗机15次、无延迟收益105次、研究15次。所有208个即时状态和208个未来房间收益都与选择后再运行正式引擎/立即进入房间阶段的反事实结算一致。空记忆消融无法展开任何后果，证明物化器不会绕过记忆自行运行。

这证明“一次放骰的对象绑定、立即后果、延迟房间收益和目标比较”已经接通。未来房间收益是“如果相关状态不再变化、随后结算”的当前投影；后续骰子仍可能改变飞船位置、能源、研究顺序和多格房完整性。初始场景也没有覆盖撞城，不能把208/208解释成完整UFS玩家已经完成。
