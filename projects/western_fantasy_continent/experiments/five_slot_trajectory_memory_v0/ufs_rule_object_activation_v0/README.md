# UFS 规则驱动对象激活实验 v0

目标：验证一句规则能否通过真实 GTE 向量，在当前可见对象中直接激活正确对象，而不是程序先写死“同列/同房间/白色”等筛选条件。

测试覆盖十类情况：等值空间关系、复合空间关系、距离关系、最终落点与途经的区分、容器归属、状态类别、属性类别和数值阈值。每个案例使用多种自然语言说法。

评测同时报告三种口径：

1. 正确对象是否整体排在错误对象之前（成对排序准确率）。
2. 已知正确对象数量时，Top-K 是否完全正确（只测排序能力，不代表运行时知道数量）。
3. 不知道数量时，能否靠排序中的最大断层自动选出整组（可部署但可能失败）。

每项都同时测两种候选范围：`全局混合对象`包含骰子、飞船、格子、轨道等干扰；`注意力池`则假设上一层注意力已经把范围缩到本动作要扫描的对象类别，例如天空中的飞船。后者更接近“在注意力区域内绑定对象”的真实位置，但池中仍保留同类错误对象，绝不按答案过滤。

耗时分开记录模型首次加载、对象向量缓存的首次构建、每条新规则的在线编码，以及缓存后一次矩阵激活。候选规模测试只测缓存向量矩阵运算，不能误解成十万条自然语言的首次编码耗时。

```powershell
.\run-local.ps1
```
