# UFS教程规则 → 五槽轨迹隔离实验 v0

目标：验证AI逐句读教程后，能否把规则拆成独立的五槽 `q当前 → q后续`，并在缺参数、分段粘连、随机结果和规则缺失时不自行补全。

每个 `q` 始终只有：

```text
[
  受影响对象,
  变化趋势,
  原因关系,
  时间状态,
  上下文
]
```

## 当前结构

- `NumericRelation`：保存“结束行 = 开始行 + 骰子点数”这类可换起点复用的关系，不执行任意代码。
- `RuleTrajectoryDraft`：一个AI产生的五槽连接；必须引用冻结原句，不能加入原文没有的具体阿拉伯数字。
- `ready`：已有可靠 `q后续`，可以进入五槽记忆。
- `unresolved`：教程只说“结算图标”却没说明图标效果时，不造 `q后续`；保留“需要查看什么”。
- `RuleHeadIndex`：用一次矩阵乘法同时检索可执行头和未解决头。未解决头被唤醒时返回查规则，不拿相似的其他规则顶替。
- `CandidateEvidence`：向量只提出候选行；Agent必须对五槽逐项引用当前查询里的证据。存在矛盾或未知就不能采用该后续。
- `AdaptiveNumericOutcome`：保存随机结果的大概中心、常见范围和观察范围；旧经历逐渐衰减，近期经历可以移动预期。

## 六条规则样例

见：

- `source_rules.json`：冻结的六句教程规则。
- `ai_compiled_examples.json`：当前AI只依据这些短句生成的六条轨迹草稿。

覆盖：

1. 放骰 → 同列飞船下降，下降距离绑定骰子点数。
2. 最终停在箭头 → 横移；它没有被提前写进“飞船下降”轨迹。
3. 放白骰 → 剩余骰子重掷，具体新点数保持未知。
4. 母舰下降 → 当前行图标效果未知，轨迹停在查规则出口。
5. 飞船到城市 → 城市受伤、飞船进等待区。
6. 飞船停在爆炸数字格 → 即时移动链停止。

## 验证结果

运行：

```powershell
.\run-local.ps1
```

- 结构/边界单元测试11/11通过。
- 真实GTE对10种不同措辞Top-1找回10/10。
- 两段独立轨迹成功按局部状态粘合：`放骰→下降`，注意到最终箭头后再唤醒`箭头→横移`。
- 变量关系在`开始行2 + 点数3`和`开始行8 + 点数3`上分别得到5和11。
- 随机结果先经历`1,1,2,1,2`，预期中心1.54、常见1～2；随后近期连续八次5，中心移动到4.83、常见5～5。
- 重复验证同一箭头连接三次后，观察数和支持度均从1增加到3。

## 一次重要失败与修正

纯向量检索把：

> “飞船只是经过箭头，最后停在普通格”

以0.847高相似度错误匹配到“最终停在箭头后横移”。这证明embedding不能可靠处理否定词。

当前修正不是给向量偷偷加答案，而是恢复之前确定的两步机制：

1. 矩阵提出最相似的轨迹行。
2. Agent对五槽逐项举证；该反例五槽均与“最终停在箭头”矛盾，因此拒绝采用。

另一个反例“母舰进入陌生图标”在只索引ready轨迹时误联想到箭头；把`unresolved`头也放入同一矩阵后，它以0.822找到母舰未知图标头并返回查规则。

## 诚实边界

- 这批AI草稿由当前AI一次性生成，不是另一个独立模型的盲测。
- 程序能证明草稿结构完整、引用来自原句、没有偷偷补具体数字；不能只靠字符串证明所有自然语言概括都被原句逻辑蕴含。
- 五槽逐项举证目前验证了接口和正反样例，下一步需要让真实玩家Agent在隔离输入下自行提交证据。
- 本实验尚未接入完整UFS玩家。
