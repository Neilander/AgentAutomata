# 硬轨迹记忆矩阵检索实验

目标：验证“不训练长期模型，只保存注意力局部环境的状态轨迹；新变化出现时用一次矩阵相似度查询相近轨迹片段，并由多条相似经历共同预测下一方向”是否可行。

运行时没有对象分支、规则条件或逐条记忆循环。每个可续接轨迹片段预编译成一行，最终由开发集选择出的表示为：

```text
片段签名 = [当前状态坐标 × 0.5, 当前状态-上一状态的方向 × 0.5]
全库相似度 = 片段矩阵 × 当前查询
后续 = Top-K中彼此相近的硬轨迹后继状态共同佐证
```

## 冻结结果

- V0：58个一次性留出案例为42/58；已知规则40/48，多步6/7，跨轨迹组合成功，但陌生规则只拒绝2/10，矛盾经历不会正确降信心。
- V1：在不改变矩阵检索的前提下增加低确定度拒绝和矛盾证据支配度。新的一次性37例为32/37；已知正例11/15、已知无后续10/10、陌生规则拒绝11/12；同终点不同来向4/4，多步6/6，原轨迹重放102/102。
- 50,082片段的一次矩阵查询中位数约9.9ms。
- 直接把旧箭头平移成新未来坐标只有46.6%，因此通过的是“相似轨迹检索与续接”，不是“任意语义箭头可作向量代数”。

证据文件：`artifacts/frozen_config.json`、`artifacts/frozen_results.json`、`artifacts/frozen_config_v1.json`、`artifacts/frozen_results_v1.json`。冻结评测脚本默认拒绝重复运行，避免看到答案后继续调同一批案例。

当前没有接入UFS或正式玩家模拟。下一步应把它作为“注意到局部变化之后的动作链唤醒器”接到公开观察层；规划/策略选择仍由Agent负责。
