# 高维符文猜测 V0

这个隔离实验验证一件事：能否把一维“猜数字”推广成在连续语义空间中寻找角色。

## 边界

- 不接正式玩家 Agent。
- 不修改 `cognitive_gameplay_lab_v0`。
- GTE 模型与 Python 依赖位于 worktree 外的 Git 忽略目录。
- 角色坐标只由玩家认知到的机制描述生成；角色真值标签只用于回答问题和评估，不进入向量生成。

## 两层验证

1. **真值坐标**：用已知标签生成 0.95/0.05 概率，验证九个问题轴能否唯一找到四十个角色。
2. **GTE 坐标**：用独立的正反语言锚点建立语义方向，再检查角色描述在各方向上的投影是否符合真值。

这能区分“多维猜测算法不成立”和“预训练 latent space 没有稳定表达某个语义方向”。

## 当前问题轴

直接治疗、护盾、减伤、强制阻止死亡、控制、爆发输出、持续输出、位移、禁止治疗。

其中两个候选故意使用相同的技能名“锁血”，但一个表示阻止死亡，另一个表示禁止治疗，用来检查上下文能否覆盖词语先验。

## 运行

```powershell
powershell -ExecutionPolicy Bypass -File .\run-local.ps1
```

输出写入 `artifacts/latest_results.json`。
