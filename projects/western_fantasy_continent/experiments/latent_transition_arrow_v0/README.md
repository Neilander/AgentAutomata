# 高维变化箭头普适性实验 V0

这个隔离实验只验证一件事：`结束状态向量 - 开始状态向量`形成的箭头，能否跨主体、跨游戏语境保留同一种变化关系。

## 两个核心实验

1. **箭头识别**：把一个游戏语境留出，用其他语境的箭头形成关系原型，检查留出箭头能否被识别为同一种变化。
2. **箭头搬运**：把其他主体的箭头加到新主体的开始状态上，在四个同主体候选终点中寻找正确终点。

候选终点始终包含正确变化、保持原状和两个无关变化，因此不能仅靠主体词相同通过。

## 数据规模

- 核心集：6个变化家族、12个有方向关系、96条变化。
- 扩展集：12个变化家族、24个有方向关系、192条变化。
- 每个关系跨8种游戏或任务语境。

扩展集同时测试原始空间，以及移除前1、3、5、10个公共主方向后的空间。每种空间都比较单箭头、多个箭头直接平均、多个方向平均，以及只用训练语境选择步长的方向搬运。

另外固定测试所有关系共用的2倍、3倍步长，防止把“每种关系单独调参”误判成普适箭头。

最后把正确终点混入全部状态组成的候选池，比较箭头搬运和“起点不动”时的全局检索排名，避免只在简单四选一里得到虚高结果。

实验还会记录1至7根参考箭头的学习曲线，检查更多跨语境实例能否逐渐抵消单个主体带来的偏差。

```powershell
.\run-local.ps1
```
