# 高维变化箭头普适性实验 V0：结果

## 一句话结论

GTE的768维句向量里确实存在跨主体、跨游戏语境的变化方向；**方向具有很强普适性，单条箭头的长度和局部噪声不稳定**。多条箭头先归一化再求共同方向，能显著恢复搬运能力。

## 文献对齐

- 词向量中的线性关系并非纯演示技巧，已有工作从概率语义关系解释了某些类比为何形成近似平行四边形：<https://proceedings.mlr.press/v97/allen19a.html>
- 句向量也可能包含类比规律，但不同模型、不同关系差异很大，不能从词向量结果直接推定：<https://aclanthology.org/2020.coling-main.300/>
- 单一词对的偏移非常容易被主体自身特征污染；多个同关系词对求平均能明显改善结果：<https://aclanthology.org/C16-1332/>
- 传统类比题会混淆“同类偏移聚集”和“正确配对可搬运”，因此本实验将两者拆成两个实验：<https://aclanthology.org/2020.conll-1.29/>
- BERT类空间常有公共方向偏斜，移除少量主方向可能改善几何性质：<https://arxiv.org/abs/2104.05274>

## 数据

- 核心集：6个变化家族、12个有方向关系、96条变化。
- 扩展集：12个变化家族、24个有方向关系、192条变化。
- 每个关系包含8个不同游戏或任务语境。
- 变化包括接近／远离、下降／上升、获得／失去、启动／关闭、进入／离开、显露／隐藏、增强／削弱、连接／断开、阻塞／疏通、保护／暴露、消耗／恢复、打开／关闭。
- 箭头分类与搬运都排除和目标相同的语境；结果不是在原句改写上测试。

## 实验一：箭头是否能识别同一种变化

扩展集原始空间结果：

| 指标 | 结果 |
|---|---:|
| 24类跨语境Top-1 | 87.50% |
| 随机机会 | 4.17% |
| 平均倒数排名 | 0.9200 |
| 同关系箭头平均余弦 | 0.3998 |
| 不同关系箭头平均余弦 | -0.0206 |
| 相反关系箭头平均余弦 | -0.4748 |

同一种变化的箭头明显聚集，相反变化则明显指向相反方向。24种关系的单类召回均不低于75%。这部分可以判定通过。

## 实验二：箭头能否搬到新起点

四候选测试同时保留“状态不变”作为竞争终点：

| 方法 | Top-1 |
|---|---:|
| 随机机会 | 25.00% |
| 随机拿一条其他主体箭头 | 34.38% |
| 多条原始箭头直接平均 | 27.08% |
| 多条箭头先归一化，再求共同方向 | 64.58% |
| 共同方向，所有关系统一放大2倍 | 96.35% |
| 共同方向，所有关系统一放大3倍 | 96.35% |
| 只用训练语境选择步长 | 96.88% |

关键不是学习24套复杂参数。所有关系共用2倍步长已经达到96.35%，说明主要问题是归一化句向量中的变化箭头普遍太短，仍然过度保留起点。

参考箭头数量增加时，1倍共同方向表现单调上升：

| 参考箭头数 | Top-1 |
|---:|---:|
| 1 | 34.38% |
| 2 | 45.73% |
| 3 | 52.56% |
| 4 | 57.14% |
| 5 | 59.67% |
| 6 | 61.90% |
| 7 | 64.58% |

这直接支持“多次经历形成更稳定变化原型”：主体噪声被逐渐抵消，共同趋势被保留。

## 全局候选池复核

把正确终点混入383个候选状态，并排除起点本身：

| 方法 | Top-1 | Top-5 | 中位排名 |
|---|---:|---:|---:|
| 起点不动 | 53.13% | 89.06% | 1 |
| 原始空间，1倍共同箭头 | 94.27% | 99.48% | 1 |
| 去掉1个公共方向，1倍共同箭头 | 96.35% | 98.96% | 1 |

这里1倍优于2倍、3倍，因为候选池已排除“不发生变化”；继续放大会越过正确终点。四选一保留“不变状态”时则需要约2倍，才能让变化压过起点惯性。

## 空间校正

- 只去掉第1个公共主方向：箭头识别率不变，四选一准确率不变，但正确答案的平均领先幅度增加；全局Top-1从94.27%升至96.35%。
- 去掉3个以上公共方向：识别和搬运都下降。
- 因此只保留`ABTT-1`作为可选轻校正，不能把“去公共方向”做成越多越好的固定清洗。

## 对玩家模型的意义

变化趋势可以先作为高维箭头使用，但用途应分开：

1. **唤起预设动作**：使用归一化方向与记忆中变化原型做相似度匹配。这部分证据最强。
2. **经验固化**：同类变化每出现一次，加入原型方向；多次经历会自然提高稳定度，形成路径依赖和更低成本的召回。
3. **预测精确终点**：不能只靠箭头。是否允许“不变”、移动多少、是否跨过规则边界，仍需要动作规则与状态演算。

因此最合适的结构不是“一个动作永远等于一根固定箭头”，而是：

```text
当前状态变化产生一条局部箭头
→ 与多个经历形成的共同方向匹配
→ 唤起动作—注意力预设
→ 由预设中的规则程序计算具体后果
```

## 风险

- 数据是受控中文游戏状态句，不代表任意长文本、任意语言同样成立。
- 每类目前只有8个语境；已看见稳定学习曲线，但还没有测试几十次经验后的饱和点。
- 候选终点由明确状态句构成；真实游戏信号需要先经过已有感知整理层，才能形成可比较的前后状态。
- 结果证明GTE里有可用的工程几何结构，不证明人脑真的以相同768维坐标执行。
