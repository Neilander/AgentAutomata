# 局部变化唤醒下一动作预设实验 V0

本实验验证的不是规则执行，而是三段式召回：

1. 动作注意力先确认真正受到作用的对象；
2. 局部场景前后状态形成变化箭头，并识别其属于接触、下移、加热、移除或观察；
3. 在受影响对象的记忆中，用局部变化箭头匹配各预设积累出的触发箭头原型，召回下一条动作—注意力预设。

例如：飞船下降只先改变飞船位置；落点与炸弹重合后，才构造“接触”局部变化，并将它搬运到炸弹，尝试唤醒“检查触发条件 → 预想爆炸 → 关注爆炸范围”。

实验同时保留“当前状态坐标直接加箭头再找终点”的朴素对照。结果表明句向量编码器并不是解码器，直接点加法容易停留在原状态附近；箭头对箭头的触发记忆匹配更稳定。

向量不负责计算下降距离、爆炸伤害或合法性。没有终点接触、信息不足或没有已学预设时，合同要求保持不唤醒或疑问。
