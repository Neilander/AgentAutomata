# 基于玩家已学知识的猜角色实验 V1

本实验验证 GTE 是否能充当玩家的快速候选唤起器，而不是最终战斗计算器。

## 数据边界

- 输入来自冻结的两章22场真实模拟战斗。
- 角色知识由现有角色认知模型读取玩家可见战斗信号后生成。
- 不向 GTE 提供设计师技能数值、隐藏战斗权重或角色真实标签。
- 当前稳定身份为10名英雄与3类民兵，共13个候选。
- 角色名和职业不会进入向量检索文本，避免模型只凭“牧师”“法师”等预训练先验作答。

## 认知坐标

- 粗能力：输出、保护、团队增益三套独立前30%标尺。
- 细特点：治疗、护盾、群体输出、持续输出等实际观察形成的特点认知。
- 未观察到的特点保持未知，不补成零。

## 目标

自然语言线索先匹配玩家知识中的能力或特点方向，程序再使用该知识记录中的相对位置或认知程度缩小候选集合。评价重点是目标角色能否留在 Top-3/Top-5，而不是要求快速唤起层直接给出最终唯一答案。

GTE 不读取、比较或生成认知数值。它只把“回血”“挡伤害”“清一群怪”等自然语言问题匹配到玩家已经形成的知识方向；旧矩阵与特点认知负责该方向上的连续大小比较。

## 运行

```powershell
powershell -ExecutionPolicy Bypass -File .\run-local.ps1
```
