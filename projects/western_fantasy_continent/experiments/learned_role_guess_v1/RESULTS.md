# 基于玩家知识的猜角色 V1 结果

## 结论

基础快速召回链路通过：GTE 能把多数模糊问法匹配到玩家已经形成的能力/特点方向，再由旧矩阵和特点认知执行相对比较。经过最多6条线索，13个目标全部保留在 Top-3，符合“先想起少数候选、再展开细节”的职责。

这不是外部真实性验证。线索答案和候选坐标都来自同一份冻结玩家认知，因此当前证明的是认知内部的找人链路能工作，而不是这些角色在新关卡中一定真有用。

## 输入

- 冻结两章22场真实模拟战斗。
- 88个角色战斗样本、2219条玩家可见事件。
- 10名英雄与3类民兵，共13个稳定候选。
- 32条粗能力认知：输出、保护、增益。
- 16条细特点认知：治疗、护盾、群体输出、持续输出。
- 不读取设计师技能数值、隐藏战斗权重或真实职业标签。
- 角色名称和职业不进入GTE检索文本。

## 模糊问题理解

七个方向、每个三种问法，共21条：

| 口径 | 结果 |
|---|---:|
| 正确方向排第1 | 15/21，71.4% |
| 正确方向进入Top-2 | 19/21，90.5% |
| 正确方向进入Top-3 | 20/21，95.2% |
| 落在正确语义家族 | 20/21，95.2% |

六个Top-1错误中，五个属于上下位概念混淆：

- 总体输出 ↔ 持续输出；
- 总体保护 ↔ 直接治疗；
- 总体保护 ↔ 护盾。

唯一明显跨家族错误是“强化其他队友”被理解成总体保护。说明后续不应强迫GTE只选一个方向，应保留Top-K相关知识原子，并让注意力或后续问题消除粗细歧义。

## 猜角色

为了压力测试，本轮仍强制只使用GTE的Top-1方向解释，再由该方向上的认知坐标回答大小关系：

| 指标 | 结果 |
|---|---:|
| Top-1 | 8/13，61.5% |
| Top-3 | 13/13，100% |
| Top-5 | 13/13，100% |
| 平均目标名次 | 1.46 |
| 完美方向解释的平均名次 | 1.15 |

晨祷牧师在“总体保护比灰鸦战士强”“总体保护比赤潮狂战士强”两条有效线索后从第7升到第1。部分总体输出问法被误解成持续输出，因为很多角色没有持续输出知识，系统正确保持未知并没有强删候选，因此后续线索仍能恢复。

## 未知处理

治疗方向只有4个角色有形成过的知识，另外9个保持未知。一条治疗比较线索后：

- 9个未知角色仍全部保留非零概率；
- 未知角色得到相同的中性权重；
- 未知没有被当作“治疗为0”。

## 下一步

进入实验2前先保留本版，不继续为13角色追Top-1。实验2应把训练与判卷彻底分开：历史战斗生成玩家知识；未见敌队、未见种子和固定换人槽只用于验证。知识库提出“缺保护/缺输出/需要群攻”等思路，GTE召回Top-3，战斗引擎判断其中是否真有解。

未来队伍实验不枚举并记住全部116,280个四人有序无重复组合。只有玩家实际遇到或主动考虑过的队伍才形成团队认知块；未见组合由角色知识和已学组合关系临时估算。
