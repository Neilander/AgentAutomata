# 第二章第一轮玩家反馈分析

## 配对结果

- Player A：24 轮结束时未击败首领，最终情绪 `60.1431`。完成两名角色救援、两项场地试炼与汇流关，终局队伍为战士/骑士/牧师/游侠。
- Player B：第 20 轮首试击败首领，最终情绪 `69.7789`。终局队伍为骑士/牧师/法师/游侠。
- 两条轨迹都继承同一份第一章知识，使用同一 Frozen V3 心理模型与解析器；差异来自真实决策、掉落种子和队伍选择。

## 已通过的教学

- 两个 Agent 都主动换入骑士与牧师，并用真实战斗贡献确认护盾/治疗，而非只复述角色说明。
- 两个 Agent 都观察到护盾爆裂和王旗信号，并完成对应场地战斗。
- 两个 Agent 都正确观察到“获得装备不自动增加主动队伍战力”，并通过手动装备验证等级与空槽价值。
- Player B 能区分“低品质高等级装备”与“高品质低等级装备”，没有把颜色当成唯一排序。

## 失败轨迹的数学归因

Player A 的首领准备过程为：

```text
史诗装备后战力 548 -> 首领失败
补装到 777       -> 首领失败
补装到 1037      -> 首领失败
同队再次挑战     -> 首领失败
```

四次失败时敌方均 4 人存活。游侠一直贡献约 60% 队伍伤害；骑士和牧师合计伤害极低。因而问题不是“数值再多一点”，而是当前阵容的输出结构：

```text
通关能力 ~= 生存窗口 x 单位时间伤害
```

骑士与牧师继续吃装备主要扩大生存窗口，但首领战的伤害端没有被修复。Player A 在第 23、24 轮已把 `swap:2:hero_mage` 列为合法替代方案，说明信息足以让它最终接近正确归因；24 轮上限和仍有正收益装备共同延迟了换人实验。

## 发现的设计问题

1. 原固定史诗护符偏向骑士/牧师，继续强化了已经过量的生存端，和首领真正需要补足的伤害端相反。
2. 装备候选只显示自身适配分，不显示相对当前同部位的净提升，谨慎玩家出现了反复换装倾向。
3. 原首领在标准完整装备路径下过硬；静态模拟中正确装备后首通率仍只有约 `15%`。

## 第二版单变量组

- 保持 Frozen V3、正式技能、两个场地和前六关结构不变。
- 输入可读性：装备候选增加当前装备、当前适配分和 `fitDelta`，不自动配装。
- 史诗钥匙：固定奖励改为法强、奥术、节律、火焰增幅、暴击构成的四词缀火印护符，使掉落本身指向已有法师。
- 首领敌方章节缩放由 `1.38` 调整为 `1.32`。

第二版静态配对结果：相同标准成长队伍把史诗留在背包时首领通过率 `17.5%`，正确装备时 `72.5%`，绝对提升 `55` 个百分点。
