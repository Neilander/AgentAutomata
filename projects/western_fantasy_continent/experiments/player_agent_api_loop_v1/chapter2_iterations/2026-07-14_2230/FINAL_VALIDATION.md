# 第二章 Frozen 玩家验证结论

## 最终判定

第二章当前版本判定为 **PASS with risks**。设计、战斗数值、真实事件信号与 Frozen 玩家决策循环已经连通；两个独立最终版玩家都完成了双救援、双场地试炼、汇流、史诗配装与首领战。

## 设计结构

第二章采用双路交叉锁钥，不复用第一章的单向回头链：

1. 入口同时开放骑士救援与牧师救援，顺序由玩家决定。
2. 骑士路线继续通向护盾爆裂试炼，但低成本钥匙来自另一条路线的牧师。
3. 牧师路线继续通向王旗试炼，但低成本钥匙来自另一条路线的骑士。
4. 两项试炼共同解锁汇流关，固定给予 Lv.24 四词缀史诗火印护符。
5. 玩家必须手动换入角色、手动穿装，再以首领战验证角色与史诗适配。

## 静态锁钥验收

相同敌人、场地、装备与配对种子下：

| 锁钥 | 换入前 | 换入后 | 绝对提升 |
| --- | ---: | ---: | ---: |
| 护盾试炼：牧师 | 27% | 84% | +57pp |
| 王旗试炼：骑士 | 0% | 100% | +100pp |
| 首领：史诗留在背包 / 正确装备 | 17.5% | 72.5% | +55pp |

这些结果满足本章约束：前钥匙不高于 35%，后钥匙不低于 65%，提升不少于 35 个百分点。高等级装备仍可作为成本更高的异质解。

## 真实 Agent 反馈与迭代

第一轮 Player A 在首领前连续补装，战力从 548 增至 1037 仍四次失败。数学归因是：

```text
通关能力 ~= 生存窗口 x 单位时间伤害
```

该队已有骑士与牧师，继续强化生存没有修复伤害端；旧史诗还错误强化了生存。于是第二版只调整真实设计与信息：固定史诗改为法师输出向火印、装备候选显示相对当前装备的 `fitDelta`、章节首领缩放从 1.38 调到 1.32。Frozen 玩家模型没有为新版单独调参。

最终版 Player D：20 个决策完成全章，最终队伍为战士/骑士/法师/牧师，装备战力 983，情绪 68.9334；史诗给法师后首领首通，法师伤害占比 55.57%。

最终版 Player E：16 个决策完成全章，最终队伍同样为战士/骑士/法师/牧师，装备战力 738，情绪 67.8103；牧师在护盾试炼前主动上阵，两个场地分别产生 4、5 个真实信号，史诗按 `fitDelta +151.4` 给法师，首领战法师伤害占比 71.64%。

## 已验证教学

- 新角色不会自动上阵；两个玩家都手动换入骑士与牧师。
- 骑士通过真实护盾贡献、牧师通过真实治疗/护盾贡献被认识。
- 护盾爆裂与王旗不是提示文本：场地事件进入日志、结构化知识和后续决策。
- 获得装备只进入库存，手动装备后战力才变化。
- 装备等级影响基础数值；史诗以四词缀和明确适配形成新的选择维度。
- 首轮失败反馈实际改变了第二版设计，第二版改进来自规则、掉落与敌人，不是心理参数。

## 剩余风险

1. 最终版两名玩家都没有在第二章失败，失败诊断与重试情绪链仍缺真实样本。
2. 王旗试炼在安全阵容下耗时 42.96 至 61.84 秒，存在拖时解与节奏疲劳风险。
3. 王旗的骑士钥匙提升达到 100pp，方向正确但幅度偏硬；后续真人试玩应观察是否显得只有一种解。
4. 史诗前后静态对照已通过，但 Agent 轨迹没有同一首领的持有/穿戴配对，不能把法师全部输出提升归因于单件史诗。
5. 牧师换入会让被换下角色装备退出活跃战力，短期战力下降明显；信息正确，但真人是否会误判角色强弱尚未验证。

## 结论边界

本轮完成的是独立 AI 试玩版、真实战斗、真实事件和 Frozen 玩家模型的第二章设计验证。没有制作或修改人类试玩 UI，也没有改第一章、正式技能数值或 Frozen 心理参数。
