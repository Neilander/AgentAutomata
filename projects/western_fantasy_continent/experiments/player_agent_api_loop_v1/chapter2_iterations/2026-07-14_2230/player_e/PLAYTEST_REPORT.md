# 第二章最终版独立复核 - Player E

**PASS with risks。** 共执行 16 个决策，依次通关 `r2_entry -> knight rescue -> priest rescue -> shield trial -> flag trial -> confluence -> r2_boss`，Boss 已击败后立即停止，没有继续游戏或修改源码。

## 实际路线

1. 入口首通，取得 Lv.22 武器并按 `fitDelta +108` 装给游侠，战力 246 -> 354。
2. 选择骑士救援在前、牧师救援在后；救出骑士后手动以 `swap:1:hero_knight` 替换拒马民兵。
3. 骑士下一战产生 142.2563 护盾，`knight shield > 0` 假设确认。
4. 救出牧师后，在护盾试炼前主动以 `swap:3:hero_priest` 换下游侠；换人令上阵装备战力 445 -> 247，随后给骑士和法师补装至 419。

6. 王旗试炼观察到 5 个场地信号，耗时 42.96 秒，为全章最长战斗。
7. 汇流战 20.8 秒通关，固定获得四词缀 Lv.24 史诗装备。
8. 史诗装备给法师，战力 586 -> 738；Boss 战法师贡献假设以 `damageShare 0.7164` 确认，Boss 27.84 秒通关并产生 7 个王旗信号。

## 玩家学习

- **新角色：** 骑士通过真实护盾量证明守护职责；牧师通过真实治疗量证明治疗职责。两者都由手动换人进入阵容，不是只解锁未使用。
- **场地：** 护盾试炼的 4 个信号和王旗试炼的 5 个信号均进入后续判断；Boss 的 7 个王旗信号证明该知识继续出现。
- **装备等级：** 实际使用了 Lv.20、22、23、24 装备；所有配装动作均依据小文件中的 `baseStats / affixes / bestFits / fitDelta`。
- **史诗适配：** 法师拥有最高 `fitDelta +151.4`，且护符包含魔法与火焰相关属性，因此史诗明确驱动了法师配装；随后法师 Boss 伤害占比 71.64%。
- **锁钥理解：** 已形成。骑士对应护盾与前排稳定，牧师对应治疗/护盾，双前排加牧师被保留用于王旗与 Boss，史诗则强化法师输出钥匙。

## 情绪

情绪从 51.6778 上升到 67.8103。最大跃升来自两次角色救援：骑士救援 `+4.8445`，牧师救援 `+4.3266`；汇流与史诗奖励 `+1.8737`，Boss 通关 `+1.8687`。普通换人和装备事件的即时情绪变化很小，主要正反馈来自角色、关键奖励与通关。

## 问题与风险

1. compact 轨迹中全部战斗结果均为 `win`，没有真实第二章失败，因此“Boss 失败是否可诊断”未被验证。
2. 牧师换入时战力从 445 降至 247，说明装备跟随被换下角色会造成显著但容易忽视的阵容成本；本次通过后续补装恢复。
3. 王旗试炼耗时 42.96 秒，双前排加治疗的锁钥安全但偏慢，可能形成拖时解。
4. 骑士先、牧师后的顺序是合理真实选择，但没有同条件反向路线，不能证明其绝对优于牧师先救。
5. 史诗假设确认了装备后的法师贡献，却不是同一遭遇的装备前后对照，不能把 71.64% 完全归因于史诗。
6. 因 Boss 胜利后按要求立即停止，compact 状态仍显示 `phase: attribution`、`completedCycles: 15`，但 cycles 已包含第 16 轮 Boss 胜利且 `bossCleared: true`；这是停止边界造成的汇总口径差异。

## 最终判定

第二章的救援顺序、新角色使用、两种场地信号、汇流解锁和史诗法师适配均能从真实玩家行为链中成立。主要未决项是失败恢复链没有被采样，以及安全阵容在王旗内容中偏慢。
