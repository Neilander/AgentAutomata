# 新认知接入后的双Agent两章对比

## 结论

这次结果支持“最近的认知更新带来了真实提升”，但不能把所有通关提速都归因给认知。

两个独立玩家Agent都在相同 `paired-alpha` 种子、普通感知档和同一丰富两章环境中完成通关。与2026-07-17的同类型旧轨迹相比，它们使用更少循环、更少无效换装和更少知识条目完成路线；Agent在决策中真实引用角色当前认知、历史阵型坐标、场地规则和换装验证结果。原始威胁信息泄漏已经消失。

同时，长跑暴露了两个本轮应处理的问题：支援/坦克整体强度可能被低估；请求合同与运行时的条件字段不一致。相同配置随机翻盘后玩家被误导，符合要模拟的真实玩家偏差，不是缺陷。换人A/C回归正常；通用假设确认与证伪目前共享 `+0.06` 验证过程感，是尚未修改的另一项设计，不属于本轮A修复。

## 对比口径

- 环境：`enriched_v1` 大地图第1～2章。
- 种子：新旧均为 `paired-alpha`。
- 感知：新跑均为 `ordinary`。
- 新玩家：开放新手、惯性玩家，各由一个独立子Agent从头跑到两章结束。
- Agent只读取每轮正式request，不预读旧统计、另一名玩家结果或设计者结论。
- 请求记录目标模型为 `5.5fast`，但当前编排器不能确认实际模型，因此报告不声称真实模型就是5.5fast。
- Agent采样不是确定性的；相同种子只固定游戏侧随机源，行为差异是诊断证据，不是单次严格因果证明。

开放新手减少19个循环、5次换人、11次换装和87条知识。惯性玩家减少14个循环、6场战斗、4次失败、2次换人、6次换装和85条知识。两个旧玩家都接近情绪上限；新版最终情绪分别下降到89.18和84.68，没有再次直接顶到95以上。

这些数字不是单独的成功依据。开放新手跳过了部分非必要战斗；惯性玩家被一次原阵随机翻盘影响了后续判断——这符合真实玩家会被随机结果误导的设计，但意味着循环数不能当作严格的算法因果证明。真正有价值的是下列行为证据。

## 已确认的提升

### 1. 信息减少，但决策信息没有被删空

旧开放新手和惯性玩家的战斗/奖励知识中分别有175、177条使用非公开战斗事件证据，各有13条带原始威胁形状。新版两条轨迹均降为0。

新版正式记录：

- 开放新手19场战斗形成363个候选信号，实际接收156个；65个角色详细信号转给旧角色认知，114条非角色因果关系进入旧canonical知识库。
- 惯性玩家28场战斗形成521个候选信号，实际接收200个；110个角色详细信号转给旧角色认知，153条非角色因果关系进入旧canonical知识库。

两名Agent仍能使用敌方治疗/护盾、场地规则、地图、掉落和装备事实完成两章。首场归因越界时，运行时会拒绝不属于该知识的公开信号，说明现在不是“只换了ID名称”，而是真有证据边界。

### 2. 角色认知和历史坐标真实改变行为

- 开放新手19/19条关卡知识、惯性玩家22/22条合并后的关卡知识都保存四名角色的矩阵位置、当时前30%标尺和相对距离，数学关系全部正确。
- 开放新手30次决策中19次实际引用认知；惯性玩家35次决策中21次引用认知。两者都至少两次明确引用历史认知。
- 开放新手看到法师加入后抬高全局标尺，原本强的战士被重新评价；刺客虽然“伤害前三”局部假设确认，但历史阵型坐标低、只剩2人，于是换回游侠，后续恢复4人存活。
- 惯性玩家在法师换入失败后，读取法师相对标尺约 `-1.999`、伤害第3，把结论限制为“这个法师实验失败”；随后继续测试未知狂战士。狂战士伤害第1、相对标尺约 `+4.740`并帮助通关，没有形成“换人都会失败”的泛化。

### 3. 换装不再自动等于成功

- 开放新手给战士的神话靴子通过下一场验证；传说头盔和法师稀有武器虽然抬高面板，但角色伤害目标均被证伪，Agent没有继续维护错误解释。
- 惯性玩家在主线6把装备强度从0提高到116、再到164，仍连续失败；牧师救援又从164提高到331，仍失败。Agent据此转向阵容和关卡机制，而不是无限堆装备。

### 4. 新关弱惯性和强信号覆盖都出现了

两名玩家都沿用上一关阵容、以较低置信进入新章；场地出现“高盾爆炸并清空”的强提示时，它们没有把上一关成功机械复制到护盾试炼。开放新手两次换人预测在自然进入下一关后都得到结算，旧开放新手8次预测全部因推进而失效。

### 5. 惯性不再等于无限死磕

惯性玩家允许一次原阵重试，但在相同失败重复后会要求新的装备、角色或目标：

- 主线6：两档装备仍失败，法师失败后继续试狂战士并获胜。
- 牧师救援：装备大幅提升仍失败，转去取得骑士，再回来获胜。
- 折旗台：原阵两次出现相同2对3残局后，根据敌方治疗/护盾和收尾不足换入刺客，随后获胜。

## 新暴露、已排除与以后再做的事项

### 1. 支援和坦克整体强度可能被低估

开放新手中：

- 晨祷牧师实际治疗约180.482，但首场整体认知为相对标尺 `-2.839`、非常弱。
- 白垒骑士实际护盾约288.840，并帮助队伍4人存活，但首场整体认知为 `-3.752`、排名9、非常弱。

惯性玩家能正确保留“骑士在牧师救援产生202.209护盾”的环境特点，但骑士整体分仍偏低。Agent目前可以用场景特点绕过全局低分，这不代表矩阵数值正确。需要检查治疗、护盾、承伤和帮助全队存活怎样进入共同强度口径。

### 2. 原阵随机翻盘会误导玩家——符合预期，不是问题

惯性玩家在主线10第一次失败后原阵重试并获胜。它随后在牧师救援和折旗台明确引用这次经历，作为“单次失败后应再试一次”的证据。折旗台因此连续失败两次才调整。

这正是现实玩家会发生的随机归因偏差：玩家看不到底层种子，只会从自己的经历学习。系统保留这种误导是理想行为，不应修成全知视角。唯一需要注意的是，研究者不能把这段随机翻盘造成的通关提速全部算成认知算法提升。

### 3. 换人A/C没有故障；未触发不等于没修好

- 惯性玩家4次换入的都是没有稳定战斗认知的新角色。正式请求明确输出 `expectedChange=unknown`、`predictedPerformanceScore=null` 和 `do_not_generalize_without_character_evidence`，所以不建立数值预测、也不产生A，完全符合原合同。
- 开放新手前6次新角色换入同样保持未知；后两次换回已有认知的游侠形成数值预测，并通过新关弱惯性在下一场正常结算。旧版8次预测全部因进入新关失效，本次反而证明自然推进修复有效。
- 换人A负/零/正、明显失败C归零、换装重算和新关惯性聚焦测试全部重新PASS。

### 4. 通用EVerify确认/证伪反馈——本轮没有修改

惯性玩家另外有4条Agent自建角色假设，确认2次、证伪2次，四次都产生 `EVerify=1/+0.06`。这是通用的“完成可读验证”过程感，不是换人A或C；用户尚未修改这一层。是否让猜对与猜错产生额外不同反馈，留在原“错误决策不扣情绪”任务以后处理，不能据此否定已经修好的A。

### 5. 假设条件字段合同不一致——确认是bug

正式request要求 `hypothesis.nextCombatTargetCondition`，运行时实际只读取 `hypothesis.targetCondition`。惯性Agent完全按合同作答时被拒，改用运行时字段后才继续。短测试因Agent碰巧使用运行时字段而漏掉了这个问题。

### 6. 失败体验、Progress和概率预期以后再优化

- 惯性玩家经历10次失败，情绪最低值仍是初始38；大量掉落和通关反馈使最终情绪仍为84.68。
- 开放新手19战全胜，完全没有覆盖失败负反馈。
- 同批掉落顺序和1%神话概率认知尚未修复，本次只是没有诱发明显刷神话行为。
- 目标血量、击杀、波次等局部Progress仍未进入完整情绪结算。

## 总判定

**行为提升：通过。完整心理模型：仍未通过。**

现在可以有把握地说：

- 新信息过滤没有毁掉决策信息；
- 角色相对标尺、历史阵型坐标和特点复核已被真实Agent使用；
- 换人失败不再自然泛化成“所有换人都失败”；
- 换装预期和新关惯性在自然长流程里工作；
- 知识量和无效操作显著下降。

现在还不能说：

- 支援/坦克的角色强度数值可信；
- 支援/坦克的整体认知已经使用正确共同口径；
- 通用假设的确认与证伪已经获得不同且完整的情绪反馈；
- 概率掉落、失败体验和Progress体验已经解决。
