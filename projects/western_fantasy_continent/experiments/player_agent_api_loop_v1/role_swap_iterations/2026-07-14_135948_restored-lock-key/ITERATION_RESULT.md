# Iteration Result

## Design Variable

Restore the first-region causal order by moving the Ranger single-target validation from Main 4 to Main 7, while keeping Prison and Camp optional and retryable.

## Mechanical Acceptance

The 100-seed intent verifier observed:

- Main 4 clear: `100/100`
- Main 5 clear: `100/100`
- Early Prison clear: `15/100`
- Post-Camp Prison clear: `85/85` among routes that had failed early
- Main 7 Mage clear: `15/100`
- Main 7 Ranger clear: `100/100`
- Ranger role proof: `100/100`

## Player-Cognition Acceptance

The retained 24-cycle player run followed the intended lock-key chain and formed evidence-bound knowledge for:

- Prison failure before the key;
- Camp gear as an explicit equipment action;
- Prison success after the key;
- Ranger roster unlock without auto-swap;
- manual Ranger selection;
- Ranger weapon fit;
- Ranger's first-place sustained damage in Main 7.

Result: PASS. No second gameplay iteration is justified by the current evidence.
