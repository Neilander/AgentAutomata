# 玩家情绪生成模型 V1：事件如何真正产生影响

## 1. 模型解决的不是“读一句话，猜一个情绪”

模型的固定链路是：

```text
客观事件
  + 玩家档案
  + 已发生的长期经历
  + 事件发生前冻结的预期
→ 事件影响
→ 生理/化学状态变化
→ 多种同时存在的情绪
→ 行为倾向
```

情绪名称不允许出现在输入里。事件说明文字也不参与计算。程序只读取结构化事实。

例如，“敌人突然冲锋”不是直接对应“恐惧”。程序先计算：

- 玩家有多重视生存；
- 受伤概率与伤害有多大；
- 距离伤害发生还有多久；
- 玩家知道哪些可用动作；
- 玩家认为自己能不能执行这些动作；
- 以前同类失败是否仍未消化。

这些量共同决定威胁、紧迫、可控性和不确定性，随后才推动去甲肾上腺素、肾上腺素、皮质醇等状态，并生成恐惧、焦虑或兴奋等可能共存的结果。

## 2. 输入分四类，各自不能越界

### 2.1 客观事件

事件层只允许填写观察到或在事件发生前已经成立的事实：

- `stakes`：什么对象可能受损或获益、幅度、概率、多久发生、是否已经损失、能否恢复。
- `options`：当时有哪些已知选项、是否可用、预计有效性、成本。
- `difficulty`：执行这些选项的客观难度。
- `outcome`：已经发生的效用、目标进度、获得奖励、解除威胁的比例。
- `agency`：谁对结果有因果贡献、是否故意、证据有多可靠。
- `social`：是否伤人、助人、违背规则、公开曝光、损害地位、威胁关系。
- `sensory`：污染、腐败等直接感官事实。
- `epistemic`：决策所需信息缺了多少、事情是否熟悉、本次新增了多少信息。

`outcome.expectedUtility` 必须是事件发生前冻结的预期，不能看见结果以后补写。

### 2.2 玩家档案

同一件事对不同玩家影响不同，差异来自预先存在的档案，而不是测试时临时调数：

- 不同目标的重视程度；
- 不同关系的重视程度；
- 各领域自我效能；
- 风险和不确定性容忍；
- 规则、他人评价、污染、反事实比较敏感度；
- 生理化学基线和反应敏感度。

### 2.3 长期经历

长期经历只改变当前的起点和解释倾向：

- 同领域未解决的失败会降低可控性；
- 未解决的威胁记忆会放大相似威胁；
- 慢性压力提高皮质醇的长期基线；
- 疲劳和慢性压力提高炎症负荷的长期基线；
- 已解决的记忆只保留较小影响。

长期状态是“底噪”，不会因为程序又处理了一条无关事件而重复释放一次。

### 2.4 可选的真实测量

如果未来确实有心率、动作、面部或生理测量，可以作为带来源和可信度的观测输入。没有测量时必须保持未知，程序不能自行编造“画面归因清晰度”或伪测量值。

## 3. 事件影响的固定计算

### 3.1 威胁

每项负面风险先计算：

```text
单项威胁 = 损害幅度 × 该玩家对目标的重视 × 发生概率
```

多项威胁使用“联合累积”而非简单求和，避免超过 1：

```text
总威胁 = 1 - Π(1 - 单项威胁)
```

随后只允许风险容忍和未解决的相似威胁记忆改变它。

### 3.2 紧迫性

```text
紧迫性 = 损害幅度 × exp(-距离发生时间 / 事件时间尺度)
```

同样的损害，三秒后发生比三分钟后发生更容易产生急性恐惧。

### 3.3 可控性

每个选项先计算：

```text
有效选项 = 可用性 × 已知程度 × 预计有效性 × 成本折扣 × 证据可信度
```

多个选项联合形成“方案覆盖度”，再与难度、自我效能和同类失败记忆共同进入 S 形函数：

```text
可控性 = logistic(
  3.1 × (方案覆盖度 - 难度)
  + 1.8 × (自我效能 - 0.5)
)
```

因此同一个 Boss 冲锋，对熟练玩家仍是威胁，但更可能成为可处理的挑战；新手则更可能认为没有路。

### 3.4 结果与预期偏差

结果好坏与是否超出预期分开：

```text
结果效价 = 实际效用映射到 0..1
预测偏差 = 实际效用 - 事件前冻结的预期效用
```

成功但低于预期，可以同时出现满足较低、失望较高；失败但比预期好，也不等于纯粹负面。

世界模型被打破与奖励预测偏差也必须分开。看见一个不可能出现的东西，可以高度意外，却不等于“本来期待得到奖励但落空”。前者由 `epistemic.expectationViolation` 产生惊讶和注意转向；后者才进入奖励预测偏差和失望。

正向预测偏差还会按事件背景分流：如果它主要来自刚才的高威胁被解除，优先形成释然；如果不是从危险中脱身，才更充分进入兴奋。这样“终于确认家人安全”不会仅仅因为结果远好于预期就被算成普通兴奋。

通用快乐也要向更具体的归因结果分流：

- 高威胁刚解除：更多进入释然；
- 收益主要由别人主动带来：更多进入感激；
- 结果主要由自己完成且提升自我评价：更多进入骄傲。

分流只降低通用快乐的竞争权重，不会删除快乐本身。

### 3.5 责任归因

```text
自我归因 = 自己是否行动 × 因果贡献
责任确定度 = 因果贡献 × (0.35 + 0.65 × 故意程度)
```

负面结果首先可能产生失望或挫败。若确认是别人故意造成，模型将其中一部分分流成愤怒：

- 责任越明确、越外部、越故意，愤怒越强；
- 同时保留一部分失望和挫败，而不是只输出一个标签；
- 若主要是自己造成，则不走外部愤怒分流，更可能进入内疚、羞耻或后悔。

### 3.6 损失、规则、关系与信息

- 已实现损失 × 不可恢复比例产生不可逆损失，主要支持悲伤。
- `realizedFraction` 只表示伤害或损失已经发生，默认会减少相同部分的未来威胁；若袭击仍在继续，必须另填 `ongoingThreatFraction`。这样死亡不会被当成完整的未来危险，而“正在被打”可以同时产生已经受伤和仍受威胁。
- 不可逆性越高，“继续换办法解决障碍”的挫败通道越弱；否则永久死亡也会被错误解释成普通卡关。
- 自己造成伤害、违反已经认可的责任、关系价值与可补救性支持内疚；内疚不要求他人已经受到严重伤害。
- 自己违反规则 + 公开程度 + 自我评价下降支持羞耻；严重的内部自我形象受损即使没有观众也能形成羞耻。
- 厌恶有三种客观入口：污染/腐败线索、排斥性的身体接触、严重且责任明确的道德违背。它们共用厌恶输出，但输入证据保持可区分。
- 他人主动带来收益 + 收益实际到账支持感激。
- 安全且可处理的信息缺口支持好奇；危险且不可控的信息缺口更接近焦虑或困惑。
- 熟悉且没有新信息、目标价值低时支持无聊。

## 4. 生理和化学状态不是情绪标签

V1 显式保留 12 条化学轴：

1. 中枢去甲肾上腺素
2. 肾上腺素
3. 皮质醇
4. 多巴胺
5. 血清素
6. 乙酰胆碱
7. 内源性阿片
8. 内源性大麻素
9. 催产素
10. 加压素
11. 睾酮
12. 炎症负荷

它们只调节唤醒、持续压力、奖赏、注意、社会联结、调节能力等中间过程，不与某个情绪一一对应。

血清素在 V1 中主要提高调节和等待能力。它不会把人直接变“开心”，也不会让被故意阻挠的人不再愤怒；它更可能降低冲动强度，把立刻对抗改成暂停后判断。

## 5. 情绪输出

每个时点可同时输出多种情绪，每项包含：

- 情绪家族；
- 强度；
- 对象；
- 置信度；
- 预计持续时间；
- 行为倾向；
- 支持它的事件影响、生理状态和记忆。

模型同时给出即时结果和一段时间后的投影。例如故意阻挠可能即时以惊讶最显眼，但惊讶快速衰减后，愤怒成为主要状态。

事件影响的 `confidence` 表示这条判断有多可靠，用于输出结论可信度；它不再把已经算出的影响强度重复乘一次。风险发生概率已经在威胁公式中计算，若再乘可信度，会把同一份不确定性扣两遍。

实际目标进展或倒退本身会补充目标相关性。否则一个没有预先列出 `stakes`、但实际完成了重大目标的事件，会错误地缺少骄傲、满足等目标反馈。

## 6. 验证规则

### 6.1 单元测试

人工小案例只证明公式方向和边界正确，不能证明模型能解释真人。

### 6.2 真实来源发现集

真实案例必须拆成三个文件：

1. `source`：来源、时间、可核查原文位置。
2. `input`：只含情绪发生前的客观事实、人物档案和历史。
3. `gold`：来源中实际报告或明确表现的情绪，只在模型输出冻结后读取。

如果开发者已经看过答案，这个案例只能用于找错，不能计算盲测准确率。

### 6.3 封存盲测集

盲测中，结构化事件的整理者不能看 `gold`；模型开发者只能得到冻结后的 `input`。全部预测写入并哈希后，才允许打开答案。文学解释有歧义时必须允许多情绪答案和置信区间，不能强迫唯一标签。

## 7. 当前边界

- 这是隔离实验，没有接入或修改正式玩家 Agent。
- 当前程序已经覆盖威胁、可控性、结果偏差、责任、损失、自我评价、关系、污染和信息缺口。
- 已完成三轮答案后开的顺序封存验证，但事件结构仍由同一开发者在看不到答案的情况下整理，不是独立双人盲标。
- 最新 V3 在第三轮 16 条有可观察事件上 Top-1 为 11/16、Top-3 为 16/16；样本仍小，不能据此宣称真人情绪已经普遍预测准确。
- 强度刻度、不同玩家档案造成的个体差异、固定 V3 的大样本独立留出验证仍未完成。
- 旧的“直接读取事件文本并分类情绪”实验不属于这条模型链路，后续不得拿它的分类准确率替代生成模型验证。
