# 队伍语义坐标 V0

这是一个隔离实验，用来验证以下想法：队伍认知从768维零向量开始，每条玩家知识都让坐标发生一次位移；当前需求直接用自然语言向量与队伍坐标匹配，不再经过九维人工能力表，也不让LLM分配权重。

## 当前公式

每条知识先保存为：

```text
自然语言命题 + 支持次数 + 反驳次数
```

同一命题的当前位移权重为：

```text
证据饱和度 = 1 - exp(-证据总数 / 2)
认知方向 = (支持数 - 反驳数) / 证据总数
知识位移 = 证据饱和度 × 认知方向 × GTE(自然语言命题)
```

队伍坐标是全部知识位移之和再归一化。需求“要让队伍活下去”直接编码为GTE向量，与所有队伍坐标做点积。

支持/反驳是证据状态，不是人工能力维度。之所以必须单独保存，是因为文本Embedding通常会认为“能够治疗”和“无法治疗”主题相似，不能依靠否定词自动产生相反方向。

## 数据边界

- 输入来自既有50队实验中由信息解析器筛选出的玩家可见战斗陈述。
- 敌方表现不会被写入我方队伍坐标。
- 验证使用第二随机种子的战斗指标，只参与最终评分，不参与坐标形成。
- 正式玩家Agent、九轴角色标尺和反馈系统均未修改。

