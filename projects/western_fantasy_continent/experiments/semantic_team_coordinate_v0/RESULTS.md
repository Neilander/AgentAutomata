# 队伍语义坐标 V0 结果

## 结论

“从零点出发、由知识逐条拉动队伍坐标、用自然语言需求直接匹配”的核心结构可以实现，而且在当前50队真实知识上已经出现有效信号；但第五步的知识语义化仍不完整，当前版本不能接入正式玩家Agent。

## 自然语言自身的激活

查询“要让队伍活下去”直接匹配不带统一主语模板的能力短语：

| 能力 | 相似度 |
| --- | ---: |
| 持续恢复受伤队友生命 | 0.7712 |
| 限制敌人行动、争取时间 | 0.6888 |
| 用护盾保护队友 | 0.6728 |
| 降低队友受到的伤害 | 0.6593 |
| 获得更多战利品 | 0.6205 |
| 快速击杀、提前解除威胁 | 0.6161 |
| 同时攻击多个敌人 | 0.5604 |
| 造成很高伤害 | 0.5158 |

符合预期的部分是治疗最高，护盾、减伤和控制较高，快速击杀与纯伤害仍有较弱激活。不符合预期的是“战利品”仍然偏高，说明原始GTE余弦值有明显的通用游戏语境基线，不能把绝对相似度直接解释为心理激活强度。

## 真实50队验证

完整“命题 + 支持/反驳”坐标与第二随机种子真实表现的Spearman相关：

| 自然语言需求 | 相关性 | Top-10是否优于Bottom-10 |
| --- | ---: | --- |
| 要让队伍活下去 | 0.7568 | 是 |
| 持续治疗和保护队友 | 0.7278 | 是 |
| 造成更多伤害 | 0.5787 | 是 |
| 在敌人启动前迅速建立优势 | 0.1667 | 是 |
| 同时攻击多个敌人 | 0.6417 | 是 |
| 限制敌人行动 | -0.0372 | 是，但总体排序无效 |
| 用持续效果消耗敌人 | 0.4551 | 是 |

把“曾经获胜、有人存活、有人倒下”等结果知识全部移除，只保留能力知识后：

| 自然语言需求 | 相关性 |
| --- | ---: |
| 要让队伍活下去 | 0.3940 |
| 持续治疗和保护队友 | 0.8321 |
| 造成更多伤害 | 0.5490 |
| 迅速建立优势 | -0.1102 |
| 同时攻击多个敌人 | 0.4206 |
| 限制敌人行动 | 0.1051 |
| 持续效果消耗 | 0.3927 |

能力消融后，生存Top-10的第二种子平均存活率为0.425，Bottom-10为0.150。说明生存结果不只是记住旧胜负，治疗、保护等能力知识确实提供了跨随机种子的有效方向。

## 边界测试

- 重复证据会继续拉动坐标但逐渐饱和：1、2、5、20次的单组权重分别为0.3935、0.6321、0.9179、1.0000。
- 一条治疗支持证据的生存相似度为0.7164；加入一条同命题反驳后回到0；一条支持、三条反驳后反向为-0.7164。
- 这证明正负更新能工作，但依靠的是“命题 + 支持/反驳”的知识合同，不能依靠原始否定句Embedding。

## 发现的第五步问题

当前知识解析器经常只留下“使用过霜环、急板战歌”等技能名，没有形成“霜环会限制敌人行动”“急板战歌能加速启动”这样的玩家认知。因此：

- 治疗、伤害和存活等被文本明确说出的能力可以进入连续坐标。
- 控制、启动速度和复杂技能联动没有被语义化，坐标无法凭技能名称恢复这些含义。
- 这不是点积或坐标累积失败，而是进入坐标前的知识还没有包含可检索的意义。

下一步应隔离开发“观察事件 → 当前自然语言命题 + 支持/反驳”的知识形成层，并用控制、启动、净化、锁血和技能组合测试它；通过后再复用本实验的坐标累积器。
