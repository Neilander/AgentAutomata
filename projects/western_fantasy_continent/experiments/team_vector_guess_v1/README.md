# 50队知识向量与猜队伍 V1

这是一个不接入正式玩家Agent的隔离实验。它验证一条完整但可拆开的链路：

```text
四人有序队伍（允许重复角色）
→ 对六种固定流派各打一场
→ 只保留前端渲染可见的战斗signal
→ 形成主体/环境/行为/结果队伍知识
→ 九个独立能力方向形成队伍向量
→ 原子需求形成方向向量
→ 点积排序候选队伍
→ 用第二随机种子的战斗验证排序
```

## 边界

- 当前50队中有46队为固定种子随机抽样，另有四个重复角色和换站位边缘样本。
- 每个位置独立抽取10个标准角色，因此队内允许重复；候选队伍之间保持唯一。
- V1固定每个角色的标准技能，只验证队伍组成与站位，不同时随机技能。
- 队伍向量来自玩家可见战斗表现；角色说明、预设标签和设计师隐藏数值不进入向量。
- 正式需求方向由真实大语言模型读取失败后的玩家知识和当前队伍认知后输出；GTE原子匹配只保留为失败的对照实验，不再是正式结论。
- 大语言模型拥有100点有限注意力预算，必须分配到九个方向，且Top-3合计至少60。没有这个预算时，模型会把所有有益能力都打高，点积退化成永远寻找全局最强队。
- LLM权重做L2归一化，队伍向量不归一化，最终使用普通点积。因此相对需求方向和队伍实际能力都会影响得分。
- 盲方向由`forkTurns=none`的独立模型生成；它只读取请求，不读取候选队向量、验证战斗或结果报告。
- 原角色认知与队伍认知彼此隔离；一支队伍失败不会直接降低四名角色的个人认知。

## 运行

在本目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run-local.ps1
```

结果写入 `artifacts/`、`RESULTS.md`和`LLM_RESULTS.md`。完整原始signal不落盘；所有signal流过汇总器，只保存300格知识、关键证据样本和数值向量。
