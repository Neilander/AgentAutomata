# 隔离模拟玩家一回合判断卡

知识边界：只使用第1—9页已生成知识与当前公开/脑内状态。候选按同质房间或列聚类，不把每个等价格穷举成几十行。每次白骰后的新点数来自`external_random_observations.json`，不是玩家预先知道或自行编造。

## P1：灰4 → `A-r2-c5`

- 关键局面：能源2；五列未占；灰4、灰3是稳定大骰，白5会重投其余骰。
- 知识：多格房必须填满；能源房值为骰子和加修正；白骰会重投未放骰；骰子推动同列飞船。
- 候选：能源半房C4/C5；研究C2；战斗机C1；AA；距离1—4的挖掘格。
- 成本/限制：所有放置都用一骰一列；能源房还必须承诺另一半；当前研究需要付2能源且灰4最多提供值4；挖掘另付1能源。
- 收益：先锁能源半房，不引发重投；C5船落H4普通格。
- 宏观需要：先建立能源，再挖掘；研究不是本回合唯一目标。
- 排除：暂不白骰，避免重投四骰；不先研究耗尽初始能源；不先战斗机，因为当前无爆炸格目标。
- 选择：灰4放C5能源半房。

## P2：灰3 → `A-r2-c4`

- 关键局面：C5已由灰4占据；C4空；能源房只差一半。
- 知识：两格能源房完整才生效；房间值=`4+3-3=4`。
- 候选：灰3完成能源房；灰3用于挖掘；白5完成能源房但重投更多骰。
- 成本/限制：占C4；该列船下降3至H3普通格。
- 收益：确定获得值4能源房；无需支付能源；保留白5和另两骰。
- 宏观需要：把第一步承诺兑现，避免半房两骰全部浪费。
- 排除：不改去挖掘而放弃已锁定半房；不让白骰承担可由灰骰完成的任务。
- 选择：灰3完成C4+C5能源房。

## P3：白5 → `A-r2-c1`

- 关键局面：能源组合已锁定；剩余C1/C2/C3，骰为灰2、白5、白1。
- 知识：白骰放置后只重投尚未放置骰；战斗机房值=`5-1=4`、能耗1；只有爆炸格目标才有收益。
- 候选：白5进C1战斗机；白5/灰2挖掘C3；低骰进AA；研究C2。
- 成本/限制：现在白骰只重投两骰，随机成本比前两步低；战斗机尚无确定目标，房间阶段可跳过不付能。
- 收益：保留一个潜在值4射击选项；C1船落H5普通格；推进到真实随机观察边界。
- 宏观需要：能源已保证，余下主要争取挖掘，同时避免低骰把C1飞机推到母舰下降格H2。
- 排除：灰2进C1会落H2并令母舰下降；白5研究虽能推进，但会把初始资源重心改成研究且挤掉挖掘列规划。
- 选择：白5进C1战斗机；是否支付留到房间阶段根据实际目标再判断。

## P4：重投后的白5 → `A-r3-c3`

- 关键局面：只剩C2/C3；灰3与白5；本回合还未挖掘；距离2格可达。
- 知识：未挖掘格要求骰值不小于距离；每回合只允许一颗挖掘骰；结算挖掘需1能源。
- 候选：白5挖到路径2；灰3挖路径2；白5研究C2；AA收尾。
- 成本/限制：白5放后会再次重投最后灰骰；挖掘占唯一挖掘名额且后续付1能。
- 收益：确定推进挖掘机两格；C3船落H5普通格；让最后一骰独自承担随机。
- 宏观需要：能源房已提供发展资源，下一环是打开更深房间。
- 排除：白5研究会花2能且使挖掘只剩灰3，虽仍可达但C3船会落箭头H3；此处优先简洁的安全落点和确定深挖。
- 选择：白5用于路径2挖掘。

## P5：灰4 → `A-r1-c2`

- 关键局面：只剩C2；该列船仍在H0；灰4；其他四列已占。
- 知识：AA让下降少1；只触发最终落点；该房在房间阶段无收益。
- 候选：C2 AA；C2研究；更深未挖掘格因本回合已用了挖掘骰而非法。
- 成本/限制：AA没有资源收益；研究值4要付2能，可推进3+1两格，但会让船下降4到箭头并改变列。
- 收益：AA把下降压到3，落H3普通格；不再触发随机。
- 宏观需要：已经获得能源+挖掘组合，收尾优先避免额外母舰/箭头复杂后果。
- 排除：研究有直接胜利进度，但会同时花2能；当前试验选择偏保守发展，不宣称最优。
- 选择：灰4进C2 AA。

## R1：先结算能源房并支付0

- 关键局面：完整能源房值4；能源2；其他有效选择是挖掘、值4但当前无目标的战斗机、AA。
- 知识：房间顺序自由；能源不超过上限；完整能源房才生效。
- 候选：能源、战斗机、挖掘、跳过、结束。
- 成本/收益：能源房成本0，收益+4到6；先结算可确保后续1能挖掘可付。
- 排除：不先射击，因为当前没有爆炸格敌机；不先结束而浪费完整房。
- 选择：结算能源房。

## R2：跳过战斗机房

- 关键局面：战斗机值4、能耗1，但五架紫船均不在爆炸数字格。
- 知识：战斗机只击毁爆炸格数字不大于房间值的敌机。
- 候选：支付1并结算；跳过。
- 成本/收益：支付的确定成本是1能源，确定收益为0。
- 宏观需要：保留能源供挖掘与后续回合。
- 选择：跳过。这也承认P3只是保留选项，事后未兑现。

## R3：支付1能源挖到路径2

- 关键局面：能源6；白5合法放在路径2；挖掘机仍在路径0。
- 知识：支付1能、移除该骰、移动挖掘机并开放身后路径。
- 候选：挖掘；跳过；直接结束。
- 成本/收益：-1能源，路径0→2；收益匹配“能源→挖掘→更深房间”的宏观链。
- 选择：挖掘。

## R4：跳过AA骰

- 关键局面：AA的下降减免已在放置时发生，房间阶段无效果。
- 候选：清理/跳过；结束房间阶段。
- 选择：显式跳过该骰，随后再检查没有未处理的有收益动作。

## R5：结束房间阶段

- 关键局面：能源房已结算，挖掘已完成；战斗机和AA均已跳过。
- 限制/收益：继续没有合法的正收益房间；结束会进入母舰阶段。
- 选择：结束房间阶段。

## S1：白船生成平局，选择`DP-C1`

- 关键局面：母舰到H0并生成白船；五列均有船。C1、C3最高船都在H5，形成同等最远投放距离。
- 知识：每列都有船时，选择离该列最高船最远的投放点；仍平局时玩家自由选择。
- 候选：`DP-C1`、`DP-C3`，成本和即时收益相同。
- 宏观需要：规则知识没有提供足以区分两者的后续价值；不能伪造更深策略。
- 排除：C2/C4/C5不满足当前最大距离；C1与C3不应虚构优劣。
- 选择：用固定但公开的平局规则选编号较小的`DP-C1`。
