# UFS 候选判断试卷 V0：冻结评分标准

> 本文件在答题者开始前由主 Agent 冻结，禁止答题者读取。它用于防止看到答卷后临时改变期待答案。

## 通用合格条件

每题检查：

1. 引用知识 ID 能在五份允许知识中找到，且与判断有关。
2. 没有使用第10页后知识、隐藏地图、未来骰子、规划器或固定胜率。
3. 四个候选均分析基础成本、生效条件、直接收益、后续用途、天空副作用与机会成本。
4. 没把“基础成本同为一颗骰子”误写成“总代价完全相同”。
5. 没把条件不成立写成某类房间永久无用。
6. 宏观需要由当前瓶颈推出，不使用固定“能源永远高于研究”等权重。
7. 最终选择能由其前面的知识与比较推出；无法区分时允许诚实保留不确定。

评审结论使用 `accept`、`revise`、`reject`：

- `accept`：核心选择与推理链一致，只有不影响选择的轻微遗漏。
- `revise`：大体机制成立，但至少一题因漏条件、漏成本或宏观链错误而需要修正。
- `reject`：依赖越界知识、未逐项判断、选择与自身分析矛盾，或多数场景不能根据状态翻转。

## 场景期待

### 场景1

- `S1-F` 应因没有爆炸格目标而排除或强烈后置。
- `S1-AA` 应因没有改变危险后果且无房间阶段产出而后置。
- 应识别 `S1-E` 与 `S1-R` 都有效：能源解除挖掘前置，研究直接推进两格。
- 倾向 `S1-E` 符合当前“能源为零且终局入口未开放”的瓶颈推理；若选择 `S1-R`，必须明确说明为何两格即时研究比当前能源前置更紧迫，不能声称唯一客观最优。

### 场景2

- 应识别 `S2-E` 房间值5实际只能增加1能源，而且当前已有支付一次挖掘所需的能源。
- `S2-R` 能用满房间值推进两个连续格，预期选择 `S2-R`。
- 仅以“能源能挖掘”为理由继续选择 `S2-E` 属于没有计算饱和与当前瓶颈。

### 场景3

- `S3-E`、`S3-R`、`S3-F` 都造成立即失败；资源收益和无目标房间效果不能抵消终局失败。
- 预期选择 `S3-AA`。
- 必须把避免这次致命伤害视为防空的当前收益，不能说防空“完全没有收益”。

### 场景4

- `S4-F` 的条件成立，房间值4可一次击毁三个合格爆炸格目标。
- 两架白船若不处理会造成确定的2点伤害并立即失败；射击后白船移出版图，紫船等待重生。
- 预期选择 `S4-F`。若仍按固定发展链选择能源，说明没有让条件工具随局面激活。

### 场景5

- 预期识别 `S5-E` 为高直接收益、无当前天空代价，且解除能源/挖掘瓶颈。
- `S5-R` 收益较低并触发母舰额外下降；在给定状态下相对 `S5-E` 明显劣势。
- `S5-AA` 不改变有意义后果，`S5-F` 无目标，均应后置或排除。

### 场景6

- `S6-R` 满足最终11点格并立即获胜，预期选择。
- `S6-E` 只增加到上限，且能源→挖掘的前置链已经完成；继续发展不能高于即时胜利。
- `S6-AA` 与 `S6-F` 当前条件没有产生有意义结果。
- 应明确瓶颈已经从能源/挖掘转移为最终研究兑现。

## 总体观察重点

- 是否先按条件过滤，再比较有效候选。
- 是否把知识中的因果关系实例化为当前成本与收益，而不是复述规则。
- 是否能因能源上限、失败窗口、爆炸目标、空列和终局入口变化而翻转选择。
- 是否能输出“引用知识→当前瓶颈→逐项判断→排除→选择”的可审计链。
