# UFS progressive-detail activation V0 protocol

## Question

When one real situation is described with progressively more true discriminating detail, does the current personal GTE move the correct learned trajectory upward without any applicability filter?

This isolates semantic activation quality. It does not test Q-before/Q-after merging, post-retrieval validation, action utility or planning.

## Independent channels

Q-before and Q-after are evaluated independently. Each channel has five cumulative semantic levels:

1. generic event family;
2. two-cell energy-room structure;
3. first-versus-second investment and `1→2` occupancy;
4. delayed reward timing;
5. exact visible identifiers, operation and phase.

The exact stored endpoint is compiled separately as a ceiling diagnostic and is not counted as a progressive level.

## Frozen expectations

- Level 5 target rank should be better than level 1 in each channel.
- Level 5 should place the target in Top-3 in each channel.
- At least three of four detail additions per channel should be non-worsening in target rank.
- Level 5 should rank the target above the close confuser in each channel.

Failure means the current five-slot semantic encoding does not preserve added relational detail reliably enough by itself. It does not mean a later structural validation stage is impossible.
