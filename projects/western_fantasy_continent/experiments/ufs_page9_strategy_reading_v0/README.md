# UFS 第1—9页三视角策略阅读实验 V0

本实验让三位彼此隔离的阅读者，只读取 UFS 首局规则第1—9页对应的五份知识阶段，分别回答三个不同问题：

1. 不细化到具体格子的宏观打法是什么；
2. 规则最强调哪些资源、压力与约束；
3. 能从规则中形成哪些带触发条件的具体策略假设。

## 阅读顺序

- [`EXPERIMENT_PROTOCOL.md`](EXPERIMENT_PROTOCOL.md)：输入边界与隔离条件。
- [`reports/01_macro_strategy.md`](reports/01_macro_strategy.md)：宏观策略。
- [`reports/02_resource_emphasis.md`](reports/02_resource_emphasis.md)：资源强调。
- [`reports/03_concrete_tactics.md`](reports/03_concrete_tactics.md)：20条条件式具体策略假设。
- [`SYNTHESIS.md`](SYNTHESIS.md)：主 Agent 对三份独立报告的对照与边界审计。

## 这次实验没有做什么

- 没有读取第10页后的规则；
- 没有读取旧策略研究、游戏引擎、地图实例或规划器；
- 没有运行对局或声称任何策略最优；
- 没有让三位阅读者互相看答案。
