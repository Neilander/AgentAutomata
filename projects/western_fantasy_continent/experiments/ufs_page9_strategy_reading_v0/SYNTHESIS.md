# UFS 第1—9页三视角阅读实验：主 Agent 对照

- 日期：2026-08-21
- 输入：只含规则第1—9页对应的五份 `stages` JSON
- 样本：3位隔离阅读者，每位只承担一种分析角色
- 性质：规则阅读后的自然策略形成实验，不是实战胜率评测

## 一句话结果

只读到第9页，阅读者已经能形成一个一致的策略骨架：**这是在母舰固定倒计时下推进研究的竞速；骰子既产生基地行动，也推动同列敌机；能源和挖掘负责把当前行动接到最终研究入口；防空、射击和落点控制负责避免两种失败先发生。**

但规则本身还不足以直接回答“当前局面究竟选哪个动作”。它提供的是目标、约束、行动后果与一批条件式候选；真正选择仍需要当前局面、注意结果、候选比较和停止/继续判断。

## 三份报告各自产出了什么

### 1. 宏观策略：给出整局方向与回合检查顺序

宏观阅读者把整局理解为“研究竞速 + 生存底线”，并形成六个高层判断：

- 研究是持续收束方向，城市伤害与母舰骷髅行是硬边界；
- 每颗骰子都要同时看房间收益和同列天空后果；
- 能源是付费房间与挖掘链条的兑现条件；
- 挖掘是抵达最终研究入口的必要投资，但速度不固定；
- 多格房、白骰重投与研究房顺序要求按完整组合规划；
- 敌机会回收和再生成，防御更像争取研究时间，而非默认永久清场。

它还给出一个回合级检查框架：先看失败窗口，再定本回合主推进目标，然后共同检查天空后果和房间组合，最后按依赖关系结算并预想母舰阶段后的新局面。

### 2. 资源强调：没有得出单一排行榜，而是三层结构

资源阅读者没有把答案简化成“能源最重要”或“研究最重要”，而是区分出：

1. **终局进度**：研究是唯一明示的正向胜利进度；
2. **生存时间**：城市伤害余量与母舰距骷髅行共同构成双重失败时钟；
3. **行动转化**：骰子、列、房间格、能源、挖掘空间和结算顺序把有限机会转成研究或防御效果。

其中，能源是支付关系最明确的可消耗数值资源；骰子和合法格则更像每回合的机会容量。二者不能互相替代：有骰无能源时部分行动无法兑现，有能源而没有合适骰子、列或完整多格房时也无法形成效果。

这说明规则最强调的不是孤立资源存量，而是**资源能否在正确空间和时序中配套兑现**。

### 3. 具体策略：形成20条条件式候选

具体策略阅读者产出 T01—T20，共七组局部判断：

- 白骰顺序与重投：保留已有用途的骰值，或在当前骰值无法过门槛时把重投当修正机会；
- 防空与落点：一点防空冻结一列、紧急防撞时接受无房间收益、只按最终停留格规划；
- 爆炸格与战斗机：把多艘符合条件的敌机送到爆炸格后一次击毁，只为新增目标追求更高阈值；
- 能源与结算：先产能再结算耗能房，减少能源上限溢出；
- 多格房与研究：无法填满时不轻易承诺，多研究房逐个模拟顺序，能到顶时先结算立即获胜；
- 挖掘与终局：为最终11点格提前开放下半部多格研究房，用满足距离的骰并预留1能源；
- 母舰与生成：利用下一行回收获得短期缓冲，在生成平局时考虑下一回合可控性，清空一列前考虑它会成为紫船优先生成候选。

这些不是固定动作表。每条都写了触发条件、预期后果、依据、推论等级和仍需观察的局面信息。

## 三份报告自然一致的地方

三位阅读者在没有互相读取报告的情况下，都独立强调了以下关系：

- 研究、伤害、母舰位置共同决定整局方向与截止时间；
- 骰子点数不是单向收益，因为它同时强化房间和推动敌机；
- 能源、骰子、格位和结算顺序必须配套，单看一个资源数值会误判；
- 挖掘不是单纯扩张，而是最终研究入口的前置条件；
- 规则能产生条件式策略，却不给固定资源权重、最优骰序或标准胜利路线。

这种跨角色一致性说明：上述骨架确实能从第1—9页规则自然形成，不依赖旧攻略或引擎后见信息。

## 对“主动下一步”的启示

这次实验把第七项问题切得更清楚了：

- 规则阅读可以形成**长期方向**；
- 当前环境和动作后果可以唤起一批**条件式候选**；
- 但“现在选哪一个”还需要把候选放回当前注意到的对象与状态中比较。

因此，候选判断与主动下一步不是再补一条自动因果轨迹，而是：

1. 从当前真实世界或设想世界读取被注意到的状态；
2. 用规则与经验生成适用的候选；
3. 预测各候选的即时后果和后续压力；
4. 按当前目标、失败窗口与资源可兑现性进行比较；
5. 选出一个动作，或因信息不足/需要选择而停止继续自动粘连。

具体策略报告中的20条假设，可以作为后续“候选生成器”的首批人工可审计样本；它们还不能直接充当最终决策器。

## 边界审计

- 三位阅读者只被提供实验协议和五份允许输入；没有收到旧策略研究、引擎、地图或用户示例。
- 三份报告引用的61个反引号标识均能在五份允许输入中找到，或明确指向其中的 `blockedInferences` / `openQuestions` 分区；未发现来源不明的规则 ID。
- 第10页后的城市能力、机器人、威胁等级细节与战役内容只在“不允许使用”的边界说明中出现，没有参与策略推导。
- 报告明确保留固定资源权重、最佳挖掘速度、最优骰序和标准胜利路线为未知。

## 尚未验证

- 20条具体策略是否在真实首局局面中经常触发；
- 触发后是否确实改善结果，或会被其他同回合机会成本反转；
- 三位阅读者的结论能否稳定复现到更多独立阅读者；
- 把这些候选接入当前注意—五槽—唤醒—连续设想流程后，能否在不读取隐藏状态的前提下选出合理下一步。

下一步最有价值的实验，是给同一个只暴露公开信息的首局局面，让系统先注意、再从 T01—T20 中唤起适用候选，记录“为什么候选适用、为什么选它、为什么停止”，而不是直接跑完整最优规划器。
