# UFS 真实状态候选发现与判断试卷 V0

对 `PUBLIC_MAP_AND_STATES.md` 中的状态A、B、C分别作答。

## 每题必答

1. **读取到的公开状态**：用自己的话复述当前轨道、已占列、骰子、关键飞机和已形成房间。
2. **依据知识**：列出实际使用的知识/事实/行为 ID；只列真正进入判断的项目。
3. **发现合法候选**：
   - 按未放骰、开放列、已挖掘/未挖掘格分组；
   - 列出你认为合法的“骰子→格子”候选；同类防空可合并写，但必须说清列；
   - 写出因列已占、距离不足、多格承诺或每回合一次挖掘限制而不能做的动作。
4. **自行计算直接后果**：至少对最终进入比较的5个候选计算：
   - 实际下降量；
   - 该列全部飞机最终位置；
   - 最终格效果；
   - 房间值、完整性、能耗与可兑现结果；
   - 白骰放置会重投哪些剩余骰子。
5. **判断卡**：为至少3个认真保留的候选写明条件、基础成本、状态代价、直接收益、后续用途、宏观瓶颈匹配、排除/保留理由和不确定性。
6. **当前宏观需要**：判断当前更卡能源、挖掘、研究、生存、房间组合还是剩余时间；不得使用固定资源权重。
7. **锁定下一步**：只选择一个精确的 `骰子ID/颜色点数 → 格子ID`，说明为什么现在先做它，以及没选次优项的原因。
8. **可审计预测**：在每题结尾单独写一行：

```text
SELECTION <状态字母>: die=<骰子描述>; cell=<格子ID>
```

再写一行只预测这次放置后、白骰未知重投之前可以确定的公开变化：

```text
PREDICTION <状态字母>: ...
```

## 重要边界

- 不运行引擎，不读取候选列表，不查询未来重投。
- 箭头占位等若现有知识不足以确定，必须标为不确定，不可偷偷补规则。
- 不要求声称全局最优；要求下一步合法、即时预测尽量准确、选择能由前文推出。
