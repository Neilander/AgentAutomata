# 正式规则引擎 V1

当前已经完成的是“地图驱动的正式规则状态机”，不是完整正式地图，也还没有接规划玩家。

## 已实现

- 五颗工人骰、白骰放置后重掷、每列一骰。
- 高骰推动敌机、AA 减一、城市受伤。
- 箭头落点、母舰立即下降落点、爆炸格。
- 房间自由结算、能源成本、房间修正。
- 多格房间、逐格研究成本、最终研究必须多格房。
- 挖掘路径和每回合最多一个未挖掘放置。
- 紫机重生、白机被击落后移出、正式出生优先级。
- 母舰移动、行效果、骷髅失败。
- 机器人安装、占格、疲劳、逐次衰减、主动移除和被埋。
- Roswell/New York/Washington 所需的无能力、机器人上限和首次掷骰设值三类城市配置能力。

## 当前不能做什么

- 不能报告正式游戏胜率：真实天空、基地和城市组件尚未录入。
- 不能评价规划玩家：当前只有随机冒烟玩家，用于发现状态机卡死。
- 合成地图位于 `fixtures/synthetic-map.js`，只覆盖规则形状，不代表任何商业版图。

## 运行

```powershell
node test-standard-engine.js
node run-synthetic-smoke.js
```

收到真实组件图片后，先录入地图并通过 `map-contract.js`，再接现有 768 维召回和路线规划器。
