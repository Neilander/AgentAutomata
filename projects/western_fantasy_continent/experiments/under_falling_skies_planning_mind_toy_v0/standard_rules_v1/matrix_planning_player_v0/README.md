# UFS 规划玩家 v0

这是一个隔离的程序玩家实验，目标不是穷举整局，也不是偷看未来，而是在玩家可见信息上做回合内规划，并验证“目标—方法—动作—后果”的规划 MindToy 能否实际玩通 UFS。

## 当前结果

- 训练集 30 局：22 胜，73.3%。
- 独立开发集 30 局：19 胜，63.3%。
- 冻结最终集 100 局：58 胜，58.0%。
- 最终集只跑了一次，且在运行前冻结了策略、引擎、地图和种子表哈希。

旧版独立开发集为 9/30（30%）。本版提升的主要原因不是扩大搜索，而是修复了两个玩家认知错误：

1. 规划中的飞船出生选择与真实执行改为同一个公开策略，避免玩家计划的是另一个世界。
2. `researchIndex=15` 不再被当成已经接近自动胜利；玩家知道自己仍欠最后 11 点，并检查多格研究室、能源和剩余安全回合是否足以兑现。

## 信息边界

玩家只收到公开地图状态、当前骰子、公开轨道和当前合法动作。随机种子、RNG 状态、未来骰子、候选动作的真实未来状态、标准答案和其他玩家轨迹都留在评测器内部。白骰规划仍使用固定的公开概率近似，因此它能预测风险，但不能预知本局未来。

## 仍未完成

- 当前白骰近似仍是固定的 `3/4` 序列，不是真正的概率 chance node。
- 搜索主要覆盖当前回合，没有正式的下一回合随机 afterstate。
- 防空、战机和批量飞船出生还没有用精确反事实统一估值。
- Roswell A+B 威胁 0 地图是用户录入、结构测试通过的可运行版本，不应宣称已逐格独立核对官方地图。

下一步若继续优化，应优先做白骰 chance node 和一回合风险 afterstate，而不是继续微调固定奖励权重。
