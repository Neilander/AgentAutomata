# 零规划高维符文 V0

这是正式 Roswell 威胁 0 地图上的隔离基线。它故意没有计划、路线、里程碑、假设或跨步骤记忆。

每次选择只做四件事：

1. 从最终胜利规则和当前可见状态激活研究、生存、能源、防御、挖掘等知识方向。
2. 将每个合法选项的即时规则结果拆成知识位移，例如研究推进为正研究方向、城市受伤为负生存方向。
3. 把全部位移加到 768 维零点，得到该选项当前的坐标；坐标不归一化，因此更强或更多的即时效果会移动得更远。
4. 只用 `当前需求向量 · 选项坐标` 选择最高项。

程序允许模拟一个候选动作以读取它的即时规则结果，但不会组合多个动作、预测下一回合、保存计划或在历史中学习。这正是后续规划 MindToy 的零规划对照。

运行：

```powershell
node test-no-plan-rune-player.js
node run-experiment.js
```
