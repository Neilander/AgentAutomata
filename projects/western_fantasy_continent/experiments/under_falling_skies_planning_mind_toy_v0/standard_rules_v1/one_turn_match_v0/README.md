# 一步 Grounded Match V0

这是短期规划的最小单元，不是完整规划器。

## 输入与输出

```text
输入：一个数学目标 + 当前状态 + 当前所有已实例化合法行为
处理：每个行为只向前演算一次，再由目标检查结果
输出：完成 / 部分推进 / 无关 / 有害 / 无效
```

`one-turn-match.js` 不生成行为，不创造子目标，不连接多个动作，也不替玩家选最终动作。它只回答：当前这组行为里，有没有能在一步内匹配这个目标的行为，并保留完整枚举审计。

`ufs-placement-match.js` 把正式 Roswell 引擎当前所有合法“骰子—格子”组合接入 Match。这里的“一步”是当前一次工人骰放置决定，不是把五颗骰子的整轮路线提前穷举。

## 为什么现在可以穷举

当前合法放置是有限集合，且标准引擎已经拥有确定的单步状态转移。因此程序可以逐项验证，不需要语言模型猜测，也不会只检查看起来最好的几个选项。

穷举边界仅覆盖玩家行为。白骰若导致剩余骰子重掷，未来点数仍未知；适配器会标记 `future_dice_reroll`，目标不得读取这些未来随机点数。

## 测试覆盖

- 一个目标同时存在直接完成、部分推进、无关和有害行为。
- 只有部分推进时，不能伪装成目标完成。
- 完全无匹配时明确返回无解。
- 模拟失败的行为仍保留在审计中。
- Roswell 真实合法放置全部被检查；同一个2点骰放在普通房会让敌机落到母舰下降格，而放在 AA 房因下降减1可以避开。
- 重复行为键直接报错，避免所谓穷举实际漏项。

运行：

```powershell
node projects/western_fantasy_continent/experiments/under_falling_skies_planning_mind_toy_v0/standard_rules_v1/one_turn_match_v0/test-one-turn-match.js
```
