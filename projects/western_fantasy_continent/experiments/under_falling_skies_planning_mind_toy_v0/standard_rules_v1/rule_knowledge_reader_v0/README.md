# 规则分段认知读取 V0

目标不是整理一份全知规则摘要，而是保存一个认真阅读规则书的新玩家在每个阅读阶段实际拥有的认知。

每个阶段只能使用该阶段及更早页面：

- `conceptsAdded`：玩家已经能识别的概念。
- `environmentFactsAdded`：界面或设置直接告诉玩家的当前事实。
- `knowledgeAdded`：规则书明确建立的主体、环境、行为、结果关系。
- `behaviorsAdded`：玩家已经知道自己可以执行的行为。
- `openQuestions`：当前尚未解释，不能自行补全的内容。
- `blockedInferences`：看起来合理但规则书此时没有教会玩家的攻略或后见知识。

后续阶段允许新增和修正规则认知，但不得修改旧阶段来伪造“玩家一开始就知道”。
