# 获得面与意义 V0

这个隔离实验把普通概念和 `获得(概念)` 分开：

```text
科技完成 -> 获得(胜利)
能源 -> 获得(研究)
能源房 -> 获得(能源)
```

一条已经能够在决策时调用的规则，会让规则来源的768维自然语言坐标拉动对应的“获得面”。某个东西对当前目标的意义，是它沿已理解关系抵达 `获得(胜利)` 的路径贴近程度。

路径不会因为规则书里出现了两条可组合规则就自动打通。`房间需要能源` 和 `研究房推进研究` 在阅读后都属于声明知识，但 `能源 -> 获得(研究)` 要等玩家真实遇到研究房缺电，才成为可以在决策中调用的组合知识。

V0不设置科技、能源、挖掘的人工效用权重。每个已激活规则锚点等权拉动获得面；多步意义由每一层768维余弦贴近程度相乘得到。
