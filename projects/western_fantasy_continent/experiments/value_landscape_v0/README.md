# 玩家价值地形 V0

这个隔离实验验证一件事：队伍在语义空间中的坐标描述“它是什么”，玩家对它的强弱判断则由另一层可变化的价值地形描述。胜负不会修改队伍坐标。

## 两类学习

1. `R` 只说明某个具体队伍在某个环境中的结果，因此在完整队伍坐标附近增加一个窄的局部锚点。
2. `EVerify` 说明结果确实由某个概念造成，因此除了局部锚点，还会在该概念附近增加一个较宽的概念锚点。

所以“护盾队赢了，但不知道为什么”只会提高这支队伍及非常相似队伍的价值；“护盾队赢了，而且护盾确实挡住了致命伤害”才会提高整个护盾区域的价值。

## 计算

每条锚点保存：坐标、结果效用、适用环境、证据权重、影响半径和来源。查询队伍 `x` 时，锚点 `i` 的影响是：

```text
distance_i = 1 - cosine(x, anchor_i)
influence_i = exp(-distance_i / radius_i) * weight_i
value = (prior_mass * 0.5 + Σ influence_i * utility_i)
        / (prior_mass + Σ influence_i)
```

信心不是“附近见过多少证据”这么简单：

```text
coverage  = evidence_mass / (prior_mass + evidence_mass)
consensus = 1 - 4 * weighted_outcome_variance
confidence = coverage * consensus
```

因此同一位置一次胜、一次负时，覆盖度很高，但共识度和最终信心都会归零。

## 环境与全局变化

- 普通环境中的护盾证据不会自动污染驱散环境。
- “驱散导致护盾失效”只改变驱散环境里的护盾价值。
- 若证据确认护盾机制被全局削弱，则概念锚点使用全局作用域，所有环境都会重新评价护盾。
- 不论价值如何变化，队伍及护盾概念的语义坐标都不移动。

## 真实验证边界

- 使用既有 50 支允许重复角色的队伍、6 支敌队和玩家可见战斗结果。
- 队伍坐标来自 `semantic_team_coordinate_v0` 的纯能力快照，明确排除了胜负结果。
- 学习每个队伍/敌人组合的 2 场既有可见结果；验证使用每格 20 个隐藏随机种子，共 6000 场。
- 五折按队伍留出：预测目标队伍的结果不会用于该队伍的学习。
- 真实战报目前没有结构化的 `EVerify` 因果标签，所以真实 50 队部分只验证 `R` 的局部锚点；概念推广由受控实验验证。
- `hiddenTruthCoordinateOracle` 故意违规使用隐藏真值，只是诊断坐标几何是否有表达能力，绝不属于有效的玩家学习成绩。

## 运行

`run-local.ps1` 会先生成 6000 场隐藏验证，再运行价值地形和断言。若隐藏验证已存在，也可以只运行 `run_experiment.py` 与 `test_results.py`。

本实验没有修改正式玩家 Agent。
