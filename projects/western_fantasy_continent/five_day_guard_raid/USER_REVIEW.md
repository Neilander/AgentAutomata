# 十五日网页版玩家路径审查

## User frame

- User：第一次打开 Demo、只知道“刷装不耗行动”的玩家。
- Intent：在有限行动中探索事件、扩充队伍、刷装，并活过第 5、10、15 日。
- Prior knowledge：不知道隐藏解法、未来事件、招募条件与政治路线阈值。
- Success state：能看懂当前哪里有事，完成选择，进入并看完真实战斗，理解战果造成的公开变化。

## Task path

1. 看地图：区域徽标显示当前事项总数，地点行显示各自事项数；可切换区域和地点，选错可随时换回。
2. 做选择：右栏只显示所选地点当前真实可执行的行动；行动后同场景提示最近变化。
3. 刷装：灰炉、采坑、炉心按日期逐步开放；十连不消耗行动，背包数字立即增长。
4. 整队：出战位直接显示人数上限、前后排、角色与战力；满员候补显示“已满”，可让出战者回到候补。
5. 迎战：进入正式战斗后地图与管理栏收起；玩家完整观看战斗，再从伤害、治疗、护盾与存活读战果。
6. 返回局势：确认战果后回到地图；失败也推进局势，不把玩家送回初始状态。

## Findings and minimal fixes

- Ambiguous result：地图以前只列地点，没有清楚回答“这里还有几件事”。已在区域和地点两层显示实时事项数。
- State mismatch：五日时间轴和四人固定格无法表达三幕。已改为十五日节点、三次来袭标记与动态 4/10 人编队。
- Repeated action：结束本日按钮在重绘后会累计监听，存在一次点击跳多日风险。已改为静态按钮只绑定一次，并以浏览器连续推进验证。
- Hidden action：候补在满员时没有加入按钮，但原因不明确。已显示“已满”。
- Ambiguous result：战斗结束只看胜负不足以学习队伍表现。已补存活、伤害、治疗、护盾与主要输出；不展示隐藏阈值。
- State mismatch：旧场景层可能遮住战斗层。已保留显式 hidden 规则并实测河畔战斗可见、结算后可返回地图。

## Do not change

- 不展示尚未出现的事件、完整锁钥解法、政治路线阈值或建议答案。
- 不把战斗替换成战力数字比较，也不加入跳过战斗。
- 不把全部事件一次铺在首屏；首日仍只有两个事件。
