# 十五日网页版玩家路径审查

## User frame

- User：第一次打开 Demo、只知道“刷装不耗行动”的玩家。
- Intent：在有限行动中探索事件、扩充队伍、刷装，并活过第 5、10、15 日。
- Prior knowledge：不知道隐藏解法、未来事件、招募条件与政治路线阈值。
- Success state：能看懂当前哪里有事，完成选择，进入并看完真实战斗，理解战果造成的公开变化。

## Task path

1. 看地图：全屏地图直接显示每个当前地点及事项数；可拖动、缩放和一键回到全图。
2. 做选择：点击地点后，描述与当前真实可执行行动在该点附近的局部浮窗中出现，不需要跨屏寻找。
3. 刷装：地点浮窗显示 LV1/LV2/LV3 与敌人数；选择后整页观看真实战斗，胜利掉落一件装备并自动进入下一轮。
4. 整队：出战位直接显示人数上限、前后排、角色与战力；满员候补显示“已满”，可让出战者回到候补。
5. 迎战：进入正式战斗后地图与管理栏收起；玩家完整观看战斗，再从伤害、治疗、护盾与存活读战果。
6. 返回局势：确认战果后回到地图；失败也推进局势，不把玩家送回初始状态。

## Findings and minimal fixes

- Wrong priority：旧版把地点列表、场景描述和行动选项拆成左中右三栏，玩家每换一件事都要横穿屏幕。已改为地图点位直接打开就地浮窗。
- Hidden action：同一区域事件较多时，随机散点可能互相遮挡。已改为确定性错列布局，并用浏览器逐点点击回归发现并修复。
- No recovery：旧地点浮窗可能在跨日后挡住新地点。结束本日会自动收起；玩家也可点空白、按 Esc 或点关闭按钮退出。
- Wrong priority：行动力在资源栏和按钮区重复出现。现在只保留顶栏独立的“行动力 X/3”。
- Ambiguous result：每个地图点继续显示当前事项数；战斗、旧事回响与普通地点使用不同视觉信号。
- State mismatch：五日时间轴和四人固定格无法表达三幕。已改为十五日节点、三次来袭标记与动态 4/10 人编队。
- Repeated action：结束本日按钮在重绘后会累计监听，存在一次点击跳多日风险。已改为静态按钮只绑定一次，并以浏览器连续推进验证。
- Hidden action：候补在满员时没有加入按钮，但原因不明确。已显示“已满”。
- Ambiguous result：战斗结束只看胜负不足以学习队伍表现。已补存活、伤害、治疗、护盾与主要输出；不展示隐藏阈值。
- State mismatch：旧场景层可能遮住战斗层。已保留显式 hidden 规则并实测河畔战斗可见、结算后可返回地图。
- Ambiguous result：旧刷装点击后直接增加十件物品，玩家既没看到战斗，也不知道装备来自哪一轮。现改为每轮正式战斗后在同页下方出现本轮掉落，并在累计架上按稀有度、战力排序。
- Missing action：连续刷装若没有明确停止点，玩家只能刷新页面。现提供常驻“本轮后停止”；战斗中点击会等待本轮结束，轮间点击会立即返回地图。
- State mismatch：如果高层战败后仍自动刷新敌群，玩家无法整理装备或判断卡点。现为战败无掉落并停在结果态，明确提供“再刷一轮”和“返回地图”。
- Wrong priority：掉落详情若覆盖战场会打断观察。现让战场占主体，掉落架固定在下方；当前掉落只突出一件，累计陈列最多保留最佳 200 件，避免长时间刷装拖慢页面。

## Do not change

- 不展示尚未出现的事件、完整锁钥解法、政治路线阈值或建议答案。
- 不把战斗替换成战力数字比较，也不加入跳过战斗。
- 不公开掉率表、敌人隐藏数值或建议玩家该刷哪一层；只显示层级、敌人数与真实战斗结果。
- 不把未来事件一次铺在首屏；只在地图上呈现当前已经出现的地点。
