# Candidate Skill Pack 2026-07-06_1419

This is an isolated candidate asset pack for the automated character brainstorming pipeline.

It is intentionally separate from the official shared assets:

- Do not import it from `game_data/skill-data.js`.
- Do not merge candidates into official skill assets without user approval.
- Use this pack for blind review, local experiments, and iteration reports only.

## Files

- `brainstorm_prompt.md`: prompt used for this run.
- `brainstorm_raw.md`: raw brainstorm ideas.
- `screening.md`: pass/reject/record screening notes.
- `candidates.json`: selected blind-test candidates.
- `test_plan.md`: intended validation setup and current status.
