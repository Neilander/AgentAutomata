# Brainstorm Prompt

Run 7 used four narrow subagent directions instead of one large brainstorm.

The prompt pattern was:

> You are a divergent subagent for a western-fantasy auto-battler / loot project. Do not edit files. Output 8 original ideas around one narrow direction. Each idea must include: name, type, core fantasy, output posture, what the player wants to stack, passive, small skill, ultimate or item passive, and visible weakness. Favor output carries or output-enabling assets. Do not copy protected IP. Do not overcomplicate mechanics.

Directions:

1. Low-health ranged, reload, returning projectile, and dangerous output windows.
2. Shield-to-damage, protected long-cast, counter cannon, front line protects backline burst.
3. Frost, shatter, mark, bouncing basic attacks, and backline hunting.
4. DOT time pressure, epidemic fire spread, long-cast burst, delayed detonation, and "the longer it goes, the worse it gets".

Rationale:

- Run 6 proved small-grain direction prompts were more reliable than one large prompt.
- Run 7 keeps the same stability, but narrows toward implementable output fantasies.
- Only four subagents were used this round to avoid the timeout pattern seen in earlier rounds.
