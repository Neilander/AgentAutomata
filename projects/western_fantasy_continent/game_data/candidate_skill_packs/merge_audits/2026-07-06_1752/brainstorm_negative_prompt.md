# Negative Prompt For Next Brainstorm

Do not generate more generic versions of:

- shield cannon / shield breaks into damage;
- low-health ranged with returning projectile;
- frost bouncing archer;
- generic DOT spread / poison fire transfer;
- generic long-cast big explosion;
- generic mark hunter without a new mark function.

Allowed only if the idea changes the player's build question in a concrete way.

Prefer these open spaces:

- ailment identity beyond DOT;
- deployed entities such as traps, mines, turrets, constructs, totems, banners;
- output from block, cleanse, healing received, or effect resistance;
- formation / row / flank pressure;
- resource conversion;
- enemy/ecology tools;
- supports that change output posture rather than adding plain damage.
