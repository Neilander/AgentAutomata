- **寒星弹匣师**: attack-speed frost bullet package.
- **黑钟疫使**: long-fight DOT detonation carry.
- **余烬药剂师**: death-transfer epidemic DOT.
- **山息一刀**: stand-still charged heavy hit.
- **双手交替术士**: alternating rhythm caster.
- **白烛判官**: focused mark judgment.
- **银镜弹匠**: non-elemental bounce baseline.
- **百手拳师**: melee multi-hit basic baseline.
- **星陨长咏者 / 石钟咏唱者**: merge into one long-cast burst template.
- **鸣雷指环**: trigger-equipment component.

## Archive Rule

Archive candidates that are only a narrower or noisier version of the carry-forward representative. Reopen them only if a runtime test proves the representative's fantasy is wrong.
