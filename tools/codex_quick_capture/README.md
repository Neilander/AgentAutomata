# 划词快速记录

一个不修改 Codex、也不向任何外部服务发送内容的 Windows 小工具。它常驻在系统托盘，可从 Codex、浏览器、PDF 阅读器或其他支持复制的应用中捕获划选文字。

## 一键启动

双击 `Start.cmd`。首次运行时可能会看到 Windows 的 PowerShell 窗口短暂出现，之后工具驻留在右下角系统托盘。

无需安装依赖；工具使用 Windows 自带的 Windows PowerShell 5.1 和 WinForms。

## 使用方法

1. 在任意应用里用鼠标划选一段文字。
2. 按 `Alt+M`。
3. 在弹出窗口中填写“条目名称”，按回车或点击“保存”。
4. 按 `Alt+O`，浏览器会打开本地条目页。

条目页支持按名称/正文搜索、修改条目名称，以及一键复制正文。修改名称时可以按回车保存、按 Esc 取消；正文和原创建时间不会改变。也可以双击托盘图标打开条目页；右键托盘图标可以从当前剪贴板创建条目、查看条目或退出。

## 修改快捷键

先从托盘菜单退出工具，编辑 `config.json`，再重新运行 `Start.cmd`：

```json
{
  "captureHotkey": "Alt+M",
  "browseHotkey": "Alt+O",
  "port": 17823
}
```

支持 `Ctrl`、`Alt`、`Shift`、`Win` 和一个普通键，例如 `Ctrl+Alt+K`、`Win+Shift+F8`。如果快捷键已被别的软件占用，启动时会明确提示冲突；修改后重启即可。

## 数据与隐私

- 条目保存在 `data/entries.jsonl`，每行一个 JSON 对象，包含名称、正文和创建时间。
- `data` 目录已设置为 Git 忽略，不会把私人条目提交到仓库。
- 查看页只监听 `127.0.0.1`，不会接受其他设备的网络连接；修改名称还要求当前工具进程生成的一次性本地令牌。
- 工具不会修改或注入 Codex，也不会访问互联网。

如需备份，退出工具后复制 `data/entries.jsonl` 即可。

## 常见问题

- **按记录快捷键没有弹窗**：先确认文字能用 `Ctrl+C` 正常复制；某些管理员权限运行的应用不会接受普通权限工具发送的复制按键。
- **提示没有读取到文字**：当前应用没有把划选内容写入剪贴板。重新划选后再试。
- **网页打不开**：端口可能被占用。退出工具，修改 `config.json` 的 `port` 后重启。
- **重复启动**：工具会阻止同一用户重复运行；请在系统托盘中找到已有实例。

## 自测

双击 `Run-SelfTest.cmd`，或在此目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\QuickCapture.ps1 -SelfTest
```

自测会使用临时目录和随机本地端口，验证条目存储、本地网页 API，以及两组系统级快捷键的注册/释放，不会写入你的真实条目。
